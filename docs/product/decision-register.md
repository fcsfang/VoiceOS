# VoiceOS 产品决策与待定事项

日期：2026-10-10。依据：[愿景 v1.1](../VoiceOS：产品愿景与概念设计文档%20v1.1/VoiceOS_产品愿景与概念设计文档_v1.1.md)。

本表区分产品已确认方向（D）、用户待确认细节（P）、技术待验证事项（H）。工程方案不能替代产品确认；没有回复不能视为同意。

## 1. 已确认的十项核心决策

| ID | 已确认方向 | 来源 | 需要保留的约束 |
|---|---|---|---|
| D01 | 双模式交互 | §3、§4、§7.3 | A 默认无打断，B 用户主动开启；两模式共享历史 |
| D02 | 语音优先、多模态 | §3、§5.1 | Mac 语音为核心；来源身份分离；辅助格式可分阶段 |
| D03 | 外部资料与个人知识分层 | §3、§5.3 | 收藏、分析、阅读、认可不自动等同个人理解 |
| D04 | 个人知识分级确认 | §3、§5.4 | 用户明确表达自动保存为暂定认知；AI 推论作为候选 |
| D05 | 自主行动管家 | §3、§5.5、§7.1 | 目标规划与跟进有自主权，重要执行保留授权边界 |
| D06 | 混合自适应主动反馈 | §3、§5.6、§7.2 | 后台主动、前台低干扰；非紧急反馈不要求回应 |
| D07 | B 过渡、C 终局 | §3、§9 | 近期后台核心与轻量控制中心，最终独立应用；身份历史连续 |
| D08 | 智能体验、可靠恢复、部署开放 | §3、§8.1–8.2 | GPT 主导认知；相关上下文；允许休眠暂停，唤醒续作；无需首版常驻云 |
| D09 | 可追溯纠错与记忆修正 | §3、§8.5 | 保留修订、检查派生影响；AI 纠错不冒充真实认知变化 |
| D10 | 首版验证完整闭环 | §3、§6.2、§10 | 新表达或任务结果回到源头；总结本身不构成 MVP 完成 |

五条不变量：用户思想优先、原始依据可回溯、低负担使用、执行自主权有边界、B → C 数据不断裂。

## 2. 由正文明确的范围

- 基础模式 B 已在 §10.1 列入 MVP，§9.3 的阶段 II 是体验深化，不是把基本对话移出首版。
- Mac 录制、音频和录制视频导入、Apple 提醒事项连接、基础历史关联、版本与纠错属于 MVP。
- 思源在 §6.1 和 §12 被列为重要早期工具及待解决集成，但未在 §10.1 明确为不可替代的首版交付；P03 已确认作为可选集成，不阻塞首版。
- 原始音频是英语发音判断的必要证据；没有专门评估能力时，首版只提供文本表达反馈，不提供误导性发音评分。
- 完整原生双端、实时全双工语音、复杂图谱、自主多应用操作、休眠期间云端常驻及全量持续重评估明确延期。
- §10.4–10.5 的 95% 处理完成率、四周试用和至少三条案例是拟定起点，尚未冻结统计口径与门槛。

## 3. 用户待确认的产品细节

| ID | 问题 | 当前状态 | 影响 |
|---|---|---|---|
| P01 | 普通任务创建、目标拆解、弹性排期、重排和跟进 | 2026-10-10 用户确认高度自主，尽可能交由 AI 操作；重要/不可逆操作仍受 D05 边界约束 | 普通操作使用持续授权，不逐条审批；实际清单和接口配置待设置 |
| P02 | 云端文本、相关授权历史、原始音频和仅本地资料规则 | 2026-10-10 用户选择允许文本与相关历史，原始音频单独选择；仅本地限制保留 | 已确认处理原则；音频未自动获上传许可，服务/凭据配置待设置 |
| P03 | 思源是否为首版必须集成 | 2026-10-10 用户确认思源作为可选集成；Apple 提醒事项仍必需 | 首版阅读回溯由轻量控制中心提供，思源不成为发布依赖 |
| P04 | 首版非紧急认知反馈的默认呈现 | 2026-10-10 用户确认默认静默，系统通知由用户开启 | 未开启时无非紧急认知系统通知；开启后预算与窗口在后续设计验证 |
| P05 | 月度成本、可接受处理时延、试用样本及质量门槛 | 2026-10-10 用户授权先由工程选择方案测试；月度预算、时延及质量指标待测后校准 | 首轮小规模试验可推进；不视为无限费用授权 |
| P07 | 模式 B 首版入口及 GPT-Live 后续接入 | 2026-10-11 用户接受逐轮语音＋文字，同时保留 GPT-Live 目标；当前没有其 API，订阅文本接入与实时语音不混同 | 首版录音/本地转写/文本回复继续实现，Live 适配待实际访问条件；不改成仅限 Codex 的产品 |
| P06 | 数据导出、备份、删除的首版交付细节，包括外部副本与保留范围 | 2026-10-10 用户接受默认结构化导出、可选媒体打包、恢复前完整性校验、删除不自动传播至外部笔记/任务 | 默认范围已确认；正式格式、保留期与恢复机制待工程验证 |

P01–P04 已确认，不再按每次普通任务/文本处理重新询问，也不把思源集成或静默默认值视为未决。实际操作范围配置、模型/同步验证、通知开启后的预算与窗口设计仍需完成。P05 已授权先选方案测试；P06 默认范围已确认，不重新询问。月度预算、体验指标、备份保留期与工程格式仍待测量和设计。

## 4. 技术验证登记

以下均来自愿景 §12。第三阶段已开始，初步证据见[技术验证报告](../research/technical-validation-2026-10-10.md)；部分探针成功不代表整项已通过。新增跨资源恢复、外部未知结果模拟和迁移证据见[补充报告](../research/reliability-validation-2026-10-10.md)。

| ID | 验证题目 | 需要的证据 |
|---|---|---|
| H01 | GPT 型号、路由与预算 | 代表性任务的忠实性、延迟、成本及失败表现 |
| H02 | 本地/云端转写 | 中英文、混合术语、否定、引用、长录音样本对照 |
| H03 | 录制入口与音轨来源 | Mac 权限、录制/导入格式、用户和节目音轨区分、恢复行为 |
| H04 | 实际数据访问与上传控制 | 仅本地标记是否阻断所有相关上传；外部服务保留与删除能力 |
| H05 | 自主规划与执行边界 | 意图误判、授权范围验证及计划调整风险 |
| H06 | 主动反馈与注意力预算 | 候选价值、通知去重、静默呈现和暂停后行为 |
| H07 | 跨时间检索、关联与矛盾 | 已知相关/不相关/矛盾样本及错误修正后的检索结果 |
| H08 | 存储、备份与迁移 | 稳定身份、关系与版本恢复、格式迁移及未来同步取舍 |
| H09 | 提醒事项与思源连接 | 接口权限、创建后回读、完成/编辑/删除事件、冲突、重试及离线恢复 |
| H10 | MVP 质量指标口径 | 有效样本定义、分母、失败分类、观察时限与人工标注方法 |
