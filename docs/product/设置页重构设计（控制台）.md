# 设置页重构：从链接墙到控制台（v0.1 提案）

> 用户判断：设置页现在作用不大。除了模型配置，设置页应有更多选择权、配置权、状态显示与监控；完善设置页是完善软件很重要的一步。

## 现状盘点（11 张卡）
模型与服务（含本轮的应用内模型配置）、数据与隐私、连接与自动入口、系统权限、外观、导出与备份、资料库、存储、回顾与查找、键盘快捷键、其他工作与维护。
问题：以「跳转/说明」为主，缺少实时状态与健康监控；配置项散落；看完仍回答不了「现在一切是否正常」。

## 目标
进设置页十秒内能回答四件事：**模型可用吗？资料有多大？后台在忙什么？备份/权限是否正常？** 每一行统一为「标题 + 实时状态 + 动作」。

## 信息架构（重排）

1. **概览与健康**（新，置顶）
   - 本地转写模型：状态 + 测试
   - 文本模型：已配置型号/地址、连通延迟、最后调用结果；「测试连接」
   - 资料库：完整性检查结果与时间、schema 版本
   - 队列：待转写 / 整理中 / 知识核查 / 提醒同步（复用现有 published 状态）
   - 最近错误：一条入口进「处理情况」
2. **模型与服务**
   - 本机转写（下载/删除/状态）
   - 应用内文本模型（地址/密钥/型号/思考强度/保存启用）——本轮已实现
   - 「测试连接」：用当前草稿配置发一次极小请求，显示成功/延迟/错误
3. **数据与存储**
   - 资料库路径（可复制）、占用明细（DB/媒体/备份/其他）与清理入口
   - 备份：保留份数、最近一次备份时间、立即备份
   - 导出/恢复/迁移包
4. **自动化与连接**
   - 收件箱（VoiceOS 收件箱 / 语音备忘录 / 其他文件夹）与自动处理说明
   - 提醒事项连接与同步状态
   - 监测来源与检查频率
   - 快捷键与冲突检测
5. **行为与生成**
   - 自动整理开关（按材料类型）、默认云端授权策略
   - 笔记：重新整理入口、批注默认显示、「最近笔记」显示
   - 通知开关（整理完成/导入完成/监测）
6. **隐私与权限**
   - 麦克风、屏幕录制、完全磁盘访问的实时状态与系统设置跳转
   - 云端数据范围说明（沿用现有隐私卡并并入）
7. **外观与阅读**：主题、字号、行宽、阅读器默认
8. **诊断**：版本与构建号、日志导出、诊断包（脱敏）

## 交互约定
- 每行：左侧标题与一行状态（值/健康点/时间），右侧动作（更改/测试/打开/清理）。
- 破坏性操作（删除模型、清空备份、删库）二次确认并说明后果。
- 所有新配置存应用内部（UserDefaults/钥匙串），不引入外部文件；文件导入只作迁移入口。
- 设置页顶部加搜索框（P4）：按关键词跳到对应卡片。

## 分阶段
- **P1（进行中）**：应用内模型配置（地址/密钥/型号/强度，钥匙串存密钥）；模型「测试连接」；概览与健康卡第一版（模型/转写/队列/资料库四项状态）。
- **P2**：数据与存储数字化（占用明细、最近备份时间、立即备份）；自动化与连接状态化。
- **P3**：行为与生成开关集中、隐私权限实时状态、诊断与版本信息。
- **P4**：设置搜索、键盘可达、细节打磨。

## 验收
- 十秒四问可答；测试连接在 3 秒内给出结论与延迟；所有配置无需外部文件即可完成。
