## 2. H01/H04：API 实测

认证 `/models` 返回 200，共 21 个模型 ID，包含 `gpt-6.1-sol` 和 `gpt-6-luna`；列出不等于全部路由可用。仅发送合成文本，无工具、无个人历史、无音频。客户端强制 HTTPS 并拒绝重定向，避免把密钥随重定向发送给其他地址。

| 模型 / 样本 | 实际结果 | 生成等待时间 | 语义判定 |
|---|---|---|---|
| Luna / SEM-01 | 客户端超时，服务端结果未知 | 60.19 秒 | 无结果，不评分，不自动重试 |
| Sol / SEM-01 | HTTP 200，completed，JSON 根字段齐全 | 21.910 秒 | 单条人工审查：保留“并不认为”与“只有……才可能”，未制造任务；没有改变否定和条件 |
| Sol / SEM-02 | HTTP 503 | 5.333 秒 | 无结果，不评分；停止剩余样本 |

生成尝试总数为 3，成功完成 1 次。这是有限服务可用性观测，不是十条样本质量对照，也不能推导生产成功率。返回的模型标签与请求一致，只证明服务报告的标签，没有独立验证实际模型来源。Luna 的一个超时不能证明该型号普遍不可用。

成功请求 usage 为输入 519、输出 111、总计 630；此前输入计数返回 319，比实际少 200。该兼容计数路径存在差异，原因未定位；后续估算必须对照实际 usage 和服务账单。输出结构及一条人工语义判定通过，不等于全部嵌套 schema 和语义回归通过。

原定完整两模型十样本方案停止在服务错误处，没有为了凑样本继续反复调用。按已核对的官方 Sol 输入/输出价格计算，成功请求的参考估算为 $0.002148；它不是此第三方的实际账单，不包含失败/未知请求或代理计费。此前 $1 的官方价格工程预算不能在第三方价格未知时被当作真实费用保证。[官方价格参考](https://developers.openai.com/api/docs/pricing)。

公开结果仅包含合成输入对应的输出、请求摘要和 usage，见[API 证据](evidence/api-gateway-2026-10-10.json)。没有保存认证头或密钥。请求 `store=false` 没有证明该第三方保留政策，真实数据及音频不因此获得上传授权。

## 3. H09：Apple 提醒事项实测

用户在系统弹窗授予原生探针权限。通过 Apple 提醒事项界面新建“VoiceOS 验证 2026-10-10”，确认新清单无未完成/已完成项目。探针只选择该清单，一次创建“VoiceOS 合成验证任务”，无到期日期、提醒或邀请。

| 步骤 | 观测 |
|---|---|
| 原生创建 + 回读 | 唯一操作标记匹配，标题相同，isCompleted=false；Apple 界面显示一条合成项 |
| Apple 界面改名 | 实际输入并提交后，原生回读得到“VoiceOS 合成验证任务 — 外部改名”，没有覆盖它 |
| Apple 界面完成 | 原生回读 isCompleted=true，标题与本机 ID 保持一致 |
| 退出重开 | 原测试清单和尝试状态恢复，创建按钮禁用；回读仍为同一 ID、唯一匹配、已完成 |

本轮证明单机当前环境的一条真实写入、已提交外部编辑和完成回流、普通退出重开的有限路径。原生探针没有修改个人已有任务；界面准备时看到了现有列表/任务信息，未将其记录进公共证据或发送 API。公开证据仅包含测试清单和合成项，见[提醒事项证据](evidence/reminders-live-2026-10-10.json)。

合成项仍留在专用清单中，最终状态为已完成，便于复核；没有删除用户资料、清空最近删除或撤销系统权限。探针使用 UserDefaults 记录测试身份，只验证普通退出，不声称支持硬中断或并发幂等。

## 4. 发现与修正：编辑提交和对象刷新

首次通过界面 accessibility setValue 修改标题后，界面显示新文字，但多次查询乃至重开仍读到旧值。随后通过实际粘贴输入并按 Return 提交，回读立即得到新标题。因此不能把早期现象直接归因于 EventKit 缓存；界面文字变化不等于持久化提交。

在排查期间也按 SDK 官方契约强化探针：查询前 reset 存储，再按清单 ID 重新获取对象。reset 会使旧对象失效并丢弃尚未提交的变更；此探针查询时没有待提交编辑。它是验证时的刷新措施，不是生产双向同步策略。[Apple reset](https://developer.apple.com/documentation/eventkit/ekeventstore/reset())。

后续生产设计应明确保存返回、变更通知、重新读取、对象生命周期和冲突快照，避免使用过时对象；本轮没有隔离出“旧代码在已提交编辑后的缓存失败”，不将其记作已复现的系统缺陷。
