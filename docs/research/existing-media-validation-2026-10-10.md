# 现有短音视频本地验证

日期：2026-10-10。run_id：`existing-media-2026-10-10`。用户要求在电脑上找已有短视频/语音测试，暂无时间真实录制。执行本地能力探针，不实现业务功能，不改变 22 个 AC 的未执行状态。

## 1. 选材与处理

在项目、Downloads、Desktop、Movies、Music 查找媒体文件及元数据。选一个 26.9 秒演示视频 V01，以及一段 1449.64 秒中文主题音频 A01 的前 60 秒；未使用另一个教学指导录音。实际来源路径只保存在 Git 忽略的私有 manifest，不放进公开证据。

两者均复制完整原件到独立测试目录，核对原件/副本 SHA-256，再从副本导出 M4A 音轨/片段。转写输入是导出文件，使用已安装的 `zh_CN` Apple SpeechAnalyzer/SpeechTranscriber。无麦克风录制、播放、新模型下载、云上传、GPT 请求或提醒事项操作。

文件是电脑上已有材料，其最初是否真人录制/AI 合成未知；不标作用户个人观点，也不将“现有文件”误写成已确认真人语音。

## 2. 结果

| 项目 | V01 视频 | A01 音频 |
|---|---|---|
| 原件容器时长 | 26.900 秒 | 1449.644 秒 |
| 测试范围 | 全段音轨，读出 26.910 秒 | 0–60 秒，读出 60.000 秒 |
| 原件/副本 | hash 一致；全部探针后原件 hash 未变 | hash 一致；全部探针后原件 hash 未变 |
| 原素材轨道 | 1 视频 + 1 音轨 | 1 音轨 |
| 完整 PCM 解码 | 1,186,752 帧，与声明帧数一致 | 2,646,000 帧，与声明帧数一致 |
| 信号 RMS / peak | 0.03803 / 0.39238，非全零 | 0.08368 / 0.71031，非全零 |
| 本地转写 | 正常结束，0 个字符 | 正常结束，286 个 Unicode 字符 |
| Analyzer 处理时间 | 0.578 秒 | 0.988 秒 |

时间仅从 Analyzer 启动到最终结果，不包括编译、复制/提取、资源查询和模型初始化，不代表端到端 SLA。视频容器时长与导出文件读出时长略有差别，保留两个值，不据此承诺时间戳精度。

A01 产生中文文本；未经原音逐句人工听证/金标准对齐，不能报告识别准确率。V01 有音轨及非零信号但没有文字，不能直接推断“无语音”或“识别失败”，原因未确认。没有为凑成功率替换或隐藏该样本。

补充信号检查器初版在声明帧范围之后继续读取时发生错误；修正为按剩余帧读取后，两份片段完整解码。这是临时探针读取边界的修正，没有产品应用运行，不能记为产品缺陷或系统 API 普遍失败。

## 3. 证据与复现

公开[元数据证据](evidence/existing-media-2026-10-10.json)保留比较结果、时长、轨道、全帧信号指标和调用范围，不包含实际转写、私有路径或原件摘要。完整原件摘要、实际路径、片段、转写结果/文本留在 `runtime/test-runs/existing-media-2026-10-10/`，由 Git 忽略；用户可本地复核。

探针源文件：[导入/提取](../../scripts/probes/media-import-probe.swift)、[本地转写](../../scripts/probes/local-transcription.swift)、[信号/完整解码](../../scripts/probes/audio-signal-probe.swift)。本机环境为 macOS 27.0.1（26A434），显式 macOS SDK 26.5 编译，部署目标 arm64 macOS 26；正式最低系统仍未冻结。

参数契约：导入探针接收 `输入文件、新的临时目录、起始秒数、最大秒数`，已存在输出目录拒绝覆盖；转写探针接收 `音频文件、locale、synthetic/existing-media`，省略第三项保持原合成探针兼容；信号探针接收一个本地音频文件。原件不移动/修改，导出是衍生测试片段，不代替原始文件。
