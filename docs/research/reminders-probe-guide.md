# 提醒事项最小验证程序

日期：2026-10-10。状态：源码已编译，本地临时应用包的 ad-hoc 签名校验通过；随后同日用户授予权限，完成专用清单合成项创建、外部改名/完成回读及退出重开；结果见[实测报告](api-reminders-validation-2026-10-10.md)。它是技术探针，不是 VoiceOS 业务应用。

## 操作范围

系统完整权限覆盖所有提醒事项，程序自身只读取可写清单名称，随后只在用户选定的测试清单内查询和写入一个合成项。Apple 没有清单级的系统权限；查询必须显式传入所选清单，不能用 `nil` 查询所有内容。[Apple 清单谓词接口](https://developer.apple.com/documentation/eventkit/ekeventstore/predicateforreminders(in:))。

合成项不含到期日期、提醒或邀请；程序不修改或删除已有任务。使用 notes 中的操作标记核对，不靠标题去重；这是验证方法提案，不保证标记在所有同步、编辑和设备上稳定。真实适配器必须进一步验证内部/外部 ID 映射。

## 复现

```sh
python3 scripts/probes/build-reminders-probe.py
open tmp/research/VoiceOSRemindersProbe.app
```

构建脚本只编译、打包与签名校验，不启动程序。当前目标为本机 arm64/macOS 26；应用包在被 Git 忽略的 `tmp/research/`。生产分发、沙盒 entitlement、签名与公证均未验证。

1. 在 Apple 提醒事项新建一个空白测试清单，建议命名“VoiceOS 验证”。程序不会自动创建或猜测清单。
2. 打开探针，点击“请求系统权限并载入清单名称”，在系统弹窗授权；拒绝时应显示未授予且没有读写。
3. 选择测试清单，点击一次合成创建，随后回读。记录唯一标记匹配、标题与完成状态；不要把其他清单作为试验对象。
4. 在 Apple 提醒事项手动完成合成项，再回读；另改标题后回读。外部编辑后的值应保留。
5. 退出重开，重新载入权限与清单；程序只回读原操作，不自动再创建。可再测试权限撤销、合成项删除后的未知状态。
6. 测试结束，可在提醒事项手动删除合成项或测试清单。探针不自动清理。

## 待核实与结果记录

首轮构建仅验证编译。本轮已运行正常权限路径及一条真实合成项；用户选择允许，未测试拒绝/撤销。公共结果只保留测试清单与合成项，不把个人清单/任务导入仓库。

当前探针采用 UserDefaults 保存操作标记、测试清单 ID 和尝试标记，用于普通退出重开。它没有证明硬中断时的同步落盘保证，不能用来证明生产幂等；生产操作状态需采用可验证的持久化机制。探针查询会临时接触所选清单中的全部提醒事项再过滤，因此必须用空白合成清单。

“回读零条”只能记为未知，可能是同步延迟、删除或标记被编辑，不自动重建；多条则记为歧义。后续还需验证超时、杀进程窗口、iCloud 延迟、断网、双进程并发及不同清单/来源的行为。

记录模板：运行日期、系统/探针版本、权限路径、测试清单是否为空、写入返回、标记匹配数、完成/编辑回读、重开/撤销/删除结果、同步等待时间、失败原因。已有正常路径的有限真实结果；未执行的场景不填写“通过”。
