# 首轮 GPT 文本质量测试方案

日期：2026-10-10。状态：用户 P05 授权先选方案测试；方案和十条合成样本已准备，API 尚未执行。不是生产模型选型或月度预算确认。

## 1. 试验选择

主比较模型为 `gpt-6.1-sol` 与 `gpt-6-luna`，使用 Responses、Standard、`reasoning.effort=low`。前者作为复杂理解的起点，后者比较降本效果；两者是否适合 VoiceOS 以本项目结果决定。模型 ID、支持能力和价格已按官方资料核对，不用产品宣传代替质量证据。[Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol)、[Luna](https://developers.openai.com/api/docs/models/gpt-6-luna)、[模型目录](https://developers.openai.com/api/docs/models)。

仅使用[十条人工编写的合成文本](cognitive-evaluation-cases.json)，每模型每样本一次，共最多 20 次请求；不使用音频、不调用外部操作工具、不联网搜索、不读取个人历史。把样本的 `input`、必要的 `history`、固定参考日期和来源类型提供给模型，`expected` 与 `critical_error` 仅供评分，不放进请求。

请求采用 `store=false`，不依赖云端会话记录；它不等于零数据保留，保留条件仍以实际服务和账户配置为准。仅本地来源的真实请求拦截另测，不能用本次文本试验宣称其已经实现。

## 2. 费用与执行边界

本次选择每请求输入上限 4000 tokens、输出上限 2048 tokens；构造实际请求后先计量输入，不满足上限就不发送。20 次请求不自动重试，错误与未完成输出也作为结果保存；不因服务不可用擅自切换代理。此为小规模工程试验配置，不作为用户的产品录音长度或等待目标。

2026-10-10 官方 Standard 短上下文每百万 tokens：Sol 输入 $2、输出 $10；Luna 输入 $0.10、输出 $0.50。用较高的 cache-write 费率 $2.50/$0.125 覆盖全部输入，并按每请求输入 4000、输出 2048 计算，20 次生成费用预算约 $0.321。执行前复核价格和计量，预算封顶 $1；这是工程选择，不是用户已确认的月度预算。金额为美元，不包含代理加价、税费或人民币换算。[官方定价](https://developers.openai.com/api/docs/pricing)。

当前仅检查了本进程环境是否具备配置：`OPENAI_API_KEY` 和 `OPENAI_BASE_URL` 均未设置；工作区尚无已知服务配置。没有查找其他应用凭据，也没有请求 API。接下来需要将官方 API 凭据配置到本地运行环境；密钥不写进 Git、不贴在聊天中。若使用兼容服务，应先说明服务端点，再核对模型、数据保留和价格，不能沿用官方价格假设。

## 3. 提示与结果契约

使用一份简短任务提示：忠实提取表达；区分用户立场、外部材料、AI 候选；保留否定、条件和来源；识别有承诺的行动以及权限边界；纠错时指出受影响的引用；只提出结构化结果，不执行外部操作。

统一结果字段：`claims`（内容、归属、证据状态、来源 ID）、`questions`、`actions`（意图、建议动作、授权依据、需核对信息）、`relations`（关联及依据）、`corrections`（旧 ID、原因、依赖影响）、`english_feedback`。模型输出是待验证提案，不能等同业务数据写入。具体 JSON Schema 与请求格式在接入试验时按官方接口核对，不冻结生产数据模型。

每次保留：样本 ID、提示与参数版本、返回模型 ID、请求起止时间、完成/错误状态、输入/缓存/缓存写入/输出 usage、费用估算、原始模型输出和评分。推理耗时包含在完成时延中；不能只记录首 token 时间。原始错误必须去除凭据与敏感请求头。

## 4. 判定方法

由工程协作者逐项按样本的 expected 和 critical_error 审查，保留判定理由；JSON 合法不等于语义正确。分别统计否定/条件、归属、认知确认、意图、纠错、历史关联和英语反馈。任何关键语义错误均列为阻塞对应路由的失败，不用平均分抵消。

十条样本只用于找明显失败和估算单次费用，不能推导生产 ≥95% 完成率。人工参考答案也需要审查；跨模型一致不代表正确。首轮报告给出每模型完成率、关键错误清单、时延分布、实际 token 与费用，并说明有限样本的局限。

后续依据结果扩展：更长授权历史、正负关联对照、含噪真实转写文本、重复运行稳定性和用户实际使用。再协商月预算、典型长度与体验门槛，不要求用户现在猜数字。
