# VoiceOS 详细测试计划 v0.1

日期：2026-10-10。状态：测试设计草稿，产品软件尚未实现，22 个 AC 全部未执行。依据：[验收对照表](acceptance-matrix.md)、[PRD](../product/prd.md)、[状态机](../architecture/state-machines.md)、[数据模型](../architecture/data-model.md)。配套：[路线图](../planning/implementation-roadmap.md)、[夹具目录](fixture-catalog.md)、[报告模板](test-report-template.md)。

## 1. 范围与执行原则

覆盖全部 31 个需求、三个愿景闭环以及保存/处理/同步/权限/纠错/迁移。思源可选不纳入必过连接；任意应用操作、实时全双工、发音评分、实时多设备同步不纳入首版通过承诺。

优先测试会破坏产品承诺的行为。内部判定可自动化，语义/交互与真实外部效果人工复核；不写只重复实现表达式的测试，不用模型互相打分代替出处判断。测试挂钩只用于测试构建，产品流不暴露内部故障控制。

历史探针报告保留其版本和有限结论，不迁移为 AC 的通过状态。测试程序跑完、请求 200、JSON 根字段齐全、界面临时显示变更都不等于链路验收；外部编辑要提交并独立回读。

## 2. 环境与证据层级

| 层级 | 环境与用途 | 能证明 | 不能代替 |
|---|---|---|---|
| L0 离线 Core | 临时库/受管资产、可注入时钟、受控适配器；无网络/外部写 | schema/约束、CAS、去重、权限/冻结/删除阻断与恢复规则 | 真实容器/OS 权限/模型质量/EventKit 行为 |
| L1 本机真实能力 | 原生测试构建、真实麦克风/录制视频/转写资源、真实退出/睡眠 | 声明环境下的录制、保存范围、资源等待与生命周期 | 其他 OS/硬件、硬件断电、云服务质量 |
| L2 真实接口 | 固定 bundle 身份、专用清单/合成项、受限模型请求 | 实际调用/回读、服务错误、有限语义与上传字节 | 完整应用恢复和所有输入泛化 |
| L3 产品端到端 | 指定产品 commit/build，从录制界面到历史与真实提醒事项 | AC 行为、完整 A/B/C、界面与内部记录一致 | 四周自然复用和长期负担 |
| L4 自然试用 | 首位个人用户自愿按生活/学习使用 | 自然闭环、找回旧思考、注意力/成本/纠错负担 | 受控故障覆盖或统计充分性 |

每次记录 Mac/OS/架构/SDK、应用身份/签名、转写资源、schema/模型/提示/配置版本、语言/时区、网络和授权。当前本机证据仅支持已测环境；最低 OS 待 W01。冻结支持列表后，对最低支持环境和日常主环境分别跑关键路径；没有对应机器/虚拟环境证据就标未验证。

权限试验使用 VoiceOS 测试应用身份，拒绝/撤销只作用于它。Core 时钟注入用于日期边界/租约，不改变系统时间；真实睡眠测试明确是睡眠/退出/强制终止哪种条件，不改用户全局电源配置。磁盘失败用测试卷/配额或写入适配器模拟，不把用户磁盘填满。

公开证据只含合成输入或必要脱敏元数据；真实媒体在忽略目录。凭据不进入请求日志、截图或报告。权限已明确的普通测试不逐条重复审批；原始音频云端选择和重要外部动作仍按实际授权执行。

## 3. 夹具、配置和判定责任

输入来自夹具目录：SEM-01–10、CH-01–10、EN-01–04、RT-01–06、PX-01–04、E2E-A/B/C。每次使用锁定版本与 hash，参考答案不得发给模型；录音与逐字参考单独保存，样本状态明确 planned/materialized/executed。

初始测试配置建议分为：默认（文本/授权历史可云处理、音频未选择、认知通知关闭、实际专用清单的普通持续授权）；only-local；外部权限拒绝/撤销；重要变更未授权/已具体授权；通知开启/暂停/关闭。配置是测试变体，不增加产品默认授权。

自动判定负责文件摘要/容器、对象/版本/关系约束、状态/次数、实际发出请求类别/字段、日志脱敏、导出恢复一致性。人工判定负责否定/条件/归属/承诺、关系依据、英文建议与交互负担。模型可提出审查线索但不是唯一裁判；有争议项保留原文与标注为 unresolved，不算通过。工程协作者维护执行记录，用户只在需要产品方向或真实使用体验判断时参与。

## 6. AI 质量与检索测量

先用固定合成文本隔离认知，再用真实/合成音频分别评价转写→理解；相同原文对照提示/模型版本。现有首轮方案最多 20 次且无自动重试，但第三方费用/保留未知时保持调查暂停状态，不能沿用官方 $1 估算做实际封顶。继续前核对实际服务价格、硬限制/调用批次和 unknown 费用；不因本计划而发新请求。

原始输出、完整 schema 校验、版本引用校验与语义判定分别记。每条关键语义项评 pass/fail/unresolved，附原句/输出片段和理由；任何反转否定、错归属、凭空行动/期限、忽略冻结或越权操作阻断对应路由，不由平均分抵消。语义失败与服务失败各有分母；没有结果的超时不评分为正确，也不从完成率分母移除。

检索先检查正确历史是否召回，再检查选入上下文，再判定最终关系；用 RT-01–06，相关位置轮换，记录 recall@实际候选数、负例误关联、引用有效性与冻结泄漏次数。初始规模 10/100/1000 是成本可控取样，未验证不能承诺容量；没有金标准的真实表达人工说明判断，不混进已有标注准确率。

开发集用于发现/修复；进入路由采用审查前补未见改写/组合回归集，并在同配置下至少两轮观察非确定性，按批次控费，不承诺两轮充分。十条 SEM 只筛明显失败，不代表 ≥95% 生产处理可靠性；小样本时分布报原始值/范围，不用少量样本的 p95 表述稳定 SLA。

| 意图/时间 | 明确任务漏建数÷明确任务样本；愿望误建数÷机会样本；明确/弹性期限错误分别计 | 关键凭空行动/承诺错误阻断对应路径；其他数值阈值待测 |
| 忠实/归属 | 逐项否定/条件/引用/归属正确数÷已标注且有输出项，另报无输出/未决数 | 必需回归不允许关键语义错误；不宣称无限输入零错误 |
| 历史关联 | 标注正/负例、实际候选数、漏检/误联/无依据/冻结泄漏分开 | 冻结内容可信使用与捏造来源阻断；召回/误联阈值待 H07 |
| 外部结果 | 每逻辑操作外部匹配数、unknown 时长/次数、人工编辑被覆盖数；回读确认比例 | 重复创建/越权/重要期限覆盖阻断；不能以 HTTP/API 返回替代事实 |
| 费用与时延 | 从捕获结束到保存/理解/回流分阶段；工作耗时与睡眠/离线/权限等待分开；计费实际/估算/unknown 分列 | 月预算/体验 SLA 待 P05；官方估算不替代第三方账单 |
| 注意力/迁移 | 默认认知通知数、重复触达、被迫回复；恢复前后 ID/版本/关系/限制/媒体一致性 | 默认零认知通知/零回应债务；必需恢复/删除用例通过，缺媒体如实显示 |

数值目标未冻结时可报告测量、内部候选的有限表现，不能宣布达到正式可靠性目标。不要把不可用格式在失败后改成“无效输入”来提高分数；支持列表、有效样本和观察窗口在测试开始前锁定。

M1–M4 按路线图的相应案例退出，另跑受改动影响的故障/权限回归。M5：全部 22 个 AC 必要变体均通过或明确未完成；未完成不得宣布完整 MVP 验收。越权、已保存原件丢失、重复外部创建、重要手工期限覆盖、冻结/删除内容继续使用、不可恢复迁移、默认认知通知打扰属于阻断问题；优先修复再重跑受影响链。

模型/提示/路由/来源选择变更重跑相关语义与发送边界；schema/资产/删除变更重跑恢复迁移；执行/授权变更重跑外部 unknown/冲突；只改低风险文案检查呈现，不机械跑全套付费试验。正式候选全套验收保存 build/报告，之后有新变化才按影响重跑。

## 8. 自然试用

受控 A/B/C 与必需恢复/权限/数据控制通过后，开展约四周自然使用，作为建议观察周期而非强制每日打卡。提前公开支持范围、模型服务/费用限制、仅本地和音频选择、数据恢复及退出方式；依旧保持普通操作自主和非紧急静默。

记录自然形成的跨时间链：两次真实表达或表达→行动→结果→新表达，原记录 ID/日期、找回方式、认知是否有依据变化、实际帮助/误判/纠错耗时。至少三条有意义闭环是愿景拟定起点，不能提前编脚本凑自然样本；受控案例单列，不计自然成功数。没有自然机会则如实未观测，不要求用户制造任务。

可在用户愿意反馈时问是否帮助找回/理解、是否打扰、是否需要频繁确认、是否信任执行；不要求每日填写评分。成本与负担超预期、关键错误出现时暂停对应能力并修复；发现产品方向冲突单列确认。试用结束报告分成功、失败、未观测及范围限制，不将试用时间到期当通过。
