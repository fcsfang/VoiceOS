## 3. 后续文档的写法

- PRD：目标用户、场景、MVP 与延期范围、正常和异常行为、权限、纠错、非功能要求、验收、待定项；避免把具体数据库和模型写成产品需求。
- 架构：录制入口、处理编排、GPT 认知、记忆检索、行动规划、第三方适配、反馈控制和控制中心的责任与契约；模块名称先不等于独立服务。
- 数据模型：Thought Event、Source、Transcript、Claim、Question、Goal、Project、Task、Outcome、Relation、Revision，及权限、处理任务、外部映射等支撑概念；归属、证据、执行状态独立。
- 实施路线图：按纵向闭环切片推进，先可追溯表达，再行动连接，再结果回流，随后完善历史复用、对话和恢复；每个切片都包含必要的可靠性。
- 测试计划：三个端到端案例、语义回归、授权边界、故障注入、同步冲突、纠错、导出恢复和注意力保护。AI 测试保留输入、模型及提示版本、期望边界和人工判定依据。

## 4. 重大技术决策

已建立 [ADR 索引](../adr/README.md)及六项 proposed 草案，每份包含问题、约束、备选、推荐、取舍、验证证据、采用条件和退出路径。覆盖应用宿主、存储检索、持久编排、提醒事项、GPT/转写及备份迁移。未来跨设备同步另立方案。

目前推荐单 Mac 原生宿主 + Swift Core/SwiftUI + SQLite/独立媒体 + 持久 jobs；这些是待验证的工程建议，不是既定产品答案。部署可以开放演进，但必须满足首版允许休眠暂停及可靠续作的体验。
