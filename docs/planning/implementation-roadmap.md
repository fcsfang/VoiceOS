# VoiceOS 实施路线图 v0.1

日期：2026-10-10。状态：可审查实施计划；第五文档阶段交付，工程 M0 验证与 M1 文件输入子集已推进，里程碑均未整体完成。依据：[PRD](../product/prd.md)、[架构](../architecture/system-architecture.md)、[数据模型](../architecture/data-model.md)、[状态机](../architecture/state-machines.md)、[ADR](../adr/README.md)。配套：[详细测试计划](../testing/test-plan.md)。

## 1. 推进方法与当前基线

按 M0–M5 六个工程里程碑推进；它们不同于项目计划的五个文档阶段。每项工作编号 W，需求编号 PRD，验收编号 AC；三者映射在下文维护。全部工程里程碑当前未完成。日期不作为通过条件，不在服务/录制边界未知时编造工期。

第一条交付重点是案例 A 的真实认知—行动—反馈闭环。M1/M2 是其可展示中间切片，不能宣传为已完成 MVP；M3 通过案例 A 也不能删除案例 B/C、基本对话、纠错和数据控制。M5 才审查完整首版范围。

当前已有[M1 原生输入开发预览](../engineering/m1-file-input.md)，合成/真实媒体恢复证据、一条真实提醒事项探针正常路径及一次成功模型生成。第三方网关另有超时/503，英语、真实录制/睡眠、跨时间检索和同步竞态未验证。[实测](../research/api-reminders-validation-2026-10-10.md)与[架构审查](../architecture/review.md)是证据边界；不把探针直接重命名为产品功能。

推荐单 Mac 宿主/可复用 Core，但六项 ADR 仍 proposed。每个里程碑只冻结实际需要且有证据的部分；尚未进入的技术选择可保留待定。重大方向变化回到产品审查，普通可逆工程选择按已有授权自主推进。

| M3 案例 A 真实闭环 | M2；W03/04 验证；W13–16 | 录入猜想/阅读任务 → 真实创建/回读 → 外部完成 → 再次口述限定 → 新旧历史双向回溯 | AC-09/10、AC-14 外部窗口、AC-15/16/17/18 对应路径通过；完成不验证观点，丢回执不重复创建，重要冲突/补偿不静默覆盖；附一条完整产品证据链 |
| M4 首版体验覆盖 | M3；W17–20 | 案例 B 静默关联/用户进入 B；案例 C 两次英语练习；可忽略反馈、通知开关/暂停 | AC-11/12/19/20 通过；B 仅用户开启；跨措辞正例及同词负例；英文来源/建议分开；无发音伪评分；无思源仍独立可用 |
| M5 完整首版候选与自然试用 | M4；W21–24，全部关键验证关闭或有不违背 PRD 的已审查处理 | 导出/空库恢复/删除、全链恢复与权限审查；可安装的内部试用版本 | 22 个 AC 均有产品版本证据；三条闭环通过；关键失败无未解决阻断；声明支持列表及测量指标；按测试计划开展自然试用后另行评审，不把内部发布等同长期效果已验证 |

M0 的工作可在 M1 的离线保存开发期间继续；模型服务不稳阻止 M2 认知验收，不阻止原件保存和恢复开发。外部同步失败阻止 M3，不得以本地假勾选替代真实回流。质量/保留政策不足时只用已授权合成测试，不能靠扩大个人上传补样本。

## 5. 风险、取舍与阻断规则

| 风险 | 当前证据 | 处理与退出路径 |
|---|---|---|
| GPT 网关不稳/实际价格未知 | 6 次尝试中 3 次成功，503/超时仍存在；官方价格不是账单 | W02 先关闭服务调查，保留错误和未知费用；可推进离线 M1；不盲重试、不假定网关适合生产，换服务更新 ADR-005/语义回归 |
| 录制容器/睡眠丢失 | 合成文件/字节不证明真实录制 | W01/W06/W07 在独立测试目录与真实容器故障验证；失败重选封存路径，不降低“已保存”承诺 |
| 源限制绕过/晚到输出 | 尚无产品发送层 | W05 屏障，W10/W13 发送前重验；修复前停对应上传/外写，不能靠提示要求模型自律 |
| 检索同词误联/忽略长历史 | 未做 H07 实测 | W03 小实验，W15/18 按正负例/出处评分；可重建投影，不把固定 Top-K 当充分上下文 |
| 外部标记编辑、丢回执/竞态 | 正常单项路径完成，故障未测 | W04/W13/14 按 FI 验证；unknown 先核对；不承诺外部 exactly-once，不静默覆盖重要字段 |
| 升级/删除/备份不一致 | 合成 schema/包已测，正式 schema 未有 | W05 设计快照/删除屏障，W21/22 真 schema 验证，失败保留现库；B → C 使用导出契约 |
| 通知负担/指标虚高 | 默认静默已确认，预算未定 | W20 试验参数，W24 区分人工准备与自然链；≥95%/四周/三条闭环为待校准目标，不凑任务或强迫打卡 |

工程退出采用“完成 / 部分完成 / 阻塞”的证据判断，不以文档数量或平均分抵消关键错误。越权发送、已保存原件丢失、重复外部创建、旧错误继续驱动动作等阻断对应发布；具体规则见测试计划。

## 6. 紧接本轮的工作

先推进 **M0 的 W01：稳定宿主与真实录制保存/恢复验证**，并将网关调查/中英样本和检索实验安排到 W02/W03。优先取得真实容器和生命周期证据，再审查 ADR-001/002/003 在 M1 所需的部分，建立最小录制/导入→可靠保存→可找回切片。
