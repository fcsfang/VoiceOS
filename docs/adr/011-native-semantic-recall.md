# ADR-011：Mac 原生中文语义召回

日期：2026-10-11。状态：accepted，采用范围限开发预览；完整 M4、模型分发和自然历史验收尚未完成。

采用已完成合成比较的 `BAAI/bge-small-zh-v1.5` 固定 revision `7999e1d3359715c523056ef9478215996d62a620`，转换为 CoreML ML Program，保留 float32，首版固定 CPU 推理。Python 只用于离线构建，不进入应用运行依赖。模型、词表、转换身份和编译产物摘要跟随应用资源，由构建显式加入；应用不下载资源，也不改走云端召回。

备选：系统句向量无额外资产，但前阶段质量已不足；Python 子进程可直接复用研究代码，但环境与版本维护负担更大；ONNX 需增加原生库与包装依赖，后续跨平台时可再评估；CoreML 的代价是转换与原生分词需要独立验证，且暂限 Mac。首次转换在 Python 3.14 环境失败，改用独立 Python 3.12 + torch 2.7.0/coremltools 9.0 开发环境通过，不影响应用运行。

六个特殊字符/长文样例的 Swift 分词 ID 与原分词器一致，原生向量与原模型余弦均大于 0.99999。两组本地样例的标注原文全部进入前八；千条模板容量库也保留全部标注目标。原生匹配分数与研究输出的最大差异约 5.3e-7；弱候选的同分填充文字会因来源身份改变顺序，不能宣称所有排序完全相同。

语义窗口 256 Unicode 标量、96 重叠；关键词保留既有 800/512 窗口。完整扫描支持范围后按来源去重，语义显示八个候选。单次最多一万片段，超出明确报错，不截去旧历史。词元超过 512 拒绝，不截断查询。既有来源、文字版本与权限屏障复用，未增加权威数据表或迁移格式。

固定 0.57 门槛会漏掉已有相关原文，因此不用绝对分数作为候选过滤。取相对排序候选，再由独立、已授权的相关性判断筛选，仍允许空结果。候选不是关联、观点或事实结论，界面明确标为待核对。完整生产上下文有独立预算，不把 top8 自动当成充分上下文。

投影只在内存，按文字摘要复用向量，固定模型实例，最多一万条缓存；查询结束清除不在当前输入中的投影。取消时也限制增长。更正、损坏和权限变化后的真实出处由核心重新校验。关闭/重开会重建，不作为唯一历史或导出内容。未来持久投影需新增单独的版本、清理与重建决策。

资产摘要检查用于本地完整性，并不替代正式分发签名。当前为本机开发签名，正式签名/更新/跨平台模型尚待对应阶段。详见[实施及证据](../engineering/m4-native-semantic-recall.md)。
