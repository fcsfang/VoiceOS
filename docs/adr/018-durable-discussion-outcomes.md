# ADR-018：结束后混合成果的持久单次提取

状态：partially_adopted；持久端口、原子回流与历史界面切片已验证，真实模型驱动未接入。日期：2026-10-11。

首切片只对已明确结束且依据有效的讨论进行一次完整成果提取；进行中仍可用既有个人单轮整理和AI段落保留。关闭讨论不调用模型或认可观点，成果提取另行明确执行。以conversation ID防重，改变端口/模型或准备命令也不能重发未知请求。

理由与备选：进行中按范围指纹可多次总结，但需要额外控制重复观点、在途最后回复和不同范围覆盖；用完整结束范围先验证角色与引用准确性，简化恢复及迁移的可证明边界。不是撤销实时逐轮愿景；后续可按质量证据扩展增量提取。

既有model_attempts保存真实请求与用量，独立conversation_outcome_attempts保存完整角色快照与双重出处结果。候选和个人明确行动复用既有原子提交；完整成果结果与候选同事务落库。模型端口不执行工具、重试或原始音频处理。AI行动提议保留为AI候选及结构化建议元数据，首切片不凭AI引文自动创建个人任务；个人跨轮意图留机会，完整个人普通任务沿用P01。必要的来源锚点不宣称证明AI猜想。

全部输入/权限发送前和接纳前重验；未知保留且不重发；来源更正/撤销冻结全部依赖。迁移保留实际来源、AI调用/段落、结果和候选关系并冻结，不恢复外写权限。恢复校验整段角色目录、最后回复、原文和AI引文、扁平候选结果与提交摘要，不只信任文件hash。

退出门槛：正常原子混合结果、AI/个人归属、完整输入和晚到屏障、未知防重、三处实际强退、篡改拒绝、新包与旧包恢复；真实驱动与界面后续独立验证，不能由fixture宣称完整AC-11。


首切片身份边界：整段提取之前，任一个人回合的同一原文版本已有理解尝试，或会话已有独立AI段落候选，则发送前拒绝；等待期间再检查。反向的个人单轮整理也拒绝已被整段尝试覆盖的相同个人版本。这样保留原候选、审阅与行动身份，但暂时限制两个入口组合使用，不是永久产品规则。整段结果已包含的完全相同AI原段落可直接返回原候选，拒绝/认可状态不重置。后续应在完整输入之外明确新增成果目标及已有结果关联，不能凭语义相似度合并个人任务，也不能以省略历史来防重。

验证：226项测试通过；三处真实进程强退、12次既有会话/回复/候选强退回归、四个新格式迁移往返、实际旧v1–v16恢复、含语义资源签名构建与原生历史/原文/AI出处/原候选返回通过。合成完成反馈迁移保留完整身份链，任务完成不验证观点。本切片0云端调用、0录音、0外部写。详情见[实施记录](../engineering/m4-durable-discussion-outcomes.md)。

2026-10-11更新：显式`prepareReusableConversationOutcome`已接入持久原身份目录，新个人目标与已有结果分开，不复制候选/任务；旧无目录路径继续首切片隔离。244项测试、三个新强退位置、三个迁移往返与原生UI通过，真实驱动未接入，见[复用实施](../engineering/m4-discussion-outcome-reuse.md)。
