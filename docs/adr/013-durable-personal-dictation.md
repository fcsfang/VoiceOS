# ADR-013：显式个人口述与原件封存

日期：2026-10-11。状态：partially_adopted。无麦克风工程验证完成，真实设备/权限和睡眠仍待验证。

用户主动点击“开始我的口述”才请求麦克风权限；此入口声明录制本人表达，第三方节目继续走外部资料导入，引用他人不因此成为用户立场。录制与音频不自动获得云端授权，也不触发文本模型或任务写入。

采用AVAudioRecorder写24kHz单声道16bit PCM CAF，平台只负责设备和结束回调，核心负责身份、完整解码、摘要、封存和队列。备选AVAudioEngine适于后续实时/多轨，但首版增加采样缓冲、溢出和容器收尾负担；暂存后普通导入实现简单但录制中没有持久来源身份，故不采用。

在设备开始前持久化来源/原件/输入版本身份，`microphone-v1:<sourceID>`标识捕获协议；bytes0/零摘要只表示未封存，不能成为可用原件。暂存写入staging，设备正常结束回调后同步、完整解码及两次摘要核对，再复用sealed/renamed/saved事务和本地转写队列。同一宿主最多一个设备录制，资料库最多一个未结束口述。

启动时未封存片段只转interrupted并保留，不自动视为完整表达；用户可明确核对并保存可解码片段。编码错误、权限拒绝、未获结束回调或休眠不声称成功。正常退出/休眠停止设备；下次启动核对身份，未封存保留待查。回调缺失五秒后报未正常结束，不隐式续录或重新请求。

字段未增加，但个人音频身份和未封存记录语义改变，升级schema14/包v13，使旧读者明确拒绝。恢复校验口述身份，未封存记录不虚构资产/任务；结构化包不带暂存音频并明确提示，带原件导出遇未封存片段会拒绝，避免静默遗漏。已有已封存录音按P06可选打包。

真实录音测试需要具体采集授权；六次强退与合成CAF测试不能替代设备、权限拒绝、自然表达质量或真实睡眠。见[实施记录](../engineering/m1-personal-dictation.md)。
