# ADR-021 表达关联持久身份

2026-10-11；状态 partially_adopted。采用范围为独立快照、持久尝试和迁移，自动触发/卡片/自然质量仍未完成。

问题：手动相关性调用没有完整当前表达锚点，随机查询身份允许重复发送；不能作为自动静默关联的执行身份。

选择独立 expression_association_attempts 表，复用本地上下文、召回、权限和反馈偏好。备选是扩展 relevance_attempts，但会改变手动查询与旧包语义；另一个备选是存入 claims，会把关联提案错误混入观点归属及行动生产者。独立表增加迁移和校验成本，换取清晰的数据身份。

派发键锁定当前来源/来源版本/逐字稿版本/权限版本及模型、提示、Schema和目的地；完整快照摘要另锁定所有候选与偏好。候选刷新、偏好切换和新预览UUID不能造成隐式重发。代价是同一表达不能仅因新历史自动再次判断；显式重新判断机制以后单独设计。

同步预留后才await端口，重复在途请求拒绝；端口失败或晚到撤权/纠错/暂停/取消成为unknown并保留已知用量。返回后原子提交结果和用量。崩溃恢复unknown，不自动重发。历史读取冻结失效记录，迁移历史一律冻结；不创建认知候选、行动或通知。

schema20→21增加独立表；v20包携带记录，旧v1–v19按原版本表读取。恢复校验当前及全部历史原话、授权历史、上下文、偏好、配置、结果和用量，失败不留下部分恢复目录。可迁移历史不等于继续外发许可。

证据：290项测试、三处真实SIGKILL、三次包往返及含语义资源的签名构建。详见[契约](../engineering/m4-expression-association-contract.md)。只有合成离线证据，未验收自然质量或完整W18。
