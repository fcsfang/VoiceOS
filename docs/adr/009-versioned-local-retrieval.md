# ADR-009：带版本出处的本地检索

日期：2026-10-10。状态：partially_adopted。关联 ADR-002、PRD-MEM-02、PRD-COR-02、AC-12/17。采用范围是文字检索和出处屏障；跨措辞关联仍待质量验收。

## 约束与备选

检索必须返回可核对的来源片段，不能把旧更正稿、冻结模型解释或无依据的相似度当成当前立场。仅本地来源可以在本机找回，但不能因此获得云端发送授权。

| 备选 | 收益 | 取舍与当前证据 |
|---|---|---|
| 原文连续文字匹配 | 易核对、无模型依赖、可立即提供出处 | 跨措辞漏检；采用为当前界面入口 |
| 系统 NLEmbedding 中文句向量 | 本机资源已可用、640 维，无新增下载 | 1000 条样本误召回多，正例第 91 位，条件细化漏检；只保留工程实验，不进入日常界面 |
| 系统 NLContextualEmbedding + token 均值池化 | 已有本机资产、512 维，无新增下载 | 两个正例在厨房干扰中第 1 位；10-11 扩大到 24 个主题后目标第 20 位，无关分数重叠；不采用为产品语义方法 |
| 独立本地中文向量/多语言重排 | 可替换、可针对检索任务评估 | 10-11 已研究 BGE-small-zh + BGE-reranker-base，保留组返回精确率改善但相关记录覆盖仅 50%；约 1.23 GB 资产，未增加应用依赖或采用 |
| 本地召回 + 云端相关性判定 | 可明确选择为空，减少主题相近误回 | 10-11 单次合成测试两组返回精确率 100%，相关记录召回率 82%/90%；需独立样本、来源授权闭包和晚到结果屏障；尚未发送任何私人历史用于检索或接入产品 |

## 当前采用

核心读取 saved/reference_only 来源的当前逐字稿；不索引旧版本或派生候选。saved 原件先重新校验，损坏来源隔离并不参与检索。每个摘录带来源 ID、来源版本、文字版本、权限版本、片段 ID 和 Unicode 标量范围；结果返回后与打开时都重验。用户文字保留其原文身份，外部/未知说话人不升级为用户观点。

按已有来源片段分成至多 800 标量、512 标量重叠的检索片段，以保留连续查询的边界上下文。单次最多一万片段，超出报错而不是只扫描最近历史。查询最多 512 标量。单次扫描完整支持范围，再按来源去重并返回至多 20 份；界面显示扫描/匹配/显示数量。结果数量不是模型上下文预算，不能直接视为“已选入充分上下文”。

`LocalRetrievalPort` 是明确本地处理契约，不持有网络配置。系统向量实验采用 actor 串行处理，临时缓存最多 4096 份文字摘要对应的向量；缓存不是唯一历史，不写入 SQLite 或迁移包。依赖实例和模型版本固定，销毁即可重建。当前检索不改变存储 schema 11/包 v10。

晚到查询若匹配记录已更正或权限变化，整次结果拒绝；取消后丢弃晚到结果。界面换查询、关闭或受影响资料刷新时清理结果。端口返回重复/未知片段、非有限分数或未知方法均拒绝；端口只能提供排名，不能自行编造摘录。

不自动建立支持/矛盾/修正关系，不改变观点认可或证据状态，不创建任务、发通知或开启讨论。后续云端重排必须走独立的来源授权与发送前/返回后重验，不能把本机命中转换为上传许可。

## 验证及不足

93 项测试通过，其中 11 项新增检索测试涵盖出处、纠错、权限变化、晚到/取消、非法提案、Unicode 边界、损坏隔离、无原件迁移后查找和原生距离尺度核对。10/100/1000 合成历史对比与实际界面证据见 [检索基础记录](../engineering/m4-local-retrieval.md)。

系统句向量的向量余弦距离与其 `distance` 接口尺度不同，最初实验错误沿用阈值造成全量误召回，已纠正为归一化 L2 并用系统接口独立校验；修正后仍有实际质量不足，不能靠修改阈值宣称已验收。上下文池化探针的正例排名改善也不能替代完整关系判定、长期使用和不同主题负例。

下一步在同一版本/权限边界上比较上下文模型和重排，补充独立主题、否定/条件与无相关历史的样本，再决定语义入口。产品愿景和验收要求未降低。
