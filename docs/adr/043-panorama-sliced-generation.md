# 043 全景单元分片生成

- 状态：已采纳
- 日期：2026-11-01
- 相关：issue #55、PR #46、PR #53、`work/tasks/20261101-panorama-slicing`

## 背景

真实资料库的 25 个全景单元里，CE3C1904（单来源 26,868 字符加一个 32 字符依赖）从未完成 `unit.generate`。2026-10-31 的 9 次真实尝试中，只有一次在 8 分 43 秒内返回完整提案（45,844 字节），随后因引文定位失败被丢弃；其余八次都在 601/601/603 秒被服务端切断流。ED362352（33,033 字符）完成过一次，回执为 41,837 输入 token、54,363 输出 token、9 分 53 秒。服务端拒绝 `store` 与 `previous_response_id`，background 模式不可用；非流式长请求历史上也在约 15 分钟以 `upstream_error` 结束。

2026-11-01 的只读探针确认了时间花在哪：同一段 26,868 字符全文，只要求输出 3 个问题时，全文输入总耗时 22.0 秒（17,855 输入 token、1,134 输出 token）；同样全文加“只覆盖前 6,000 字符”的聚焦提示耗时 25.0 秒；只送 6,000 字符窗口耗时 19.6 秒。读全文不是瓶颈，600 秒墙由单次响应要生成的提案体量造成。

## 决策

对超过单请求预算的单元，把生成拆成若干聚焦请求，每个请求仍携带完整单元原文，只把本次可引用与可覆盖的内容限制在一个确定性的范围里；再把分片结果机械合并为一个单元提案。

- 阈值 16,000 全文 scalar：全库仅 CE3C1904（26,900）与 ED362352（33,033）超过，其余 23 个最大 7,184，请求与既有回执完全不变。
- 片大小 8,000 scalar，边界取转录 span 端点，单个超长 span 才在字符安全边界内切开。CE3C1904 切 4 到 5 片，ED362352 切 4 到 5 片；小依赖并入相邻片。
- 聚焦请求携带完整 `PanoramaInput`、本片 `focus`（全文 Unicode scalar 坐标）与 `target`（本片可覆盖的 sourceID/claimID）。证据偏移始终是全文坐标，不做窗口平移。
- 每片证据必须完全落在本片 focus 内，违反按一次重试处理；本地先用按 target 收窄 manifest 的 `validatePanorama` 校验，合并后再对完整单元校验一次。
- 合并是纯函数：分片提案的 region/question/relation ID 加 `part[n]/` 前缀，覆盖清单按完整 manifest 重算补集，原因优先取分片给出的非空原因，否则用固定原因。跨片联系留给 `global.synthesize`。
- 保留一个 canonical `unit.generate` 行，输入是自描述的切片记录（策略、计划摘要、完整输入），结果是合并提案，回执是组合回执：`responseID` 为 `panorama-slices-v1:...`，`sourceResponseIDs` 列出每片的真实回执，`generationIdentity` 记录生成身份。
- 聚焦生成使用独立身份后缀 `|unit-slices-v1`；单请求身份一字不改，24 个既有单元回执与 ED362352 的完成回执继续复用。跨尝试复用先按旧身份重放，无法重放才走分片。
- 单元核对被拒时，repair 也按片投影执行并重新合并，避免一次 repair 再产出整份提案撞同一上限。
- 不改数据库 schema；新阶段名与内部 scope ID 只出现在 `panorama_steps`，不进入 manifest、失败文本或用户可见身份。

## 备选

- 窗口化原文加偏移平移：需要裁剪 span、重写 claim 引用、重定位引文，触碰全部偏移与重复引文不变量；探针已证明读全文不慢，拒绝。
- 模型合并分片提案：合并请求又要一次输出整份提案，正是超窗形状；拒绝。
- 只在 600 秒失败后自适应分片：步骤身份不确定，最坏情况先浪费十分钟；拒绝。
- 只按来源拆分多来源单元：CE3C1904 是单来源，无效；拒绝。

## 后果

- 超长单元的输入 token 约为原来的 4 到 5 倍，换取每个请求的输出在窗口内完成；`inputTokens` 回执可见。
- 单元内的跨片联系不会在生成阶段出现，由全局综合建立；区域可能重复，由全局综合合并。
- `unit.review` 与全局核对仍为整单元请求；ED362352 曾在 33k 字符上完成过它们，CE3C1904 尚未实测。若真实运行证明其超窗，失败按单元隔离并保留分片回执，下一步用同一聚焦形状扩展核对。
