# ADR-010：相关性调用独立留痕

日期：2026-10-11。状态：accepted。产品方向不变；只选择原文候选，不建立关系。

已验证的相关性快照需要跨进程记录：发送之前保留调用，未知结果不重发，更正/授权变化使完整输入失效，迁移保留历史但不恢复执行许可。

备选：复用理解模型的 contexts/model_attempts 表会混淆“选择原文”和“生成观点”，原有恢复校验也假定陈述输出；只留运行日志缺引用约束及可靠恢复；为快照、输入、结果分别建表增加不必要对象。本阶段采用独立 `relevance_attempts` 与 `relevance_inputs` 两表，结果最多三个片段 ID 内联保存。来源/文字版本使用外键，历史快照与策略版本共同校验；原文仍只有既有来源层一份身份。

调用状态与输入有效性独立：reserved/completed/rejected/unknown 说明调用结果，current/frozen 说明快照是否仍可使用。同一查询/输入/模型版本只有一次保留；后续读取不再调用。完成也不证明观点正确。重启将 reserved 改为 unknown；迁移冻结全部相关性历史，未完成请求也改 unknown。

SQLite schema 12、迁移包 v11 追加两表；保持 v1–v10 包恢复兼容。新格式校验原文范围、来源归属、授权历史、完整输入、选择身份与结果摘要。117 项测试与三处真实强退检查通过，v1–v10 实际旧包恢复通过；详见[实施记录](../engineering/m4-durable-relevance.md)。模型分发、实际语义界面与关系反馈是后续切片。
