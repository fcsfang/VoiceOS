# ADR-020：英文反馈使用独立持久记录

状态：提案，尚未接入数据库。

## 背景

英文练习需要同时保存个人原句、文本建议、旧练习比较和纠错后的版本。普通认知候选会携带用户立场、审阅和行动语义，直接复用会把语法建议误认为认知事实或任务依据。

## 决策

新增独立的英文反馈记录族，至少包含：练习会话、当前来源版本、可选旧来源版本、建议记录、比较记录、模型尝试身份、输入摘要、反馈状态和冻结原因。每条建议保存精确来源片段、建议类别、建议文字、解释及 `possibleTranscriptIssue`；每条比较保存本次建议索引、当前引文、旧练习引文和比较类别。记录只可引用用户个人来源，AI/第三方内容不能成为练习原句。

纠错、来源权限撤销或迁移完整性变化后，当前反馈冻结，原记录保留；不能自动改写成新版本。反馈状态不改变 claims、actions 或 evidence state。删除个人来源时，反馈记录进入不可检索的历史/删除态，导出包保留删除审计所需的身份摘要，不保留超出用户选择范围的原始音频。

## 取舍

独立表和独立状态增加迁移与界面工作，但保持认知、行动和语言练习的语义边界。复用 claims 表实现较快，却会污染审阅、提醒事项和检索结果。把建议写成普通文本文件易于实现，但无法可靠执行版本屏障、撤销授权和跨包恢复。

## 实施门槛

先完成 schema 草案、迁移测试和空恢复测试；再接入一次持久模型请求。真实英文录音、发音评估和学习效果不由此 ADR 推断。费用、音频云端权限和是否启用英文自动反馈仍遵循既有 P02/P05 边界。
