# ADR035：版本化本地排期意图

日期：2026-10-13。状态：采用本地持久意图和已保存观测的三方预览；未接实际外部改期。W14 / PRD-ACT-02/04、PRD-CTRL-02、PRD-REL-02/03，产品方向不变。

## 问题与取舍

已有时间回读和纯三方策略，但没有持久 desired、表达锚点、意图归属或版本约束，不能可靠恢复排期，也不能解释某个改期提议来自用户还是 AI。

备选：①把期限与任务标题/状态塞进现有 action_revisions，会使完成回流的行动版本基线因排期改变而失效；②只存当前 due 值，丢失承诺/规划历史与表达锚点；③独立追加 schedule intent 版本链，固定行动版本和可选外部观测依据。采用③。核心意图独立于 EventKit，未来自有任务界面也可复用。

## 实际接口与存储

`recordActionSchedule` 为当前有效且未完成的 Task 保存本地 desired。`expectedActionVersion` 与 `expectedScheduleVersion` 分别阻止状态/依据和排期并发覆盖；相同命令与相同输入返回原身份，改变内容不能复用命令。排期不会递增行动状态版本，不触发提醒事项创建、完成反馈或观点认可。

schema34 新表 `action_schedule_intents` 保存行动 ID/固定版本、独立排期序号、类型化 due、authority、actor、表达/规划文本、固定表达时刻与解释时区、可选 base observation、派生基线归属、历史授权版本、validity 和命令摘要。intent、版本和依据同事务；提交前失败回滚，提交后回执丢失可幂等重放。

`user_commitment` 只接受 user 命令；AI 只能保存 `ai_flexible`。已有明确承诺时 AI 不得换期、移除或降级承诺，即使新提案日期相同也不能改变其归属。用户可明确修订本地意图；这不构成对任意外部效果的宽泛授权。外部承诺修改仍须后续 Operation 的具体确认。

日期提案固定时区；表达时刻规范保存 UTC 毫秒及原解释时区，展示按那个时区格式化，不以当前设备时区重新解释。当前 API 接收已经解析的时间，**尚未实现自然语言期限理解**。user 文本为明确本地命令，AI 文本为规划依据；二者不因保存而变成原始录音中的承诺。模型接入以后仍须验证实际来源、原话、锚点和归属。

## 基线与预览

绑定 base 时必须提供实际连接版本；base 只能引用该任务关联的最新、标记有效、身份一致、linked、未完成且时间明确的观测。没有 base 时不保存连接授权或假基线。

目前没有 VoiceOS 确认的时间写入：外部已有日期一律视为人工/未知拥有，不能假设是 AI 弹性安排；已确认无期限可作为新弹性提案的空字段基线。已有用户承诺的历史保护优先于空字段。这个工程规则在未来实际写入后，须由唯一已确认 Operation 的回读依据区分 AI 所写字段；不能只看新日期是否相等。

`previewReminderSchedule` 读取当前排期、持续授权、任务版本、出处权限/最新认知批次，以及上次外部观测，调用 ADR034 纯策略。它不调用系统接口，不冒充新鲜回读、不执行改期。外部单独变化可保留，双方不同变化保留 remote 并重规划；重要字段仍输出确认需求。

完成/取消/重开引起的行动版本变化使旧意图不具备执行资格；更正/来源收紧会冻结依赖意图。控制中心只展示最新意图和其依据，明确标为本地、尚未执行。当前没有自动模型入口或期限编辑入口，避免半完成执行器被误用为自动排期功能。

## 迁移与检查

含排期的包 v34 保留版本、类型化时间、归属和 base observation。恢复全部排期 frozen，授权版本仅作历史，不携带实际连接许可。旧 schema33 的原表不变，仅增空表；旧包继续兼容。

导入核验连续排期版本、非递减行动版本、所引用行动当时未完成、AI/用户承诺保护、规范时间编码及命令摘要。base 核验同一行动、有效未完成时间观测、非倒退 sequence、不能引用高于固定行动版本的已完成反馈，并从历史值重推基线归属；即使重算包摘要也不能把人工日期降级为 flexible。

## 接续与限制

下一步 W14 持久 Operation/outbox、效果绑定确认、调用前后状态、fresh preflight、EventKit 条件保存及写后核对，再做 W16 补偿。改期执行器应使用当前/latest/frozen、状态版本、意图版本、授权和观察身份屏障；保存途中变更只能保留 unknown 并只读核对，不盲目重发。

本轮没有真实提醒事项修改、云端或录音。W14/AC-15/M3 仍 partial；普通任务的既有高度自主权限不变，明确承诺、批删、重要目标取消等边界不扩大。自然案例 A 仍缺真实行动结果与后续表达，不能由开发代填。

后续接续：普通弹性排期的持久操作、条件保存和只读恢复已在 [ADR036](036-safe-reminder-schedule-operations.md) 实现；本文保留该基础切片的原时点边界。重要效果确认、字段所有权、模型期限入口与 W16 补偿仍待接续。
