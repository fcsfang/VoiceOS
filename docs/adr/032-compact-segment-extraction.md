# ADR-032 精简片段与聚合请求

日期：2026-10-12。状态：独立开发候选，尚未设为应用默认。路线 W10/W11。

## 问题与选择

真实5277字符长稿的v2首段在120秒后unknown，不能重发。现有quote-only协议已由本机定位原话，但云端仍收到完整片段请求对象，含引用ID、时间、配置与摘要，增加模型无需处理的元数据。尚不能断言这些字段是超时原因。

新增独立 `segment-extraction-v3`：云端仅发送origin、speaker和本段原样text。完整请求、版本、政策、引用、配置与摘要继续预留在本地持久尝试；回应quote从该固定片段唯一定位，再复用既有引用与整篇门槛。沿用v2引用响应结构和聚合v2的32000证据预算；不增加输出token、时限或工具，不改变业务授权，不裁剪来源。

v1/v2构造仍可用，默认不改。v3须显式选用，并固定在新批次快照；已有v2批次不能改身份或重发。`LocalTextModel.loadSuite`只增加显式参数，现有应用仍加载v2。探针以 `--compact-extraction` 选择新版本；只能用新独立来源进行真实比较。

## 备选与取舍

延长等待：不能保证响应且扩大等待窗口，本轮不采用。缩小未来单段：可能减少提取量，但增加调用和边界未完句，先不改变分段预算。换文本服务/模型：涉及配置、质量与费用新验证，现有短理解可用，暂缓。精简输入复用现有quote定位，变更范围小、可独立对比；不能保证服务可靠性，也不能消除输出预算、跨段未完句或语义遗漏问题。

schema不变，持久身份和内容摘要区分v3，迁移仍沿既有冻结规则。未知/拒绝历史不补丁升级。验证包括精简网络字段、持久引用保留、整篇提交、端口漂移拒绝和成功复用不再调用；真实结果单独记录，不能以本地夹具宣布服务修复。

## 聚合v3候选与真实结果

新第二视频轨2窗口2700–4800秒、4509字符：提取v3两段完成，保存48项证据，实际用量2877/1698及653/664；聚合v2等待120秒后unknown，0认知提交/外写。这是不同素材，没有对照实验，不能断言精简请求已改善可靠性。

继续增加独立 `segment-aggregation-v3` 候选。完整账本依旧在本地固定，云端投影保留每条证据的id、segmentID、ordinal、kind、statement、quote，以及batchID、ledgerDigest和未完句状态；省去本地引用偏移、时间、重复摘要和尝试回执信息。原始证据顺序与条数不变，响应仍引用原证据身份并沿已有完整覆盖、行动判断和出处门槛。v2历史不升级，v3只显式用于新批次，应用默认仍v2。`--compact-segments`同时选择两个v3。

19项直接相关检查通过，覆盖网络字段、所有quote保留、成功复用、版本漂移、发送失败不阻塞回流与创建中撤权屏障。schema31不变，正式应用默认尚未改变。

在已失败的48项账本上仅做本地投影测量：估计聚合wire UTF-8由32208字节降为18087字节，48项quote均与原稿偏移一致；该投影没有发送，不代表时延或质量改善。

探针可显式追加 `--segment-budget <1–4000>`，固定在新批次快照，旧批次配置/预算不一致直接拒绝。第二视频4800–6900秒新独立音轨的3805字符属于原生短稿范围，显式1800预算的双v3验证只证明分段机制，不冒充自然长稿路由验收。

## 双v3实测结论与发布边界

3805字符新本人音轨显式1800预算分成1762/1798/245字符；首段v3完成30项证据（1440输入/1516输出token），第二段等待120秒后unknown。第三段、聚合v3未发送，0认知/外写，完整性正常；保留请求，不重发。聚合v3只有本地结构验证，不能声称真实成功。

本轮多次不同新输入在提取或聚合超时，精简与缩段仍未稳定；暂停继续试探云端，等待用户选择另一个授权文本服务独立比较或保留现服务继续短闭环。两个v3不设为应用默认，不改变既有模型配置。新服务也不得替未知来源重发。默认仍v2；本地Qwen不变。证据：[提取v3与聚合v2](../research/evidence/compact-segment-cloud-2026-10-12.json)、[双v3小段](../research/evidence/compact-both-cloud-2026-10-12.json)。

用户后续明确：长文本是日后常态，不能让步。保留长文字需求，当前api.chiyi.cc/v1仍是已授权目的地；进一步检查客户端绝对时限、首字节/响应体阶段及网关流式/异步兼容性。现有证据仅能证明端到端超时，不足以归因服务故障。尚无新服务授权，不自行迁移目的地。
