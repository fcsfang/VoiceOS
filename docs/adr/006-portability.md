# ADR-006 备份、迁移与删除

日期：2026-10-10。状态：partially_adopted（开发切片）；其余仍 proposed。关联：D07/D09、P06、H08。

**问题与约束。** 默认结构化记录/来源/修改历史可导出，媒体可选，恢复前校验。删除 VoiceOS 数据不自动删除外部任务/笔记，B → C 保持身份。

| 备选 | 收益 | 代价 |
|---|---|---|
| 版本化可读逻辑包 + 一致本地备份 | 可跨实现迁移，原生备份可恢复运行细节 | 需格式/升级/媒体快照与删除边界设计 |
| 只复制数据库/只导出 Markdown | 生成简单 | 活跃 WAL/媒体可能不一致；历史关系/权限可能丢失 |
| 仅云服务备份 | 多设备便利 | 服务依赖/隐私/费用增加，不能代替可迁移格式 |

**推荐。** 第一项，逻辑包 manifest + 按类型 JSONL + 可选媒体；保留 ID、版本、关系、权限和引用。原生备份从一致 DB 快照取得不可变资产闭包，不盲拷主文件。首版按需备份，自动频率/加密/保留期另验证。

恢复到空库预检后原子切换；凭据不导出，外部连接和待发操作暂停核对，不重建全部提醒事项。只恢复结构的包显示媒体缺失，不造“完整恢复”。两库合并与实时跨设备同步延期。

删除先屏障后清原件/文本/历史/索引/缓存；在途导出遇涉及删除则取消。已有用户导出或旧备份不能自动追回，说明边界与清理入口。hash 检查不等于加密；正式秘密存储、备份加密与保留期限未冻结。

**证据/采用条件。** 合成导出恢复/损坏拒绝已测，见[可靠性报告](../research/reliability-validation-2026-10-10.md)。须按[数据模型](../architecture/data-model.md)验证实际 schema、活跃写入/资产清理竞态、损坏/缺媒体、升级失败回滚、源删除与晚到输出。若格式变更提供有测试的升级链，不直接覆盖旧备份；新的应用形态读取同一逻辑契约。

**M1 采用范围。** 当前四实体逻辑包/可选媒体及空库恢复已实现；缺媒体显示 reference_only，待执行 work 暂停。完整历史/删除/在途 pin 与 UI 恢复待实现。 证据与局限见[M1 实施记录](../engineering/m1-file-input.md)。
