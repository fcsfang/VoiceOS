# ADR-031 可选本地 Qwen 转写候选

日期：2026-10-12。状态：试用采用；整体准确率、长素材、精确对齐未验收。

**用户确认与当前实现覆盖（2026-10-12）。** 用户明确“语音转文字模型已敲定好”，Qwen成为已确定的工程转写方案，不再反复选型。应用缺配置时等待配置，Apple仅作为明确选择的备选，不自动回退。选择以配置内容快照保存在本机应用偏好，重启前恢复；配置或安装失效保持待转写任务，不修改旧稿。机器路径/安装状态不进入产品迁移包，迁移到其他机器需重新配置本地环境。以下试用期间的默认/不持久描述为历史状态。

问题：Apple真实中文技术口述出现疑似错字，用户要求更好转写模型。音频云端授权仍未选择，不能用已有文本API许可代替。

选择Qwen3-ASR 1.7B 8bit / MLX Audio可选端口：本机两段真实音轨对比中，修复“携代码”疑似错误、保留Codex名称和更多口语；用户声音轨2身份明确。固定revision/权重SHA256、独立环境，不修改原素材或完成的旧逐字稿。应用启动仍Apple，本次运行明确启用Qwen，菜单可切回。

备选与取舍：Apple最快且原生，保留为备选；Whisper large-v3时间更细且此次更快，但删口语、误拼Codex、数字静音广告幻觉/越界，此轮不设默认；云端可能有更高质量但本轮无音频上传许可，未测试。两样本没有人工听写参考，不能宣布Qwen整体准确率最高。

Qwen基本转写没有词级对齐，因此独立30秒音频块提供真实粗范围，界面明确范围粒度，不伪造精确时间。块生成token用尽整次拒绝；全零数字静音跳过，但环境噪声幻觉仍开放。代价是更慢、Python依赖/权重部署和跨块完整性风险；长期可选ForcedAligner或原生封装，须另有实测依据。

接口沿用SpeechPort/逐字稿backend/现有版本和迁移格式。切换限应用worker/录制空闲时，单次执行固定端口；失败不暗中换服务。当前是开发候选，尚非完整打包分发；重启不持久选择，长文件仍全量解码。取消子进程和错误回执已针对性验证。自然录音行动反馈完整闭环仍开放。
