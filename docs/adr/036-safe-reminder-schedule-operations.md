# ADR036：普通弹性排期的持久外部操作

日期：2026-10-13。状态：采用。路线 W14 / PRD-ACT-02/04、PRD-REL-02/03、PRD-CTRL-02；重要期限确认和 W16 补偿仍待接续。

## 问题、备选与取舍

本地排期意图和三方预览不能证明外部改期成功；保存调用丢回执时，重发可能覆盖用户刚刚调整的安排。

备选：①保存返回后才登记操作，进程退出会丢失是否派发的事实；②失败重试修改同一任务，容易覆盖新人工字段；③独立持久 Operation，写前预留、派发前置 unknown、写后回读，任何已尝试意图只读恢复。采用③。预留期间失败或退出标为 blocked，不自动续写；要重新规划须形成新版本，而不能换命令 ID 重发旧意图。

`RemindersSchedulingPort` 独立扩展既有读/创建端口，保留现有连接器和替身的复用。采用“条件保存＋回读”，不假设 EventKit 提供远端原子 CAS。写前本地屏障、EventKit 最终字段检查及写后核对能缩小竞态范围，不能消除跨进程/iCloud 编辑，也不能保证撤权与最终同步保存构成跨 actor 的原子事务。

## 实际接口与状态

schema35 新增 `reminder_schedule_operations`。每个 intent 至多一个操作，绑定 intent、link、预期 observation、历史 access version、before 快照、desired、命令摘要；不递增行动状态版本。`executeReminderSchedule` 目前只接受三方策略为 `writeFlexible` 的普通弹性安排，明确期限、人工基线和归属未知仍停写。

1. 同步核对 latest/current 排期、未完成行动及其固定版本、最新认知批次、出处许可、唯一外部标记/身份、已显示观测和排期所绑定授权。
2. 持久预留 `reserved` 后才 await 新鲜回读；回读必须与显示的完整 before 快照一致。写前变化保留观测并登记 conflict，不写旧安排。标题可已由用户改过，只要显示的最新基线和新鲜回读一致，保留该标题。
3. 派发前持久 `unknown` / attempted=1。连接器内部重新查找唯一匹配，await 本地授权/来源/版本屏障，再重新取得 EventKit 对象、同步比较身份、标记、标题、完成状态和期限。只赋值 due，不主动改标题、notes、priority、alarms 或完成状态。
4. 返回后持久 save acknowledgement，继续核对本地屏障并唯一回读。Observation、mapping、可能的真实完成回流与操作结果回执同事务提交；提交前故障全部回滚，提交后丢回执保持已知证据。保存返回不能代替回读。
5. 回读身份和其他字段一致、due 为 desired：有保存应答记 `confirmed`；缺应答只记 `observed`。后者只证明目标期限被观察到，不能断言由 AI 写入。其他变化记 conflict；无法读取期限保持 unknown。
6. `reconcileReminderSchedule` 只读恢复 unknown/conflict；当前授权必须覆盖原清单，但可以是新的授权版本。普通定时回读复用同一份新鲜读取完成 unknown 核对，不增加额外读取。confirmed/observed 保存的是当时效果证据，不代表后来外部值不会变化。

重复命令/同一意图不再派发；换观测/作用域也不能借同一操作重发。reserved 在启动恢复时转 blocked；unknown 继续只读。检查点覆盖预留、派发前置、应答、核对事务前后；已提交回执不因后续检查点异常退回 unknown。

本轮同时修正既有回读身份屏障：已唯一识别的 external ID 不会因另一个任务复制标记而自动更换；这种情况保留 conflict，不把替代项完成状态回流到原行动。

## 时间与归属

`writableComponents` 先验证与 `reading` 可无损往返；整天日期保留当地日期和解释时区，确切时刻保留时区。DST 重复墙上时刻和非零亚秒不能可靠核对，因此在预留前拒绝，不写出无法回读的值。`.none` 与 unknown 仍分离。

本切片不自动解读自然语言，也不把本地规划依据当作原录音的明确承诺。现有已确认操作仍不自动授予后续自由改期权：外部已有日期继续保守标人工。未来字段所有权必须依据已确认操作、观测历史和外部变化建立，不能只因日期相同或有保存返回就断言没有人工编辑。

## 控制中心、迁移与验证边界

控制中心显示当前意图的操作状态、原因和只读恢复入口；普通弹性意图可显式请求执行，Core 再核对资格。没有模型期限提取或日期编辑入口，不能据此宣称用户语音已能全自动规划期限。

含操作的迁移包 v35 保存完整尝试和效果证据；仅含意图仍 v34，旧包保持兼容。恢复操作与意图均 frozen，不恢复连接授权、不复活派发。迁移校验意图/关联/观测绑定、规范 before、三方空字段基线、尝试/应答边界和成功结果观测；重算包摘要不能把旧基线伪装成成功回读。

验证使用本地替身和隔离资料库，未修改正式素材或真实提醒事项，未调用云端/录音，未重启用户应用；原生运行时、真实 EventKit 条件改期及人工字段完整保留仍待集中实测。构建和代码检查不能替代这些证据。
