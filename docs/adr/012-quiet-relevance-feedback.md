# ADR-012：静默相关原文的展示与忽略

日期：2026-10-11。状态：accepted，范围为开发预览 W18 初始切片，不代表完整主动反馈验收。

采用已经接纳且仍有效的相关性回执作为只读展示依据，保留查询、摘录、来源和完整输入校验。相关不等于支持、修正、认同或验证。入口为用户主动打开的“静默回顾”，不发送系统通知、不自动进入模式B。

备选：另存可修改的卡片会复制查询与出处、增加纠错传播点；只用内存则重启丢失忽略。因此从已有不可变回执投影，新增两表仅保存忽略与显示偏好。忽略指纹使用查询、来源、文字版本、片段范围和原文，跨重复请求去重；查询会话或调用身份变化不当作新洞见。新问题或更正版本有新身份，不推断永久放弃兴趣。

显示偏好为normal/reduced/paused，有顺序版本与命令去重。normal最多二十条，reduced每次一条，paused暂停显示但保留历史。它是整体显示控制，尚不等同主题级“减少类似提示”。关闭、阅读和打开出处不写认可记录，不制造待回复任务。

全部候选在读取及打开时复核；更正、损坏、权限变化和冻结回执阻断旧反馈。偏好及忽略原子持久化，迁移升级v12/schema13；恢复保留偏好与忽略、冻结相关性执行回执，不发模型请求。

尚待：新表达自动附着、关联原因、未解决问题、主题级减少、模式B入口和通知opt-in。须按PRD独立实现。见[实施证据](../engineering/m4-quiet-feedback.md)。
