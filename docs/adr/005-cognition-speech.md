# ADR-005 GPT 与转写路由

日期：2026-10-10。状态：proposed。关联：D02/D04/D08、P02/P05、H01/H02/H04。

**问题与约束。** GPT 主导认知，原始表达必须忠实；云端文本/授权历史已允许，原始音频单独选择。仅本地限制必须传播，失败不能冒充理解成功。

| 备选 | 收益 | 代价 |
|---|---|---|
| 可替换 GPT 适配器；能力满足时本地转写优先 | 转写音频可留本地，认知上下文集中管理 | 本地语言资源/系统版本有限；两阶段质量需测 |
| GPT + 明确授权云转写 | 可比较语言/长录音质量，设备依赖较少 | 另有音频上传、服务保留、费用与网络风险 |
| 其他离线转写引擎 + GPT | 更广系统/语言候选 | 模型分发、资源占用、维护与质量需额外证据 |

**推荐。** 以接口分开 SpeechPort 与 CognitivePort，先比较本机可用本地转写和受明确许可的云路径。固定契约、来源版本、usage/调用状态和人工语义评分；Structured JSON 不代替忠实性测试。认知失败保存原件并等待/重试，不用规则摘要宣称满足 GPT 体验。

**当前服务边界。** 用户提供第三方 OpenAI 兼容网关。本次三次生成只有一次成功，另有超时和 503；模型标签不证明真实后端或长期稳定性，官方单价不等于网关账单。正式路由/型号尚未选定，服务保留/删除政策需查证。`store=false` 请求不证明第三方未留存。

**采用条件与退出。** 完成十样本及中英真实/合成转写对照、否定/条件/归属、长历史与仅本地发送拦截，记录实际价格和失败分类后选择。当前本地中文单合成样本不能推广到英语；英语资源和真实质量仍待测。服务变更按适配器切换并回归，保留旧结果模型/提示版本；不得暗中上传音频、加入个人历史或突破试验费用范围。

证据：[初步报告](../research/technical-validation-2026-10-10.md)、[API 实测](../research/api-reminders-validation-2026-10-10.md)、[试验方案](../research/cloud-evaluation-plan.md)。
