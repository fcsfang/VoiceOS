# ADR-022 问题状态与认知归属分离

2026-10-11；adopted，纯快照、新理解类型、独立状态与来源页已实现。

已有claim认可/证据状态不能表达问题是否登记了答案。选择独立Question及版本修订，连接原claim身份和审阅版本，复用来源快照；open/exploring/resolved/closed沿用数据模型草案。显示“尚未登记解决依据”，不把VoiceOS缺少答案记录等同现实中仍未解决。

备选复用review_state/evidence_state会混淆用户认可和客观验证；备选仅保存独立问题字符串会丢失原理解及更正依据。新表带来迁移与依赖校验成本，换取明确状态与历史。

新理解产物用版本化Schema区分问题与其他认知；旧类型未知保持unclassified，不按问号猜测、不重发。AI问题保持AI候选，不归入用户未解决问题。首个状态执行切片仅显式用户变更；自动自然语言转移稍后单独验证，不从相似度、任务完成或沉默推断答案。

纯准备、持久状态/迁移、单次模型分类、界面/静默反馈依次落地。详见[契约](../engineering/m4-question-lifecycle-contract.md)。技术选择不改变用户已确认的自主行动或默认静默方向。

采用证据：四项问题输入回归与308项全套测试；这些输入证据仅对应当时切片，后续持久及界面证据见下段。

内容类型切片：schema23/v22包及v3单次理解Schema落地，旧类型与原结果摘要保留；跨配置升级不重发既有理解。313项回归、旧v18/v21包恢复及原生候选显示通过；该段对应内容类型切片；持久状态已在后续落地。

持久执行：schema24/v23包，claim与问题同事务生成；每个claim固定问题身份，认可不重建，文字/归属/出处/权限变化冻结。状态修订单独比较版本和命令，不混入claims认可或验证；迁移冻结历史。四处真实强退/四次恢复及321项回归通过，来源页显式登记与答案出处已核对。初版答案需要不同来源版本或片段，避免同一提问的短引文冒充新增答案；自动自然语言转移和自然质量另行验证。

2026-10-12 当前依赖修订：排除“任意历史答案变化冻结整个问题”的实现，因为它会把显式重开后的当前研究永久锁住。选择当前resolved的最新答案作为有效性依赖，其他状态只依赖原问题；历史全量静态核对照常。答案失效且seed仍有效时仅显式重开可修复，原问题或迁移冻结不允许借此恢复。327项回归、六处真实强退/六次恢复和原生重开入口通过，无schema变更。

2026-10-12 讨论路径：采用成果v2显式类型，旧缺失字段保持nil且不重提取。备选按问号本地猜测会改变历史语义，备选重跑旧成果会重复费用与身份，均不采用。沿用原上下文固定预算（上限12000）而非统一重写8000，保留旧摘要并支持多轮依据；状态提交必须保持登记seed的原引文和上下文身份。334项回归、三处成果强退/恢复、六处问题状态回归、旧预算实物恢复和讨论原生入口通过；schema24/v23不变。
