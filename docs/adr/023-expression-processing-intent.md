# ADR-023 用持久处理意图区分本地保存与已请求的闭环

2026-10-12；accepted，schema25 / PortablePackage v24 已采用持久意图、单项执行器和明确保存入口。

当前表达保存、授权和理解分步进行，重启没有明确资料可判断“用户要求执行但尚未预留”与“仅保存本地”的区别。选择独立显式处理意图，固定单份文字版本、权限epoch及当时认知/关联端口；未来持久队列复用两阶段既有回执，认知成功后不因关联故障重发。

备选启动扫描所有允许云端来源，会混淆允许使用与要求立即执行，还会回填历史；备选内存队列会丢失退出前的处理意图；备选一个跨两次网络请求的数据库事务无法回滚已发生的外部处理。独立意图增加持久/迁移/取消校验成本，换取可见状态与准确恢复边界。

首个入口为显式“保存并处理本次文字”；普通保存仅本地，音频转写及讨论回合仍沿用已有明确入口。原文与授权/入队分别报告，key不进入快照，导出恢复历史冻结。配置变化使未执行意图blocked，不隐式换服务或扩大权限；已发请求仍由原尝试去重，不因升级重放。该工程选择不改变P01、P02、P04或语音优先愿景。

实现新增 `processing_intents` 表，记录固定快照、权限和端口身份、阶段、既有调用回执及取消/错误信息。状态恢复不重发 unknown/rejected；关联失败不回滚已提交认知；迁移只保留冻结历史。控制中心的“保存并处理本次文字”明确完成文本云端授权后才入队，普通保存保持本地。

具体消费、崩溃与迁移验证顺序见[执行契约](../engineering/m4-expression-processing-intent.md)。

2026-10-12 审核补充：采用语义命令指纹与完整快照摘要分别校验，避免随机准备身份破坏幂等；接受原 schema25/v24 摘要格式，无需仅为算法修正增加表版本。拒绝把当前模型配置当成历史生产者身份，续接和恢复绑定实际回执。启动恢复以“没有预留 / 已知提交 / 结果未知”区分阶段：统一 running→unknown 虽保守但丢失安全续接能力；统一重排则可能重复外部请求。选择仅续接没有预留的阶段，已有未知/拒绝/冻结回执不重发。迁移继续冻结历史，不继承该启动续接许可。
