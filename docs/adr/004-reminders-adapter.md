# ADR-004 Apple 提醒事项适配器

日期：2026-10-10。状态：proposed。关联：P01/P03、D05/D10、H09。

**问题与约束。** Apple 提醒事项是 MVP 必需连接；外部人工变更与完成要回流，普通操作无需逐条询问。系统全量权限不等于应用可以操作所有清单。

| 备选 | 收益 | 代价 |
|---|---|---|
| 同应用原生 EventKit | 明确 API、对象读取、统一应用权限身份 | 全量 OS 权限需应用限制范围；通知需再查询，竞态仍存在 |
| Python/网页调用原生独立桥 | 跨语言 UI/引擎方便 | 多身份/进程授权、桥协议、崩溃边界增加 |
| 快捷指令或 UI 自动化 | 人工验证入口直观 | 文本/焦点/界面依赖强，不宜作为首版可靠同步主通道 |

**推荐。** 第一项。配置应用实际清单范围，读/写只处理授权范围内关联项；内部 Task 独立身份，映射保存外部 ID、可核对标记与 base/remote/desired 字段。标题不是身份，标记可编辑，ID 不作跨设备永久承诺。

启动、唤醒、变更通知、应用内刷新触发核对，另保留可配置兜底轮询；频率待 H09/体验测试。通知是变化线索，不是完成事实。三方字段比较保留外部手工编辑，普通弹性安排可自主重规划；重要冲突停止覆盖。缺项不当完成、不自动重建。

**证据与限制。** 一个合成项的创建、人工改名/完成回读及普通重开已验证，见[实测](../research/api-reminders-validation-2026-10-10.md)。探针 reset 后查对象是读取实验；reset 会影响对象有效性，不作为生产同步算法。没有证明远程原子 CAS、硬崩溃去重、通知完整、云同步 ID 稳定或权限撤销。

**采用条件与退出。** 固定应用身份后验证撤销、离线、延迟、多匹配、外部删除/竞态和丢回执。若接口行为不能满足 PRD，报告具体风险与补救，不用 UI 自动化掩盖失败。保留适配接口，未来任务系统不改变历史 ID。
