# ADR-016：讨论 AI 段落的本地候选派生

状态：采纳，首个显式保留切片已验证；完整混合成果回流仍开放。日期：2026-10-11。

产品依据：PRD-DIA-02要求AI候选回原认知体系，并保留身份、出处与版本；AI提议不是个人承诺，结束不是认可。当前个人回合回流已实现，AI段落只在讨论历史。

采用首个可测切片：用户选择一个已接纳、依据未冻结的AI分析段落，原文复制为待核对AI候选，不新增模型请求、不改个人原文、不产生行动。候选复用既有审阅/冻结/引用体系；独立派生关系绑定原讨论调用、段落、结果摘要、完整输入和候选身份，同一段落不重复建立候选。

工程结构：保留claims既有提交基础，model_attempts新增execution_kind以区别实际模型请求与discussion_derivation；派生记录没有token或费用，界面不将其当新调用。新增discussion_claim_derivations保存引用语义、原回复关系与原子提交身份。已有真实调用保持原语义；迁移保留派生并冻结原讨论执行。

引用语义：AI段落有输入引用时保留model_citation；没有引用时使用最后个人发言的原文片段作为context_anchor，仅用于回到这次讨论的触发原文，不能声称它证明AI假设。完整实际输入与旧AI回复依然在原调用快照中，所有输入的权限与版本共同冻结派生，不能仅检查单个锚点。

备选：把AI段落保存成个人来源会混淆用户身份；另建一套候选/行动表增加重复审阅和维护；再调用模型提炼短句增加费用和不确定性；自动将所有分析段落入池会造成候选噪声。首切片选择明确保留某段分析，后续可依质量证据增加自动识别/简化成果，但不改变完整回流目标。

异常处理：登记派生与内部提交身份原子落库，候选与派生完成标记原子提交。进程退出后不自动恢复工作；显式重复保留可安全恢复未完成本地复制，因为不涉及外部请求。已提交回执保持原身份，不重新激活冻结候选。恢复资料不能通过新派生绕过原回复冻结状态。

验收门槛：零新网络请求/任务/原文改写；AI归属、pending/unverified、上下文锚点标识、同段防重、三处强退、来源/权限全输入冻结、审阅历史、迁移篡改拒绝及旧包恢复。未达到这些门槛前不声明该切片完成。

验证结果：205项测试、三次实际强退、四个新包往返、实际旧v1–v15恢复及引用/触发点原生界面通过；本切片零云端调用/录音/外部写。见[实施记录](../engineering/m4-discussion-candidates.md)。
