# ADR-015：逐轮讨论的持久调用与回复身份

状态：accepted，限 W17 回复基础切片。日期：2026-10-11。

产品要求：多轮讨论保留出处、个人声音与 AI 建议区别，结束不等于认可；P07 逐轮语音＋文字已确认。产品未要求一轮一次调用或此数据库结构，这些属于工程实现。

采用：共用来源与版本化上下文，新增独立讨论尝试表；调用前登记完整输入，回复提交前重验会话/来源/授权；一轮一次直接端口调用，未知不自动重发。AI 回复不是个人来源、候选观点或行动；复用既有引用结构，但保持独立回复身份。迁移保留历史并冻结执行。

备选：仅内存聊天实现最少，但退出丢历史且无法判断是否重复付费；复用认知提取表可减少表数，却混淆用户表达、AI 讨论与可执行任务；自动重试提升短期成功率，但超时不能证明服务器未执行；服务端会话 ID 节省请求内容，却增加迁移/审计依赖。完整本地快照更便于维护和替换模型，代价是历史长度与发送费用增长，超过预算明确停在该轮。

首版约束：最多40个人回合；完整文本预算默认8,000/上限12,000标量；回复最多8段、共4,000标量，每段最多1,500标量。这些为开发边界，可经质量测试调整，不是核心产品方向。已知 token 用量保存，账单未知；明确复试、总结压缩和实时语音另行设计。此 ADR 不批准音频上传、订阅登录或 GPT-Live 权限替代。
