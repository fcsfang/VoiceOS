# ADR-019：成果生产者的持久顺序

状态：partially_adopted，顺序/迁移基础已验证，跨入口持久复用尚待接入。日期：2026-10-11。

跨入口提取必须区分预留前的原成果与预留后的新生产者。以当前目录验证历史会误把后续合法结果算作被遗漏；时间戳有同秒并发、时间精度与时钟变化问题。选择单写者SQLite内、无await的唯一正整数producer_sequence，随认知请求或AI本地派生预留一并写入，失败/未知/空结果仍保留位置。不增加独立复制观点/任务表，不依赖进程内计数器。

备选：独立事件表能覆盖将来更多模块，但当前四种认知生产入口已共用model_attempts，新增表及双写校验成本较高；请求时间戳不能证明先后；用原候选语义相似度不能保持身份。顺序用于本资料库内的生产范围，不表示事实验证、收费调用数或跨库全局时间。

schema19、包v18共26表；新包严格保留顺序，缺失/重复/负数/非整数拒绝，不自动修补。旧schema18升级与v1–v17恢复，按created_at/id建立确定的回溯基线；它不证明旧记录的真实发生顺序，但后续新生产者必定位于全部旧记录之后。原ID、状态、候选、行动和回执不重建。不同独立资料库的顺序不能直接合并，未来多库合并需新决策。

237项测试通过；四项新增测试覆盖未知保留位置、原AI复制重放不增序、迁移后新增工作、旧包基线和四类重算hash篡改。实际旧v1–v17恢复、新包两次往返、三处成果强退、旧schema18完整资料库副本升级和含资源签名构建通过。0云端/录音/外写。证据见[记录](../research/evidence/model-producer-sequence-2026-10-11.json)。

下一步用此顺序重建提取预留前的原身份目录，将目录与成果快照原子保存；随后比较发送/接纳边界的当前目录，检测在途竞争。尚未取消现有跨入口隔离，不宣称完整成果复用或AC-11通过。
