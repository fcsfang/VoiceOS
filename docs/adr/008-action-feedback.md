# ADR-008：行动结果与反思的保存

状态：partially_adopted。日期：2026-10-10。适用范围：当前单机开发预览。

愿景要求认知—行动—反馈闭环。任务状态回读只能说明任务完成，无法保存实际结果或用户反思。本决策落实已有方向，不增加观点自动验证规则，也不要求每次完成后填写反馈。

采用独立的用户文字来源保存原文，并用 `action_feedback` 关联行动身份、记录时的行动版本和类型（outcome/reflection）。结果和反思均为用户记录；完成状态、观点认可、证据验证仍是独立状态。界面提供可选入口、关联行动历史及返回反馈原文。

备选一：把反馈写进行动状态修改备注。实现短，但多条反馈、文本更正、出处和迁移会被状态版本束缚。备选二：仅创建不关联的普通表达。模块复用最多，但历史回溯依赖模型推断，无法可靠找到原行动。采用的方案复用用户文字保存和更正机制，增加小型关联表；代价是必须维护关联完整性和格式升级。

保存先检查行动当前版本；相同命令可重放原回执，不能改变原文、父行动、版本或类型。行动后来变化不改写已记录反馈的关联版本。允许记录历史或冻结行动的结果，不恢复其有效性。

关联意图放在来源的 `feedback_json` 中，先持久化再保存原件；原文、文字版本、反馈关联在同一事务提交。中途退出后，恢复按原始意图补全；只有意图而无原文时标记中断，不伪装保存成功。关联意图不用外键，避免来源—行动—来源恢复顺序循环；完整性由恢复预检检查。反馈表保留父行动和来源外键，并用行动内 sequence 维持记录顺序，避免 UUID 排序打乱历史。

存储 schema 11、迁移包 v10，新增第十七类 JSONL `action_feedback`，兼容 v1–v9。包保留反馈原文、更正历史及关联，但不转移本机提醒事项连接权限。数据摘要与字段关系均验证；仅重新计算文件摘要不能绕过缺失关联检查。

默认仅本地保存；保存不调用模型或操作提醒事项。若以后引入反馈自动综合、观点验证或跨行动复用，必须另行定义证据规则和语义质量验收。当前真实证据见 [M3 行动反馈](../engineering/m3-action-feedback.md)。
