# ADR-017：混合讨论成果的输入与双重出处

状态：输入准备与提案校验已实施；持久提取、真实驱动与界面未实施。日期：2026-10-11。

依据：PRD-DIA-02要求个人新观点、AI候选和行动建议回原认知体系，保留身份和版本；P01允许已授权普通明确任务自主执行。既有个人单轮整理与AI段落保留分别有效，但不能解析跨角色短指代。

采用独立成果快照，而不直接复用“发送下一轮”的输入：成果可以在讨论结束后准备，必须包括最后一轮已接纳AI回复。入口历史和全部个人回合只出现一次；AI回复以调用ID、所回应回合、结果摘要和段落身份保存。未知/拒绝结果保留状态，无内容不推断。仍在途的回复阻断准备，防止成果提取忽略即将到达的反例。

所有实际来源和衍生AI历史共同检查目的地、版本和权限；完整文字加AI段落计入8,000标量默认预算，最多12,000，溢出拒绝。结束后可以显式准备，但准备后结束/新发言/来源或权限改变会让快照失效。完整快照目前为内存值；来源Context使用既有持久机制。真正提取前须新增可迁移的整份调用快照和结果/引用关系，不把临时值宣称持久成果。

提案出处分开：sourceEvidence是来源/逐字稿/片段/连续原话；replyEvidence是AI调用/段落/连续原话。AI的原文引用段落不能冒充AI原创出处，须回到实际来源。个人成果需要属于本次个人回合的原文，入口旧观点不是本次新观点；AI段落不能单独证明认可。未识别身份保留unresolved。

首个混合行动切片仅允许完整个人原话支持普通任务；自动标题须直接出现在个人行动引文。带AI指代的个人行动暂留opportunity、autoSend=false；AI行动为ai_suggestion。省略AI引用也不能让“好”变成未在个人原话出现的任务。此为质量验证阶段的能力边界，不修改P01长期自主目标；待指代准确性和动作取舍通过后，另行扩展唯一明确的跨轮承诺。

备选：只取最后个人回合会丢反例和AI方案；把全对话改写成个人原文会混淆身份；直接复用下一轮回复快照会漏掉最后AI回应并拒绝结束后处理；让模型自由给出引用字符串无法证明实际输入。本方案保留现有来源/候选/行动基础，新增双重出处校验，后续持久提取按原子提交接入。

验收：全角色/最后回复、未知状态、在途阻断、全输入预算/许可与变化屏障、连续引文、AI/个人/外部归属及指代任务负例。静态提案验证不能替代发送前与结果接纳前的动态快照重验，也不能证明语义判断正确。下一步先持久调用与原子回流，再有限真实文本质量测试；未验证前不开放自动混合成果入口。
