# ADR039：纠错行动影响的只读投影

日期：2026-10-13。状态：采用，W16第一切片。依据PRD-COR-01/02、PRD-CTRL-02/03；接续W14，不扩展M4。

## 问题与取舍

当前纠错会先冻结旧认知/行动，但用户看不到哪些外部任务和改期尝试受影响。冻结不能被描述为外部取消，外部任务完成也不能因为认知纠错被改写成没有发生。

备选：①冻结后直接自动删除关联任务，无法证明任务确实错误，可能损伤人工字段与实际完成事实；②为每个冻结建立“错误”记录，把认可、隐私限制或迁移误报为错误；③从明确纠错修订及实际派生引用投影行动影响，先只读核对外部现状，另立具体补偿操作。采用③。自动执行补偿另一个切片，不能将影响清单称为已补偿。

## 实际契约

`correctionActionImpacts()`读取已保存历史：认知更正reason=correction且修订版本晚于行动绑定版本；逐字稿reason=transcription_error且from版本不早于行动实际引用版本。仅冻结行动并存在明确纠错依据才进入清单。使用实际claim引用，不把普通相关主题当派生依赖。

投影包含行动及绑定认知版本、根修订ID/来源ID、外部link与上次观测、该行动的改期before/desired/应答/状态，以及当前摘要。摘要绑定当前行动、根ID、外部身份/状态/观测、操作状态和当前清单授权；重复读取相同输入稳定。底层记录均已持久，当前清单可以在重启/迁移后重建，不另造可变“补偿已完成”表。

状态区分：无外部关联（只停止旧内部行动）；连接未授权/暂停（保留旧观测，现状未核对）；未知或冲突改期（先回读，不重发）；身份/现状不明（不能假定撤销）；外部完成事实（保留事实）；未完成外部任务（待核对是否保留、改写或取消，尚未补偿）。

控制中心通过用户主动的“查看纠错影响”或处理记录菜单打开，显示纠错根、上次外部状态与改期历史，可使用既有范围限定只读回读。不开无人值守弹窗。列表不创建任务、不取消任务、不回滚期限、不把撤销标成完成、不生成用户Outcome，也不恢复冻结认知的可信性。

## 验证与边界

6项直接检查覆盖：认知更正不外写/不造结果、认可/隐私冻结非错误、逐字稿纠错根与本地影响、保留真实完成事实、迁移冻结非错误、明确纠错迁移可重建且不恢复连接。针对性测试、稳定签名构建及严格codesign证据见[本切片证据](../research/evidence/m3-w16-correction-impact-2026-10-13.json)。上一W14阶段539项完整回归为其原时点证据；本只读增量采用专项和编译，不重复全套。

schema37/包选择不变，新增投影不带可消费执行授权。原生运行时未验收；尚未覆盖跨讨论/成果的全部间接派生图，也没有具体补偿计划、效果许可或外部补偿执行。AC-17/18与M3仍partial。下一步实现持久补偿意图、一次效果许可、人工字段保护、unknown只读恢复及结果回读；现有冻结屏障持续有效，不能为补偿放宽常规执行器。
