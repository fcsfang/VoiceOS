# ADR-007 用户表达与行动提取

日期：2026-10-10。状态：partially_adopted。关联：PRD-CAP-03、PRD-COG-02/03、PRD-ACT-01/03、PRD-REL-02、P01/P02。

**问题。** 导入音视频默认外部/未知说话人，不能自动作为用户行动承诺。需要用户原始表达入口及可追溯的普通行动提取，不能把模型归属猜测当来源身份。

| 备选 | 收益 | 代价 |
|---|---|---|
| 显式用户文字入口，复用来源/原文版本；单次理解提取认知与行动 | 来源身份由入口建立，结果原子提交，复用权限/更正/迁移 | 先提供文字闭环；没有解决录音内多人身份 |
| 将导入的全部媒体默认标为用户 | 操作少 | 第三方、多人、引用会冒充用户立场，违背产品约束 |
| 第二个模型调用专做行动提取 | 契约分离，便于独立评估 | 多一次费用/失效窗口与恢复边界 |
| 关键词规则直接生成任务 | 易复现、离线可用 | 对条件、否定、转述与口语的理解不足 |

**采用。** 第一项。导入行为不改；用户文字保存为 origin=user/speaker=user/kind=user_text。不假造音频或识别结果，TXT 原件与原文版本在同一保存契约恢复。首次仅本地；文本外发与连接权限独立。

理解返回 user_tentative、external、ai_candidate 或 unresolved，并可附任务/探索意图/AI 建议、连续原文引用及普通自动发送资格。Core 校验来源身份、版本、原话、类别/归属和数量，再将认知及行动同事务保存。模型不能选择清单或直接调用外部工具。用户暂定表达仍 unverified，任务完成不认可观点。

只有原文来源允许外发、当前行动有效且存在本机连接授权时，普通明确任务可自动创建并回读；结构化响应仍最多 32 条认知以保持持久边界，但不再设置固定的自动任务数量上限，也不合并不同交付物。期限、复杂目标和歧义暂不自动激活；保留本地任务或候选，当前适配器不设置日期/闹钟。AI 建议与愿望不自动外发。模型对“普通/明确”的分类仍需质量验证，结构化格式和引用校验不能证明语义一定正确。

**2026-10-13 修订。** 早期开发阶段的“三项自动任务”保护阈值并非产品需求，已移除。P01 已确认在授权提醒事项清单内给予普通明确任务更高自主权；当前边界由任务归属、来源外发策略、授权版本、逐项回读和幂等身份决定，而不是由数量截断决定。

一次外部尝试仍由行动身份约束。重新理解同一已外发来源的其他调用结果先留本地，避免纠错或配置变化制造重复任务；明确人工发送是新授权入口。保守代价是同一来源后续新增正确意图也可能需要人工操作，未来用有依据的意图版本关系细化，不凭标题合并不同承诺。

**证据与退出。** [实施记录](../engineering/m3-expression-actions.md)包含 69 项测试、25 项强制退出检查、真实模型正负样本和专用清单闭环。质量不足时保留原文/结果，停止自动发送资格，不以循环重试隐藏误解。多人录音身份、复杂目标/期限、全历史理解和正式语音闭环仍未完成。
