# ADR026：分段处理采用独立持久批次与历史范围校验

日期：2026-10-12。状态：partially_adopted；入队、取消、恢复与迁移采用，模型片段/聚合仍未实现。

长内容的完整来源范围已不同于4000字的原处理意图。继续复用原表会使旧完整回执、局部结果与整篇完成混淆；只在内存缓存范围则丢失退出后用户的处理选择。因此新增独立父批次，复用来源、逐字稿、权限、模型身份及无损计划。

备选：直接扩大旧意图上下文（破坏固定预算/回执契约，不采用）；把各段当独立个人文字（丢失父来源且可能提前执行任务，不采用）；持久父批次和后续独立尝试（采用父批次基础）。代价是新增schema27/包v27兼容、深层历史校验；收益是取消和重放身份清晰，旧模型队列无需放宽。

仅首次入队要求当前范围有效；相同命令重放返回原历史身份但不能恢复取消/冻结状态。历史校验按旧逐字稿/权限epoch，执行预检按当前来源。迁移先校验原状态再冻结全部批次，不自动发送。暂无执行器，queued不等同running；不要把尚未实现的attempt状态写进产品。

验证入口和结果见[批次实施记录](../engineering/m4-segmented-processing-batch.md)。退出方案为保持旧队列独立运行、批次停止执行但仍可导出/读取历史；未来扩展attempt时用增量迁移，不改已有批次身份。
