# ADR025：长逐字稿先建立无损来源计划

日期：2026-10-12。状态：partially_adopted。本地计划及预览采用；模型分段执行仍待设计验证。

## 问题与约束

现有模型入口预算为4000 Unicode scalars，持久回执要求完整来源版本与逐字稿一致。真实40分钟本人录音转写为5280 scalars，不能直接通过入口。需要保留全部原话、归属及时间依据，同时避免旧回执复用到不同片段。

## 备选与取舍

1. 截断前4000：简单，但丢失后文条件/否定及出处，不采用。
2. 全局扩大预算：暂时容纳单样本，但费用/延迟边界变化，不能解决任意长内容，且未经端口质量验证，不采用。
3. 将片段包装为完整来源或复制为个人文字：可复用接口，但破坏严格来源校验、原件关系与回执身份，不采用。
4. 本地无损计划，后续独立父批次/片段执行身份：当前采用计划部分。原件与完整逐字稿不变，可复建、可校验，复杂度限于规划和界面。代价是超预算内容目前仍不能模型执行，界面必须如实说明。

## 采用机制及证据

算法按Unicode scalar预算，在完整Character边界切分。确定性身份绑定完整来源、政策版本、预算与算法；引用保留原span全局范围和包含片段时间，避免伪精确插值。播放前规范重建校验；更正或权限变化使计划失效。不增加schema或迁移执行字段。

383项回归、签名构建及真实20/40分钟本地测试通过。自然准确率、模型分段合并、任务否定/修订、真实云端成本和完整闭环未验收。详见[工程契约](../engineering/m4-transcript-segmentation.md)。

## 后续及退出

父批次完成前不得释放片段候选为外部行动。片段须独立持久身份和未知结果边界，父版本/权限改变必须使片段和聚合结果冻结。可替换切分算法时提高算法版本并重新构建计划，不复用旧片段回执。若更适合更大单次上下文，仍须经端口质量/费用验证并保留全来源校验，不能从本ADR推定支持。
