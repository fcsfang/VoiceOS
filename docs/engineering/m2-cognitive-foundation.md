# M2 持久上下文与认知候选基础

日期：2026-10-10。接续 [逐字稿基础](m2-transcript-provenance.md)。这是 W10/W11 的本地工程切片，未完成 M2 或完整产品 AC。没有云端模型请求、自动认可或外部任务写入。

## 行为与数据

选定来源的完整本地快照可持久化，保留来源/逐字稿版本、实际文字与片段、归属和仅本地限制、预算及内容摘要。规范化输入引用单独保存，用于查找实际依赖。相同上下文命令返回相同身份；更换输入拒绝；回放历史回执不会重新激活失效上下文。

本地调用先持久登记 context、provider=`local_fixture`、模型/提示/结构版本及时间，再接收结果。进程退出前未登记结果的 reserved 调用在恢复后是 unknown；不能重新提交或自动重发。费用与 usage 未知不记作零。本轮尚无真实模型执行端口、发送许可、policy/knowledge epoch 或云端调用完整账单。

候选提交要求每条有实际选入的 source/transcript/span 引用；整批验证后一个事务写入全部候选与调用完成回执。任一非法引用整批拒绝；提交前上下文重新检查。已完成结果可幂等回读身份，但不同结果不能覆盖；晚到的旧版本结果拒绝。结果摘要与候选原有顺序一起保存，迁移时复核。

当前三轴分别存储 ownership、evidence_state、validity。实现范围是 external / ai_candidate / unresolved，证据为 unverified，有效性 current / frozen；没有 user_confirmed 写入口。AI 候选不成为用户观点，current 只表示依据未失效，不表示正确或已认可。用户自身表达、明确认可、支持证据更新需要后续独立契约。

更正逐字稿与上下文 stale / 候选 frozen 在同一事务提交；原件隔离也冻结相关上下文和候选。当前冻结按上下文全部实际输入传播到直接产物，保守地覆盖整个上下文；没有 Claim→Claim 或任务依赖图，不能宣称完整跨模块冻结。正常读取也重新核验当前版本/限制及原件摘要；历史冻结内容只能作为历史展示。

控制中心默认折叠候选与历史，明确显示归属、未验证和暂停使用。当前依据可以展开文字；过期依据转到历史逐字稿查看。多来源的完整专用来源浏览器及精确历史片段高亮尚未完成，不把来自另一来源的引用显示成当前文件文字。

## 技术选择与代价

本切片采用同步事务冻结直接依赖，备选为 epoch 根屏障与后台图扫描。当前只有上下文→候选一层，事务能给出明确原子边界；图规模及长链扩大时，需要按既有架构实现根屏障与扫描，不能在等待扫描期间放行旧结果。

上下文采用内容快照加规范化版本引用，备选为仅保存版本引用、每次重建发送内容。快照保留实际输入和预算、便于核对调用，但增加原文副本；未来删除与权限传播必须覆盖 snapshot_json/refs_json，不得把它们当无约束技术日志。当前尚无删除入口。

数据库升级到 schema 4；包格式 3 覆盖十类表：原有六类，加 contexts/context_inputs/model_attempts/claims。恢复兼容格式 1/schema 2 与格式 2/schema 3；未知新版本拒绝。恢复先校验上下文摘要/预算/输入关联、候选真实引用、状态和结果回执；reserved 调用改为 unknown，不自动执行。
