# M2 文本模型真实驱动

日期：2026-10-10。接续[来源权限与模型端口](m2-source-policy-model-port.md)。已将 Responses 兼容 HTTP 驱动接入 Core，并由开发检查工具进行一次真实合成文本试验。控制中心尚未装配云端执行入口，完整 M2 与认知—行动—反馈闭环仍未完成。

## 范围与行为

使用用户已经提供的项目 `.env` 中的地址与密钥。本次实际服务为 `api.chiyi.cc`，模型请求名为 `gpt-6.1-sol`，不是直连 OpenAI；官方价格、保留政策和模型来源不能直接套用。密钥只用于请求头，不进入请求正文、资料库、错误、迁移包或版本库。正式应用的凭据保存仍待系统钥匙串实现。

驱动仅处理已选定且允许云端处理的文本。请求包括来源、逐字稿版本、片段身份和文本偏移，省略文件名、原件路径、音视频及媒体时间字段。当前材料归属为 external/unknown，不声称内容属于用户。输入最多 4000 Unicode 标量，完整请求最多 16000 字节，输出上限 2048 tokens，响应最多 256 KiB；标量/字节上限不是精确 token 或人民币预算。

一次调用只发起一个 POST `/v1/responses`：无应用重试、提供方切换、轮询、工具或自动后续操作。使用临时网络会话、禁用缓存/凭据与 Cookie 存储、拒绝 HTTP 重定向，等待上限 60 秒。仅接受已授权 HTTPS 主机及 `/v1` 根路径；提供方身份进入调用记录。请求中 `store=false` 不能证明兼容服务实际不保留数据。

沿用 Core 持久 reserved 与权限版本检查，返回后再次校验来源和出处。请求交给传输后，撤回权限不能收回已发数据；晚到结果不会入库。当前还没有完整调度、持久模型 job、跨调用去重或生产预算控制；不得把驱动直接接成无人值守的无限请求。

## 响应解析与失败边界

使用严格 JSON Schema 定义 claims，逐层拒绝额外陈述字段、未知归属、缺失或非法引用、工具输出、多个结构化文本输出和不完整消息。结构检查之外，Core 校验实际选入来源、逐字稿版本和片段关系。每条陈述仍为 unverified，模型成功不等于用户认可或事实证实。

completed 且结构/出处合法才可提交；incomplete/refused 拒绝候选并保留合法 usage。合法 usage 后遇到无效陈述，也保留用量。非 200 HTTP 状态记录 rejected；传输异常记录 unknown，两者费用均未知，不自动重发。仅记录固定分类和状态码，不持久化服务错误正文或请求头。没有 usage 仍是未知，不记为零。

HTTP 驱动与传输分离，以内存传输验证格式、限制与失败，再用同一 Core 做真实请求。相比直接复用 Python 探针，Swift 驱动复用原生资料库、权限与提交边界，避免两套认知存储逻辑；相比立即引入第三方 SDK，当前只需一次文本请求，选择系统 URLSession，显式实现边界。后续需要流式、工具或复杂生命周期时再重新评估 SDK。

响应格式依据 [OpenAI 官方结构化输出文档](https://developers.openai.com/api/docs/guides/structured-outputs)，实际兼容性由本次第三方实测确认；一次成功不足以确认服务稳定性。

## 验证结果

- 37 项核心测试通过：含七项 HTTP/响应边界测试与一项真实驱动解析失败后的用量持久化检查。HTTP 302/401/429/503 模拟均只调用一次，不泄漏服务正文；仅本地内容在传输前拦截。
- 单次真实合成试验约 8.01 秒完成，输入 373 / 输出 238 tokens，共两条 external/unverified 陈述。保留“可能有帮助”“不必立刻变成任务”，没有生成用户观点或任务。未发送个人文本、历史、录音或视频。
- 同试验目录再运行被提前拒绝，调用记录仍为一条；没有第二次网络请求。
- 真实模型结果结构化导出/空库恢复成功，五个认知与权限表逐项一致、外键正常，恢复无网络执行。资料恢复为 reference_only，不假装原件已打包。
- 原始愿景 23 个文件摘要未变化，AGENTS.md 未扩写。

脱敏结果见[验证汇总](../research/evidence/responses-driver-2026-10-10.json)。这次测试证明从授权文本、真实模型到带出处候选的工程通路，不证明真实表达质量、用户认可、任务执行或完整产品验收。

