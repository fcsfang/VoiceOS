# M2 候选审阅与认知更正

日期：2026-10-10。接续[控制中心理解入口](m2-control-center-understanding.md)，落实 PRD-COG-03、PRD-MEM-03 的明确认可、独立证据及修订要求的一部分。已实现认可、拒绝、文字/归属更正和可回溯审阅历史；证据更新、真正的用户观点演进、完整派生图与行动反馈仍待实现，不宣称完整 M2 或产品验收通过。

## 产品行为

候选详情提供“我认可这个观点”“拒绝候选”“更正认知”和“审阅历史”。沉默、关闭窗口和模型成功都不会认可内容；初始审阅状态为 pending。

明确认可只记录 endorsed，不把外部主张或 AI 推论改成用户原始表达，也不等同已理解、已验证。原始归属、来源和证据保留；当前证据仍为 unverified。用户在纠错表单中可显式调整外部/AI/不明归属，这也不自动生成用户原始观点。

拒绝记录 rejected，默认当前认知查询排除该候选；详情仍可查看历史。用户可在依据有效时重新明确认可或更正，所有操作保留版本。已因来源或授权失效而冻结的候选只能回溯，本切片不提供复活路径。

更正必须修改文字或归属并填写原因，保存后重新 pending，需要新的明确认可。它标记为纠错，不作为真实观点变化；既有出处保持不变，不为新表述捏造证据。这个入口不能修改来源逐字稿，也不能新增来源；来源文字仍通过既有逐字稿更正处理。

## 存储、接口与取舍

schema 6 增加 claim_reviews 和 claims.review_version。模型 claims 的原始文字/归属/引用/结果摘要不覆盖；审阅记录保存前后版本、完整有效内容、决定、原因、说明、用户 actor、命令/输入摘要和时间。版本 0 为模型原始结果，后续按单调版本排列，读取时以最新审阅版本构建有效内容。

选择独立的追加审阅记录，避免直接修改模型结果导致原始结果摘要失效；也暂不复制整套 Claim 身份和出处，减少复用错误与迁移负担。认可、证据和出处可用性保持独立：认可历史可存在，但冻结仍阻止当前使用。未来任务或关联依赖必须引用相应认知版本，不能只靠稳定 claim ID；目前不存在这类派生模块，完整影响传播尚未实现。

reviewClaim 先核对出处有效性和 expectedVersion，然后在同一无 await 的事务中追加记录及推进当前版本。旧版本请求拒绝；同命令同输入返回原回执，不复活内容；改用同命令提交不同输入拒绝。认可/拒绝不能同时暗改文字。AI 模型响应格式不包含审阅字段，模型端口不会调用用户审阅接口。

迁移包格式 5/schema 6，十二类实体，新增 claim_reviews。旧格式 1–4 均可恢复，旧候选默认审阅版本 0；恢复核验审阅版本连续、当前指针/历史数量、原因、状态及内容变更的一致性。文件摘要正确也不能掩盖缺失审阅历史。已升级库不应再用旧二进制打开。

## 验证与范围

- 45 项测试通过：认可不改变来源/证据、回执/CAS、拒绝排除当前查询、更正重置认可、冻结不可审阅、原稿与修订迁移保留，以及缺失审阅历史拒绝恢复。
- 九项真实 SIGKILL 本地认知检查通过：新增 reviewUncommitted/reviewCommitted，验证记录与当前版本一起回滚或提交；认可提交后仍为 ai_candidate/unverified。全部为开发夹具，零网络/外部操作。
- 含冻结候选与真实模型记录的 schema 5 库复制升级到 6，五个原有认知/授权表的已有字段全部保留，外键正常；真实旧格式 1/2/3 恢复成功，格式 4 用于本次 UI 隔离库恢复。
- 原生界面使用前轮合成资料，在独立测试库中模拟认可→更正→拒绝，核对四版历史、出处、归属和 unverified；更正原因明确标注开发测试。这不代表用户实际认可或改变观点，未操作正常个人资料库。
- UI 资料以格式 5 导出并恢复，六个认知/授权/审阅表逐项一致；重开后的拒绝状态、原稿与历史保留，无新模型调用、无音视频上传、无外部动作。
