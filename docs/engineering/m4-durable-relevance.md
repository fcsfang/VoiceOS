# M4：相关性调用持久记录

日期：2026-10-11。状态：核心切片已实现，完整 MVP 未验收。依据：[ADR-010](../adr/010-durable-relevance-attempts.md)与[快照边界](m4-relevance-boundaries.md)。

相关性选择现在先保存调用和全部输入，再进入一次直接调用。结果只接受已发送候选中的最多三个 ID；不新增观点、关系或行动。模型/提示/结构版本与完整输入摘要共同形成防重发身份，同一轮查询不能因重开或重新准备快照再次调用。调用状态与输入有效性分别记录：已完成请求也会因原文更正或权限变化冻结。

发送或接纳阶段发生中断时，已保存的 reservation 在重开后变为 unknown，不自动补发；只有事务提交完成才保存 completed 结果。已收到的非负 token 用量独立保留，即使结果因迟到、取消或授权变化被拒绝。token 不是价格，账单金额仍未知；异常详情不直接写入持久记录。

SQLite schema 12 / 包 v11 增加相关性调用与有序输入两表。恢复校验查询预算、全部原文范围、来源与文字版本、历史授权链、模型身份、防重发摘要以及结果引用；仅重算 manifest 文件摘要不足以使伪造结果通过。恢复后相关性历史统一 frozen，未完成请求 unknown，不恢复执行许可。历史更正前文字仍可作为迁移历史保留，但不能作为当前可用结果。

## 验证

- 117 项自动化测试通过，零失败；新增十项覆盖完成/空结果、未知传输、非法结果/用量、取消、授权变化、重复查询、重启、迁移及更正后授权撤回的历史。
- 三个真正 SIGKILL 检查点通过：reserved 与 uncommitted 重开为 unknown，committed 重开为 completed；各自二次恢复稳定，再次请求不调用端口。调用标记由独立同步文件证明为 0/1/1 次，不借助网络。
- schema 11 形状的独立合成库升级至 12，旧来源身份保留；十个实际此前导出的 v1–v10 包分别恢复至 12，完整性及外键检查通过。
- 应用重新构建并通过本地签名校验；23 个愿景原始文件摘要保持不变，AGENTS.md 未增加规则。

首次强退工具只调用 kill 后立即返回，信号交付前可能继续提交；该轮检查被判无效。修正后在 kill 后停住控制流，重新创建独立库完成三处验证。此前其他阶段的故障记录未在本阶段重跑，不将历史次数当成本轮验证。

复现：先构建，再运行 `python3 scripts/app/validate_relevance.py --output runtime/<全新目录>`。完整测试为 `env -u SDKROOT xcrun --sdk macosx swift test`。旧包检查依赖 runtime 下已有的实际历史导出包；没有旧包时不能据脚本成功推定全部旧格式已测。本轮证据见[摘要](../research/evidence/relevance-durability-2026-10-11.json)，原始日志位于忽略目录 `runtime/relevance-durability-2026-10-11-r2`。
