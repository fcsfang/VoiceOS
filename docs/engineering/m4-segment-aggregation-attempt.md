# 整篇聚合持久调用

日期：2026-10-12。状态：独立调用预留、整篇判断暂存、恢复和迁移已实现；真实云端驱动及最终认知提交未实现。

## 实现

schema29新增`segmented_aggregation_attempts`，每个父批次仅一个聚合尝试，状态沿用reserved/completed/unknown/rejected与current/frozen。producer_sequence与原模型及片段提取共享顺序，必须晚于全部片段回执。含聚合尝试导出v29/schema29，其他数据仍按原范围导出v24–v28。

`runSegmentAggregation`验证来源、权限、实际聚合端口和全部片段completed/current。请求固定完整证据账本、父范围摘要、片段attemptID/resultDigest/producerSequence及聚合端口，不带音频、凭证或完整原始逐字稿附件。片段不足不预留；完整证据超过预算或存在未解决断句则阻塞父批次并保留历史。

预留提交后端口只能直接发送一次文本调用，无工具和隐式重试。响应必须完整且通过全部证据/行动覆盖、重复关系、原话依据和用量校验。成功结果仅暂存：父批次仍queued，不能显示整条链完成，不能生成认知或提醒事项。

来源更正/撤权、批次取消、配置漂移或Task取消使迟到结果冻结；响应和已知用量仍保留。传输异常或结果事务失败记unknown，不重发；提交后异常不覆盖完整回执。启动把reserved转unknown，保持父终态；不自动启动调用。

迁移保留完整输入/响应与片段身份，全部冻结，reserved转unknown。历史校验重新生成账本及请求，比较摘要、片段回执与顺序；聚合成功响应再做结构校验。历史使用原逐字稿和授权epoch，不用当前文字倒推历史。

工程选择沿用ADR027的独立暂存域，新增聚合表而不扩宽旧ModelPort完整上下文回执。代价为独立用量/迁移入口；可以暂停这一管道而保留旧文字处理链。通用端口暂不提供真实HTTP驱动。
