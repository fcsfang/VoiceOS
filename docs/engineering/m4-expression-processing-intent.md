# 单份表达处理意图与闭环衔接

2026-10-12；只读准备已实现，持久队列、保存入口和自动执行尚未接入。产品依据为既定的认知—行动—反馈闭环、P01自主普通任务、P02文本授权和P04默认静默。

## 当前缺口及首个范围

普通“保存表达”目前只保存本机原文。后续允许云端与理解分别操作，理解成功后关联已接入；这不能称为保存即自动闭环。首个衔接切片限定为用户明确选择“保存并处理本次文字”的个人user_text，复用已有理解、行动及关联回执。普通本地保存保持可用；不扫描旧来源回填，不自动处理讨论个人回合、导入媒体或尚未转写的音频。后续语音入口复用同一模型阶段，但必须先有可核对的本地逐字稿和对应处理意图。

## 已实现的只读边界

ExpressionProcessingIntentSnapshot固定完整当前文字/来源版本/逐字稿版本、4000字符预算、权限epoch及认知/关联两个端口身份；两个端口必须同目的地、身份字段有限且非空。云端意图准备要求已有本次文字授权，准备方法本身不能授予云端权限。快照不携带key、不写入模型尝试、不创建候选或任务，也不代表已入队或获准派发。

消费前重新准备并比较完整上下文、权限epoch、固定端口及摘要。文字更正、撤权后再授权、任一模型/提示/Schema/目的地改变，都不能让原意图自动覆盖新范围。此处固定配置比理解/关联的历史去重更严格：去重回答“旧请求不得重发”，意图回答“尚未发出的新请求只能使用当时选择的端口”。历史成功回执仍由续接机制保留原身份。

## 后续持久执行契约

新增队列项前先完整保存原文，再记录显式用户处理命令、来源版本、权限epoch、快照摘要及当时配置；原文保存成功而授权/入队失败须分别显示，重放同一保存命令不能报告未入队为已处理。队列必须落盘后才能显示已排队，不以窗口Task或内存数组充当持久意图。

规划状态queued/running/completed/unknown/blocked/cancelled/frozen。执行器按固定顺序处理一个意图，进入模型阶段前再次核对文字、配置、权限和取消状态；成功理解立即可见，并独立触发现有提醒核对，然后进行静默关联。认知和关联各自最多一次请求，无隐式重试。noCandidates和paused如实保留阶段结果，不把它们称为已证明没有关联，也不制造通知或未回应债务。

启动只恢复已明确持久化的queued/running意图。running恢复时先读取两阶段实际回执：认知unknown/rejected阻断后续；认知completed且关联未预留可继续一次关联；关联unknown不重发。完成/终态不能因启动、配置变更或刷新再排队。配置不符保留blocked供明确查看，不能隐式换服务。恢复包携带意图历史但冻结，不恢复队列自动派发许可。

取消未发出工作写入独立命令回执；取消在途工作不能声称撤回外部已收到文字，晚到结果须检查取消状态并保留可获用量。修改来源/权限使意图失效，不能仅用历史成功请求恢复当前资格。提醒事项继续由现有独立清单授权及行动策略控制；处理意图不是额外外部写权限。

## 实施与验证顺序

1. 只读快照与配置/权限/版本校验（已实现）。
2. 持久队列及迁移校验；确定表/包版本后新增迁移，旧包不要求新表。
3. 单项执行器与应用拥有串行调度；真实强退覆盖保存、入队、阶段预留及提交边界。
4. 保存入口和可见队列状态；用离线夹具核对关闭窗口、重启、取消和配置不符。
5. 有界真实自然样本及费用记录。合成与构建证据不能替代这一项。

首个切片不增加自动状态推断、跨事件问题合并或全局云端授权。这些边界已由既定方向和现有授权确定，无新增用户决策阻塞。
