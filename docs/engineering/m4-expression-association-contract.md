# 新表达的静默历史关联契约

2026-10-11。状态：只读准备、提案校验和持久执行已实现；结果卡片与持久忽略已实现；个人文字理解后的自动关联驱动已接入，保存即理解和自然质量尚未验收。依据 PRD-LOOP-01、PRD-FEED-01、AC-10/12/17/20 与已确认 P02/P04。自动寻找关联属于既定方向；本文只选择实现边界，不新增产品审批或默认通知。

## 触发与输入

个人表达已有可用当前逐字稿后触发本地准备；外部材料不冒充个人表达。必须有 sourceID、sourceVersionID、transcriptVersionID、当前 policyVersion、全文与片段身份。只有明确用户来源、文本云端许可和可用端口同时具备时才能发送云端关联判断；原始音频不参与。普通保存仍默认仅本地，不因加入自动关联改成云端。

先执行本地召回，在准备阶段明确只搜索可用于本次目的地的历史；排除当前来源自身、冻结来源和失效版本。云端候选目录只包含授权文本，不把已有手动选择的快照偷偷过滤后发送。选定目录锁定后，全部输入（含最后未被模型选中的候选）都须在发送前和接纳前重验。

首个切片限制一个当前个人表达、最多8个历史窗口、总输入8000 Unicode scalars、最多3条关联。当前表达必须完整进入快照；超预算记录预算不足，不裁剪原话或临时上传更多历史。召回预算不足或为空分别标记，不把这两种状态都解释成“没有相关历史”。无候选时无需云端判断。需要分段处理的长表达作为后续独立切片，不将首版受控测试边界宣传为支持无限长度。

normal最多展示3条，reduced最多1条，paused不启动新自动判断且不展示；已发送请求仍保留尝试与已知用量，暂停后晚到结果不能显示为当前反馈。恢复normal不自动重发未知请求。模式偏好不是文本或通知授权。

## 输出及归属

每条关联含历史 candidateID、当前连续原句、历史连续原句、AI给出的相关理由和关系提案（延续/限定/可能修正/同一问题）。两方引文必须精确匹配锁定版本和片段。理由不得为空或超过600 scalars，关联不能引用未知候选或重复同一窗口。空结果合法。

关联是AI判断，不改变认知归属、认可或证据状态，不自动合并观点，不创建行动，不证明支持或矛盾成立。历史中的问题只能显示为“待核对的旧问题”：在没有明确解决状态和依据时，不能断言问题尚未解决。建立正式问题生命周期前不把问号、相似性或AI文本猜测当作未解决状态。

卡片附在当前表达结果中，显示“为何现在相关”及双方原文入口。用户可忽略/减少/暂停，不要求回复，不主动进入B，不发默认系统通知。忽略身份包含当前表达版本、历史窗口版本与关系种类；重开或同输入重复处理不重新展示，同一次已忽略关系不能由新query UUID绕过。用户纠错后保留旧历史但冻结，新的输入版本才允许独立判断。

## 持久执行与迁移

自动关联不能直接复用只含query字符串的手动 relevance_attempts：现有快照缺当前表达版本/权限身份，query上限512，结果只有ID，随机queryID也不能充当自动运行去重键。备选把这些字段加入现有相关性快照会改变手动查询与旧包校验；选择独立的表达关联快照与尝试记录，复用召回、文本传输、权限重验、反馈偏好与未知结果规则。

派发去重键由当前表达版本/权限、目的地、模型/提示/Schema版本决定；完整快照摘要另包含锁定候选及其版本/权限和反馈偏好版本。候选刷新或偏好开关不能绕过去重重发同一表达。代价是同一表达不会仅因新增历史自动再次判断；输入版本或模型契约变化才允许独立判断。偏好变化后优先核对已有尝试，不因开关重放未知请求。模型调用前事务写入预留；actor内不await地检查重复；返回后原子提交结果及用量。预留后崩溃恢复为unknown，不自动重发；迁移包保留尝试和引文，恢复历史冻结且不恢复自动外发许可。晚到拒收仍保留用量和费用未知状态。

独立 expression_association_attempts 表已随 schema21/v20包落地；旧相关性/静默回顾记录仍可读取，不虚构缺失理由或当前来源锚点。

## 必须覆盖的回归

| 场景 | 预期 |
|---|---|
| 相同表达并发/窗口重开/重启 | 在途最多1次，unknown不重发 |
| 当前或未选中的历史候选纠错/撤权/撤销再授权 | 晚到拒收，保留用量；卡片冻结 |
| 当前表达仅本地、历史仅本地或端口缺失 | 无云端调用，保存和本地召回不受影响 |
| 超预算、无候选、无直接相关结果 | 三种状态分开；不得裁剪、补造关联或强发请求 |
| 同词不同问题/否定或条件/跨措辞 | 可返回空；相关理由和双引文可人工核对 |
| reduced/paused、忽略后重开 | 数量正确，暂停无新派发，已忽略不复现 |
| 篡改结果并重算包文件摘要、删除候选/策略历史 | 恢复拒绝，不留下半恢复资料库 |
| 正常/unknown/冻结记录包往返 | 身份/用量/引文保持，不触发模型、通知或行动 |

先实现纯准备和提案验证，再做持久预留/故障/迁移，最后接应用拥有的处理任务及结果卡片。每步需要独立证据；直到自动触发、相关理由和问题状态均有实现与质量证据，W18继续partial。自然案例验证不由合成测试替代。


## 输入基础实施证据

`ExpressionAssociationSnapshot` 保留完整当前个人原话及其授权版本、历史窗口目录、目的地与反馈偏好版本。反复准备生成不同预览ID，但相同锁定内容得到相同digest；预览ID不是执行去重键。`validateExpressionAssociation` 重验当前来源及全部历史候选、权限epoch和偏好，不允许撤销再授权或暂停后沿用旧快照。提案类型只包含关系提案、双引文和理由，没有任务/认知认可/已解决字段。

6项新增回归覆盖只读无产物/稳定摘要、云端未授权与自引用拒绝、超预算不裁剪、空目录、当前授权撤销再授权、未选历史纠错、暂停/重复与伪引文拒绝、完整授权云端预览无派发、reduced数量及偏好变更。全套281项通过，含语义资源的签名构建通过；本轮0网络/麦克风/提醒事项调用。日志 `runtime/association-foundation-tests.log` 和 `runtime/association-foundation-build.log`。

本切片没有接自动检索或任何模型端口，没有新增数据库表和包版本；不宣称自动历史关联或W18已完成。下一步加入独立持久预留、unknown恢复、完整包校验和明确调用顺序，再开放自动处理卡片。

## 静默卡片与持久忽略

新增独立 expression_association_ignores 表（schema22/v21包），忽略身份锚定当前表达版本、历史窗口版本和关系种类，与预览UUID、模型身份和权限开关无关。重复模型版本的同一关联不重新显示。原关联尝试和用量保留；忽略不是删除、认知认可或完成任务。旧v20包实物恢复保留已完成关联并冻结，无新派发。

已完成记录的呈现偏好可变化：paused隐藏，reduced最多一条，恢复normal可重新显示未忽略结果；来源/授权变更仍冻结。在途响应仍严格核对发送时偏好版本，晚到拒收。卡片展示AI关系提案、为何现在相关、当前/历史连续原话及双方出处入口，不断言问题未解决。

294项测试通过；五处SIGKILL（含忽略提交前/后）与五次包往返通过。原生CUA验证卡片布局、双方跳转、暂停恢复、忽略及重启不复现。证据 [静默卡片验证](../research/evidence/expression-association-feedback-2026-10-11.json)。界面描述文字随后微调仅编译验证，不能冒充再次视觉观察。未接自动检索/生产模型，W18仍partial。

## 受控文本端口与处理入口

ResponsesExpressionAssociationPort 复用既有受限HTTPS传输和 ResponsesEnvelope，保留已配置 gpt-6.1-sol，不切换模型/服务。按 [OpenAI Structured Outputs 官方文档](https://developers.openai.com/api/docs/guides/structured-outputs)使用 text.format/json_schema/strict，识别拒绝和未完成响应；完整双引文与目录身份仍由本机额外校验，Schema不证明语义准确。一次POST、store=false、禁止截断、最多2048输出tokens、60秒、请求160KB/响应256KiB，无音频、工具、回退或重试。解析拒绝保留可获用量，额外字段/伪引文/未知关系拒绝。套件加载一次凭据后原子发布六个端口。

处理驱动只处理明确个人来源，尊重仅本地/暂停和可用模型。发送前先在本机排除当前来源和未授权历史，再按当前全文的最多16个512-scalar窗口召回，合并排序并选择最多8份历史、总判断输入8000 scalars。召回窗口只用于本机查找，判断输入仍包含完整当前原话；候选锁定后不偷偷过滤。未找到候选与有候选但预算不足分开，无候选不发送。相同表达/config已有尝试直接读取，不重新召回或发送。

应用的“理解并关联历史”完成个人文字理解后继续该驱动，由应用拥有处理任务，关闭视图不取消或重发；先刷新认知/行动并启动提醒事项回读，不让关联请求拖延行动可见性。讨论个人回合的显式整理也复用该驱动。外部来源不触发个人关联。仅保存、授权开关、选择来源、重启和配置变化都不自动回填旧来源；不会因此扩大普通保存的默认云端许可。当前仍需显式理解入口，不宣称已实现保存即自动理解的完整产品行为。

来源结果页展示关联理由和双原句、历史状态/冻结/已知tokens与实际费用未知；按来源核对入口不受全局最近20条回顾范围影响，切换选择不会短暂把上一来源结果归入当前表达。自动状态分别呈现暂停、权限、无模型、预算、无候选、在途、完成和未知。新请求产生实际费用仍未知，不依据合成用量推定账单。

304项全套测试通过，新增五项端口协议和五项处理驱动回归覆盖完整全文召回、私有历史提前过滤、晚到撤权、无模型/暂停/预算和单次未知终态；均为离线合成。日志 runtime/association-driver-tests.log，签名构建 runtime/association-driver-build.log。冻结记录和17/23 tokens已在实际来源页观察；真实生产关联请求与自然质量本轮未运行，不扩大AC-12/20验收声明。正式问题状态、主题级减少、保存即完整闭环及长期自然案例仍开放。
