# 表达处理审核修复

2026-10-12。针对[本轮审核](quality-review-2026-10-12.md)的四项 P2 修复；产品愿景、AGENTS、凭据及原视频未修改。

## 改动

1. 命令按固定文字、版本、授权和配置识别；随机准备 ID 仍属于完整快照审计身份，不参与命令语义指纹。同一命令重新准备后返回原记录，配置变化仍拒绝。早期 schema25/包 v24 摘要仍可读取与迁移。
2. 认知续接返回真实调用 ID，保留旧模型的生产者身份；取消后的迟到结果及调用失败也保存可取得的阶段引用。关联历史查询按来源、逐字稿及权限身份，不再错误比较两个不同用途的快照摘要。
3. 迁移和读取检查调用与具体来源、文字版本、授权版本及历史上下文的绑定。对另一来源的错绑，即使 manifest 校验和更新也拒绝；更正及撤权后的合法历史仍可恢复为冻结记录。
4. 启动修复 running 时，先读取持久阶段回执：未预留重新 queued；认知 completed 而关联未预留只续接关联；两阶段 completed 直接完成；unknown/rejected/frozen 保持阻断。发出前仍核对原快照、当前权限和当前配置，迁移历史仍冻结。

控制中心同时补齐原文保存成功、处理入队失败的区别，重放终态显示原回执，保存后选中新来源，保存中不允许编辑原文，错误可在录入窗口看到。

备选及取舍见 [ADR-023](../adr/023-expression-processing-intent.md)。没有增加模型重试、全局权限或跨应用执行范围。
