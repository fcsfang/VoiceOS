# M4 控制中心逐轮讨论

2026-10-11，W17 第三切片。模式 B 现有主动口述和文字入口、文字回复与历史；成果回流尚未完成，AC-11 与完整案例 B 仍开放。

## 使用与状态

资料详情“继续讨论”明确建立会话，不调用模型。工具栏“讨论记录”显示最近100段历史，选择旧记录不重发；恢复后的历史只读，明确建立新的讨论后才可追加。结束的讨论不能重新激活。历史引用详情展示当时的完整原文版本，不用当前纠错版本替换过去依据。

每轮可点击“口述这一轮”，复用原件封存和本地转写；停止/设备限时结束后先核对，再点击关联。已有个人录音也可选择；外部音视频、已关联来源及入口原文不能冒充新发言。空文字或仅标点的录音不能关联/发送；失败保留原件，可回到资料详情重试。录音保存成功与回合关联成功分别报告。

文字输入保存个人原文并关联，不自动调用模型。明确展示本轮云端文本开关；其默认开启，只有点击保存/关联才登记该轮文本许可，原始音频不上传。关闭可保存本地回合，但本次讨论不能云端发送。改变已入会话的处理限制会冻结旧会话，需要核对后明确另开；不会通过授权恢复旧执行状态。

点击“发送本轮文字”才调用已配置的文本模型；全部入口历史和个人回合必须允许云端文本。已有调用、无新发言、缺许可或未配置模型时禁用发送。等待期间仍可明确结束；晚到结果不重新开启或生成观点/任务。关闭前台不结束讨论或重发，重启只恢复历史。AI回复分原文引用与分析/建议，用量可回溯，实际费用未知。

引用详情第一次呈现为空的问题已在实际界面发现并修复为携带完整预览对象的呈现；实际界面确认原文和版本显示。转写后状态明确显示无可用发言，不能把环境音当讨论质量通过。

## 实测

191项测试通过，0失败、0跳过；含语义资源签名构建通过。实际 UI 检查：恢复后两轮历史与冻结状态、当时引文版本、明确进入无调用、保存无调用、正常回复、同轮发送禁用、等待中结束与晚到拒绝、重启无续发、合成口述仅本地关联与发送禁用均通过。

本切片实际两次云端合成文字调用：第一轮 completed，输入759/输出393；第二轮等待中结束，响应 rejected，已知输入1339/输出252 tokens保留，没有可消费回复。此前夹具两次调用是上个切片，不计为本次新发送。没有认知提取、观点候选、行动、提醒事项外写或音频上传。

讨论页进行了两次真实环境音采集，各10.000秒自动停止、484096bytes原件、本地转写0字符。不需要用户讲话，按持续本地测试授权执行；不会关联或发送空转写，不证明自然语音质量。另有0.5秒合成音频与可控制转写端口，只用于成功关联路径，不冒充自然语音识别验证。

工程修正：SpeechPort携带实际backendIdentity，未标识端口记为unspecified-speech-port；原生端口为Apple SpeechAnalyzer，合成夹具明确独立名称。现有历史不重写；新结果与迁移保留实际端口身份，避免可替换端口被硬编码成原生识别。新增测试验证这种身份随导出恢复保留。
