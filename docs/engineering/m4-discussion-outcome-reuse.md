# M4 跨入口成果复用：准备契约

2026-10-11。完整讨论输入与新增成果目标现在分开表达；233项测试通过，包仍v17/schema18共26表。本节记录最初的只读规划切片；持久复用执行进展见下节。没有生产驱动或提取按钮。

`conversationOutcomeReusePlan(for:)`在验证完整输入后读取既有生产者身份。个人版本已有认知理解尝试，无论完成空结果、未知或拒绝，都不作为新的个人候选/任务目标；另一未整理回合仍保留。AI段落本地复制不消费个人目标，完全相同AI原段落必须沿用原候选。已有认知和行动不复制，审阅/行动状态仍通过原记录读取；规划不重置认可/拒绝、更正、完成或费用。目录仅保存原尝试、原候选和覆盖关系，未复制观点内容或把它们变成新增云端文本许可。

完整来源和全部AI历史继续保留在原输入，目标选择不缩小输入预算或授权检查。新个人提案只能引用未消费个人版本；AI新分析可参考完整旧上下文，保留AI归属。完全相同原AI段落不能再次入候选；不同分析不是通过语义相似度强行合并。执行前和返回后必须重新读取目录，另一个入口新增生产者使旧计划失效。在途个人请求或未完成AI复制阻断准备，不把未知结果重发。恢复后的冻结讨论不能用历史重建可执行目标。

规划校验不等于执行授权。后续须将目录与持久请求同时预留，并验证迁移中不能删除先前生产者、伪造可新增目标。单纯比较当前目录不能校验历史：后续生产者会合法出现；只靠创建时间也不能分辨同秒竞态。拟使用单写者生成的持久生产者顺序，将提取预留前已有身份与之后新身份分开，保留完整快照与防晚到屏障。嵌入身份目录比建立独立复制观点/行动表更易保持原审阅与模块复用；实现前补历史范围校验及旧包升级。

新增7项测试覆盖只读/完整输入、个人原身份与完成/拒绝保留、空/未知/拒绝消费、AI原段落复用/新分析、准备后的竞态、在途与权限变化、恢复冻结。233项全套通过。实际CLI两次跨进程规划保持相同结果，生产者/候选/行动数量不变，原AI候选及未整理个人目标同时保留。23份原始愿景hash未改。本切片0云端、0录音、0外写；未进行新增原生界面验收。

复现：在新的隔离库生成`discussion-candidate-fixture`，用`outcome-reuse-plan <资料库> <会话ID>`输出脱敏身份目录。准备命令会保存来源Context，目录读取与验证本身只读。[证据](../research/evidence/discussion-outcome-reuse-plan-2026-10-11.json)，[持久成果前置](m4-durable-discussion-outcomes.md)。

## 持久复用执行：2026-10-11

`prepareReusableConversationOutcome`现在把原身份目录与完整讨论快照组合，交给已有持久端口。提取预留把这份快照与唯一生产顺序同事务保存；调用前与接纳前重读目录，排除自己的在途记录但包含其他入口的新记录。候选/任务与双重出处结果仍一次原子提交。只提交新提案；已有成果通过priorClaimIDs沿用原身份，不复制观点、重置审阅或再创建原任务。即使全部个人版本已整理，仍可生成新的AI分析，保持AI归属。

旧的无复用目录接口保留首切片隔离规则；新的显式复用准备接口允许已有个人理解和AI保留共存。完成空结果、未知或拒绝的个人理解仍消费原版本，不通过混合入口重发；此处可查看原记录，不能伪造丢失输出。已存在AI原段落以原候选呈现，新分析另存。新个人提案只能以未消费回合原话支持。

历史核验只重建提取生产顺序之前的目录；后来的生产者不会被误当作当时遗漏。迁移可检查重新计算hash后删除旧身份、重新开放旧个人目标和冒充旧包格式的行为。v18/schema19足以携带可选复用目录，无新增数据表；v1–v17成果仍按无目录旧路径解码，旧格式不能冒充带目录的新成果。

原成果若使用了讨论之外的依据，更正/撤销该依据也冻结共享成果。按生产顺序传播，可跨后续复用会话传递冻结，即使这些会话的入口本身仍有效。恢复冻结新的成果候选/行动及AI原段落；原个人候选与任务沿用既有恢复策略和授权规则，身份、完成版本保持。恢复不携带提醒事项连接授权。
