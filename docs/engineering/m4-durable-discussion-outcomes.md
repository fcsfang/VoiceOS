# M4 结束讨论成果：持久执行与原子回流

2026-10-11，W17混合成果的持久基础切片。226项自动化测试通过，包v17/schema18共26表。生产提取驱动与提取按钮尚未接入；历史界面可查看工程夹具产生的成果。本阶段不声明完整PRD-DIA-02、案例B或AC-11通过。

## 已实现

仅对依据有效、明确结束的讨论执行一次完整提取；结束操作本身不调用模型。完整快照保留入口原文、所有个人回合、最后AI回复及失败/未知回执，不截断。独立成果尝试以会话身份防重，调用前保存快照和身份，换模型或准备命令也不能重发未知请求。端口不执行工具、不上传音频。

候选、个人明确行动及完整双重出处结果同事务提交。个人成果只能以个人回合原话支持；AI观点保持待核对、未验证。AI行动建议保留为结构化元数据，不用AI引文冒充个人承诺。明确完整的个人普通任务复用原有P01路径；跨轮指代暂留机会，否定/条件不得被静默删除。没有实际来源引文的AI候选使用讨论触发点，界面明确该原文不能证明AI猜想。

发送前和返回后重验全部实际来源、版本与权限。来源更正、撤销或迁移冻结成果与依赖行动；历史仍可查看。已知用量在拒绝和晚到情形保留，不推算未知账单。结果反馈默认仅本地，独立关联当时行动版本；任务完成不改变认知候选的审阅或事实状态。

历史界面分别预览当时个人原文和原AI段落，候选可返回完整讨论成果。整段结果中已经保留的完全相同AI段落直接返回同一候选，保留已有审阅状态。查看历史不产生调用或新候选。

## 暂时边界与下一步

任一个人回合相同原文版本已有理解尝试，或已有独立AI段落保留时，首切片拒绝新的整段提取；等待期间也检查。已有整段尝试时，个人单轮整理拒绝再次理解同一版本。这是尚未实现跨入口共享成果身份的工程限制，不改变语音优先、最大普通行动授权或逐轮讨论的产品方向。

下一步明确完整输入与可新增成果目标的区别，将已有候选/行动作为原身份关联，保留未知尝试而不重发；先完成可验证的去重契约，再接入实际文本驱动并开放提取入口。不能仅靠提示词或语义相似度判断两个个人任务是同一件事。仍需实际模型的跨轮否定/条件、指代、多方案歧义和自然样本质量检查。
