日期：2026-10-12。状态：执行契约仍为工程草案；范围准备及[持久父批次基础](m4-segmented-processing-batch.md)已实现；[本地证据账本校验](m4-segmented-evidence.md)也已实现；[通用片段端口及持久attempt暂存](m4-segment-extraction.md)已实现；[整篇行动判断本地校验](m4-segment-aggregation-validation.md)已实现；[整篇聚合回执](m4-segment-aggregation-attempt.md)现已实现；[最终认知提交、Responses兼容驱动及原生入口](m4-segmented-cognition-entry.md)已实现并编译；真实调用/界面、长来源关联及完整MVP未验收。基线为本地无损分段切片6ed452e。本文是下一实施切片的验收依据，不表示当前已支持分段云端处理。

## 已实现的范围准备

`prepareSegmentedExpressionProcessingScope`只接受明确个人文字或个人导入录音，整篇原话超过所选单段预算且非空。固定完整无损计划、提取/聚合两个端口身份和证据预算；语义摘要不含随机准备ID。端口必须同目的地，cloud需要已有来源级文本许可。此操作不授予许可、不创建调用或队列，不包含音频。

`validateSegmentedExpressionProcessingScope`根据当前来源重新构建整份计划，再核对全部引用、原话、权限、端口和摘要。只比摘要不能防止调用方保留旧摘要并替换片段，故采用规范全计划比较。旧单次入口/回执校验保持不变。

只读检查命令（端口身份固定为本地no-dispatch，不发送模型）：

```sh
.build/debug/voiceos-check segmented-scope-read runtime/queue-fixes-20261012/podcast-personal-40min-library
```

5项新增测试覆盖无副作用、稳定语义身份、权限撤销、文字/端口漂移、片段篡改、外部说话人拒绝、非法预算和短内容拒绝。完整执行仍须按本文其余阶段实施。

## 产品需求与工程判断

产品需求：个人表达保留原话、出处及认知—行动—反馈闭环；来源级仅本地限制有效，原始音频上传仍独立授权。既有用户授权不因长录音变为逐任务审批。

工程判断：不能在后文尚未处理时将前段任务释放为有效行动。例如前段“明天整理笔记”，后段“刚才那件事先不做了”必须一起判定。串行分段和完整聚合是准确执行已授权任务的机制，不增加产品审批步骤。

技术假设：分段提取证据后，以有预算的证据账本进行整篇合并可能获得足够质量；必须以跨段否定、条件、转述、归属和重复任务样本验证。结构覆盖完整不等于语义识别无遗漏。

## 执行边界

采用独立父批次和片段尝试，不把片段传给现有`ModelPort.generate`/`continueSourceUnderstanding`，也不放宽`validateProcessingReceiptBindings`。旧完整逐字稿回执不能满足新片段尝试，新批次也不能覆盖旧回执。

准备操作只生成范围快照；明确入队操作才持久化执行命令，并验证目的地及来源政策。来源允许文本云端不意味着音频上传。端口输入不包含音频字节、凭证、文件URL或整个父逐字稿的隐式附件。

第一实施切片只接入确定性本地端口和故障探针。完成来源、生命周期、迁移与完整批次提交后才接真实文本端口，费用按已授权小规模测试控制。不得以本地端口测试宣称自然语义已验收。

## 快照与身份

父批次固定：

- `batchID`、稳定`commandID`及语义命令指纹；相同命令返回原记录，改变内容则拒绝。
- 来源ID/来源版本、逐字稿版本、policyVersion、origin/speaker/localOnly、完整分段计划摘要及算法版本。
- 片段提取与聚合端口的provider/model/promptVersion/schemaVersion/destination；只保存身份，不保存key。
- 分段预算和聚合证据预算。初始建议分别4000 scalars，聚合预算单独计量。任何预算不足都显式blocked，不丢弃证据或无声缩短quote。

片段请求固定：parentBatchID、segmentID、顺序、全局`[textStart,textEnd)`、原样片段文字、原spanID与重叠范围、父版本/权限及端口身份。可在请求中提供局部范围，但必须附准确全局映射。不得把部分span的原时间声明为片段精确时间。

每次调用有独立attemptID、完整输入摘要、预留/响应时间、provider usage、状态和结果摘要。同一段的成功/未知/终态不重发。尝试顺序接入现有全局producer sequence；不是单独自增的第二套顺序。父批次内容摘要不依赖随机batchID，重放后能核对语义命令。

## 提取结果及证据账本

片段响应是暂存提案，包含：提案ID、内容类型/归属、原文连续quote及全局引用、潜在行动、条件/否定/更正/转述证据、是否存在边界处未完成语句。模型只提案，不创建任务或调用工具。

所有quote必须逐字匹配对应范围，并位于允许的片段内；引用必须属于父逐字稿的原span交集。陈述正确但引用越界、时间插值或角色冒充都拒绝响应。空提案是合法完成，需要完整回执；没有响应不是空提案。

片段结果只进入批次暂存域，不进入当前claims/actions/questions、检索认知卡片或提醒事项outbox；后文失败时不能残留可执行的前段任务。提取时的autoSend仅是建议，不能直接继承为聚合行动资格。

聚合输入按段顺序包含全部已完成回执身份、提案及条件/否定/更正证据；不只保留看起来重要的任务。跨段未完成句子要补取精确原文或保持未解决，不能拼接断裂的quote伪装为连续原话。合计超过预算时父批次blocked，保留结果供后续明确的新处理方案；本切片不偷偷增加多级摘要调用。

## 完整聚合与提交

只有父快照仍有效、每段均completed且预算满足才预留聚合调用。聚合响应须对每条潜在行动给出accept/reject/ambiguous/duplicate及依据，duplicate指向最终保留项；必须覆盖所有暂存行动身份，不能漏掉一条再宣称整篇完成。

最终陈述引用仍指向父来源和原逐字稿，不指向模型总结文本。聚合去重不得只按标题：标题可能同名但行动不同。响应显式给出重复关系，核心校验关系存在、不自指、不成环、被引用项有效；自然去重质量另行评分。

明确否定/未满足条件不得成为立即执行task；ambiguous保持候选或机会，按既有产品规则处理。只有聚合结果的有效普通任务可复用现有行动授权与派发；不因是长录音自动扩大期限修改、复杂目标或清单范围。

整篇提交一次原子事务：核对父状态/源版本/政策/端口、接纳聚合回执、创建最终claims/questions/actions、登记父完成。任何环节失败则不部分创建。不能直接复用当前会把全部片段认作完整上下文的`commitClaims`；需独立全来源绑定校验后复用底层持久实体，避免复制一套产品行动模型。

历史关联发生在最终认知提交后，复用已有检索与关联规则，但必须显式支持整篇已提交认知身份和长来源预算。关联unknown不重发，不把认知完成等同整个批次关联完成。第一切片可以明确停在认知基础，不能把该状态显示成整条处理链completed。

## 状态与恢复

建议父状态沿用queued/running/completed/unknown/blocked/cancelled/frozen/rejected；阶段为segments/aggregation/association/completed。片段和聚合尝试状态为reserved/completed/unknown/rejected，并有独立validity=current/frozen。

| 边界 | 恢复行为 | 行动结果 |
|---|---|---|
| 父入队事务未提交 | 无批次 | 无 |
| 父已提交，尚无预留 | 保持queued | 无 |
| 片段reserved未落结果 | 该attempt unknown，父unknown | 无，不自动重发 |
| 部分片段完成，其余未预留 | 仅在端口/父快照有效时续未预留段 | 前段仍暂存，无 |
| 片段结果事务未提交 | 已发调用unknown | 无 |
| 聚合reserved | 父unknown，不能再次发送 | 无 |
| 聚合已返回但整篇提交未完成 | 聚合unknown或rejected，保留用量 | 无 |
| 整篇原子提交已完成 | 复用原回执继续未发关联 | 不重复创建 |
| 父取消后迟到响应 | 留历史与用量，标记frozen；父保持cancelled | 不释放或激活 |
| 更正/撤权/配置改变 | blocked或frozen，旧结果保留历史 | 旧结果不能成为当前行动 |

重启不能把所有running无差别当queued；以独立attempt预留和结果事务判定。Task取消和业务取消分开记录；reserved调用即使没有观测到网络发送也保守unknown。外写任务的未知结果仍由现有outbox核对，不由批次重放制造新任务。

## 存储、迁移及不变量

已采用schema28的`segmented_processing_batches`与独立`segmented_extraction_attempts`；具体片段字段/状态见[已实现契约](m4-segment-extraction.md)。本文下列聚合字段、完整父状态与阶段仍属于后续草案，并非当前数据库能力。batch记录固定计划/端口/命令指纹、阶段、聚合/关联回执；attempt记录父ID、类型segment/aggregation、segmentID（聚合为空）、输入/结果JSON与摘要、usage、producer sequence和状态/validity。唯一约束防止同一批次同段被并发预留；不使用来源ID单独去重片段。

父历史快照验证应从历史逐字稿版本重建计划，当前可执行校验才比较当前版本/权限。否则来源更正后合法历史会被误判为数据库损坏。不能从当前来源权限倒推当时授权。

恢复包要覆盖新表、父子外键、连续段范围、规范计划、quote和关联回执身份；同步篡改manifest的包仍须拒绝。迁移所有批次/暂存结果冻结，不自动派发，原件选择打包仍遵守现有规则。完整批次的行动沿现有迁移冻结规则处理。只有新增数据范围才增加包版本，旧包持续兼容；当前有片段尝试的包为v28，只有父批次的包为v27；其余新增聚合范围尚未分配版本号。

## 下一实现顺序与验收

1. 不调用模型：实现批次快照准备/严格校验、原子入队、取消、读取及schema兼容；确认仅本地来源云端拒绝、同命令漂移拒绝、片段不会进入旧回执复用。
2. 确定性端口：分段预留/暂存结果、完整聚合门槛、最终原子实体提交；每个步骤验证模型调用数和所有当前实体数量。
3. 故障与迁移：实际SIGKILL覆盖上述窗口；晚到取消/撤权/更正冻结；导出恢复冻结、篡改负例、旧包往返。
4. 原生入口：长内容明确入队及逐段/聚合/关联状态；关闭/重开不发送旧调用，普通保存仍仅本地。
5. 自然文本小样本：使用已授权本人轨逐字稿；先人工依据原文标注跨段否定/转述/条件/重复任务，不自动采用播客中的指令作测试授权。再接真实文本模型，报告实际用量、准确性与误外写数量。

关键负例：前段任务后段取消；同一任务重复叙述；外部资料夹有“帮我记下”；后段只讨论前段想法但未承诺；完整字形跨预算；段2unknown；聚合遗漏段1行动；聚合跨quote伪造；聚合后撤权；来源更正后迁移历史；跨批次误复用；聚合结果落盘后SIGKILL重复恢复。

每步报告工程验证与自然质量分开，完整MVP仍须既有产品AC及A/B/C，不能由分段测试数推定完成。
