# M4 个人讨论发言回流

2026-10-11，W17第四切片的个人发言部分；AI讨论段落转为独立认知候选仍待实现。不能宣称完整PRD-DIA-02或AC-11完成。

## 行为与取舍

讨论中的每轮个人原话都有既有来源身份。“整理我的这轮表达”明确选择一轮，复用 understandSource、版本化Context、持久模型尝试、候选审阅和行动提取；不建立第二套任务系统。结束后仍可显式整理尚未冻结的个人原话，结束本身不整理或认可。AI调用ID、其他会话回合、已冻结/更正的旧发言不能当个人输入；同一来源版本已有理解记录不会重发。

请求只含这一轮个人原话，入口历史与AI回复不进入本次提取。由会话关联进入既有来源处理，而不是把整段对话重新标成“我的表达”。短句若仅说“同意你上面的方案”，本切片不自动补全AI方案为用户主张或承诺，需用户说清实际判断/行动；结合完整多角色上下文解析成果是后续独立设计。

界面说明会发送这一轮原话，并沿用已有提醒清单授权。只允许文本云端许可已登记、当前原文版本与回合相同、讨论未冻结且没有理解记录的轮次；原始音频仍在本机。认知保持原有待核对/未验证规则，明确普通行动沿用P01和现有清单范围。来源详情“查看关联讨论”能返回当时会话，不会自动续发；最近100个关联是显示边界。

取舍：复用单来源流程减少实现与维护分叉，完整保留用户原文、行动状态和反馈历史；相比整段对话总结，对短指代的解析能力较少，却不会把AI建议直接转换成个人承诺。此边界不修改长期多角色成果回流目标。

## 验证

196项测试通过，0失败、0跳过，新增5项跨模块集成测试：结束后个人表达与原有行动流程、排除AI历史、同轮防重发、AI/其他会话身份拒绝、纠错前后屏障、迁移后原文/候选/行动/会话同源关系与冻结。含语义资源签名构建通过。

实际UI一次合成个人表达云端调用completed，输入597/输出491 tokens，实际费用未知。三个陈述保留“可能、容量足够、尚未验证”和“不打算学习摄影”；均user_tentative、待核对、未验证。仅“整理开发验证素材”成为普通明确任务，没有摄影任务，没有自动认可。

在隔离库标记合成任务完成，再保存结果反馈，反馈明确本次只验证流程而没有验证猜想。任务第2版完成，三个观点仍未验证；反馈只在本机保存。无已连接提醒清单，0外部写入。重启后通过原文返回原讨论，重复整理按钮禁用，没有第二次调用。

带原件迁移和重开后，模型尝试/来源/会话回合/三个候选/任务版本/反馈身份及媒体摘要一致。回溯链：反馈→行动第2版→原候选→个人来源和文本版本→conversation_user_turns→会话；恢复会话冻结、不继续调用。没有再次录音或上传音频。[非内容证据](../research/evidence/discussion-user-return-2026-10-11.json)。
