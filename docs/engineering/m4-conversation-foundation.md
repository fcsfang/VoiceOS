# M4 本地会话与个人回合基础

日期：2026-10-11。W17 初始切片，未实现 AI 对话回复/界面，未通过 AC-11。P07 已确认首版逐轮语音＋文字，接入与验收顺序见[讨论契约](m4-dialogue-contract.md)。

## 已实现

`beginConversation` 仅在显式命令下引用选定当前历史建立会话，重复命令不能更换来源；进入不触发模型/任务。`appendConversationUserSource` 关联已保存个人文字或音频的当前逐字稿，保留个人来源及当时文本版本；外部/未知身份来源不能成为用户回合。音频真实采集不因这个接口自动获授权。

追加回合与会话版本原子提交，旧版本、已结束/冻结会话、重复来源和变换命令内容均拒绝。`endConversation` 支持重复回执，可显式关闭冻结会话；没有观点认可、认知证据或任务副作用。结束后的旧进入命令不会重新激活会话。

来源更正/处理限制变化在既有原子冻结路径中冻结相关会话。读取重验实际来源和政策；历史发言保留原版本，不用更正后的文字替换过去说过的内容。启动与迁移检查上下文摘要、历史原文/片段/身份、会话状态和连续回合；伪造迁移字段即使重新计算文件摘要也不被接受。

格式 v14/schema15、23表；恢复冻结所有会话，不自动继续讨论或外写。实际 v1–v13 旧包均已恢复并重开验证，新的元数据与带原件包均保留会话和回合身份。

模型输入准备也已实现：保留全部入口历史和个人回合，开发总预算8,000 Unicode标量（可选1–12,000），溢出拒绝、不静默删历史；每个来源均须具有对应云端文本授权。发送/接纳前重验会话版本、完整来源和政策，新回合、结束或更正都会使旧输入失效。仅准备持久文本上下文，没有开始任何模型调用。

## 验证

170项测试通过，0失败、0跳过。新增15项会话测试，覆盖两轮个人发言、结束/重放、版本冲突、外部身份拒绝、更正/权限变化、重启、迁移冻结、迁移篡改拒绝及六处事务故障。六次独立进程 SIGKILL 后恢复/两次重放均只保留一个会话和一个回合；两次新格式迁移往返及13个真实旧格式恢复通过。含本地语义资源的签名应用构建通过。

测试仅合成文字/可控制本地端口，没有麦克风采集、云端请求或 EventKit 写入。复现强退入口：`python3 scripts/app/validate_conversations.py --root <新的独立目录>`；必须先构建当前 `voiceos-check`，不能指向个人库。

见[非内容证据](../research/evidence/conversation-foundation-2026-10-11.json)。

## 边界与后续

这是可复用的数据基础，不是可交付的模式B。AI 回合、单次持久模型调用、多轮输入预算/衍生隐私、晚到结果、控制中心逐轮语音/文字及认知/任务回流仍待实现。用户来源原件保存与会话关联分别返回结果，录音完成不自动证明关联完成。开发限制和备选见[ADR-014](../adr/014-local-conversation-history.md)。

第一轮模型切片先使用合成来源；实际音频质量/权限拒绝/睡眠仍单独验收。已完成的麦克风许可不用于再次录制。完整案例B、AC-11/16/17不会用本地表或测试数量代替。
