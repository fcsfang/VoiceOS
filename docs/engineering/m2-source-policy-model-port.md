# M2 来源文本权限与模型响应端口

日期：2026-10-10。接续[认知基础](m2-cognitive-foundation.md)。本轮建立来源级文本权限版本和可替换模型端口，使用内存模拟验证；没有实际 HTTP 驱动、云端生成、音视频上传或提醒事项操作。完整 M2 和 22 个产品 AC 仍未通过。

## 产品行为

每份来源分别设置“仅本地”或“允许文本用于云端”。导入仍默认仅本地；控制中心可以显式开启或撤回文本授权，并说明当前处理仍在本机。文本授权不包含原始音频/视频，不修改说话人归属，也不等于用户认可材料中的观点。

每次权限变化增加独立 policy_version，保留前后值、版本、命令与时间；同命令重交付返回原回执，内容不同或旧版本编辑拒绝。权限变更、上下文失效与直接候选冻结在同一事务提交。收紧再放宽也不复活旧上下文；需要准备新上下文。

冻结表示旧依据或授权已变化，不能继续沿用该产物；不表示用户观点改变，也不自动把内容判为错误。当前按整个上下文保守冻结直接候选；细分目的地权限传播和完整派生图仍是后续工作。

## 实现与取舍

Source 增加 policy_version；context_inputs 保存构建时的权限版本；contexts 独立记录 local/cloud 目的地；source_policy_revisions 保存历史。保留已有上下文 JSON 和摘要，不修改旧快照。相比在所有历史 JSON 中回填新字段，规范化版本引用减少历史重写；实际读取/发送/提交必须同时检查快照摘要和权限版本，不能只比较 local_only 的当前布尔值。

ModelPort 隔离执行实现。调用配置保存 provider/model/prompt/schema 身份；请求只包含实际选入的文本与来源/片段引用，不包含原始音视频字节、原件路径或凭据。Core 检查目的地和仅本地限制，先持久记录 reserved，再调用端口；结果提交复用既有出处校验与事务。

completed 响应才可提交；incomplete/refused 保留已返回的合法 usage 并拒绝候选。传输异常记录 unknown，不自动重发。晚到结果遇到更正或授权失效会被拒绝，仍保留已知 usage。未知字段为空，不当作零用量；已知 tokens 不当作实际人民币账单。

端口契约要求直接发起一次请求，不在内部排队、重试或调用工具。Core 当前没有持久模型 job、阶段自动去重、预算/HTTP 状态分类、实际价格或提供方主机绑定；不能将此接口当作已验证的生产云端流程。发送前核对不能收回已发请求，未来驱动必须对齐真实发送点及许可检查。

保留 local 默认目的地，避免既有文件导入开始自动发送；真实云端驱动、受验证的提供方配置与明确范围接入后，才把授权文本用于实际理解。已有 LocalTranscriptContext 名称描述本地构建的快照，发送目的地由持久 contexts 独立决定。

## 迁移与验证

数据库 schema 5，迁移包格式 4/十一类实体，增加权限变更历史；兼容格式 1、2、3。旧包保持默认权限版本 1、本地目的地；格式 4 才可恢复新文本授权状态，并核验版本历史与当前值、上下文权限版本。已升级资料库不应再使用旧开发二进制打开。

- 29 项核心测试通过；新增本地限制/目的地拦截（端口调用次数为零）、授权允许—收紧—再允许时的晚到拒绝、权限历史迁移及缺失历史拒绝恢复、完整/未完成/拒绝/未知响应及 usage 保留。
- 七项真实 SIGKILL 本地认知故障检查通过，在此前五个提交窗口之外增加 policyUncommitted/policyCommitted；核对权限值、版本历史、上下文和候选的原子边界。全部为开发夹具，零网络请求。
- 既有含冻结候选的 schema 4 库复制后直接升级到 schema 5，四个认知表的原字段逐项保留，外键检查通过；真实格式 1/2/3 旧包恢复成功。
- 原生界面开启、撤回文本授权后，隔离库最终 local_only=1 / policy_version=3，历史为 1→2→3；未发送文本或音视频。

真实媒体保存/转写恢复回归及脱敏证据见[汇总](../research/evidence/source-policy-model-port-2026-10-10.json)。故障脚本现在要求没有既有认知回执的输入包，否则提前说明夹具不适用；不能复用旧候选包把回执冲突误当作原子提交失败。
