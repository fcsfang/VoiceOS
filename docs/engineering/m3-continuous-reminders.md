# M3 持续连接与自动回读

日期：2026-10-10。接续[提醒事项创建与反馈](m3-reminders-feedback.md)，落实 PRD-REL-02/03、PRD-CTRL-01 的后台核对部分。产品愿景和四条 AGENTS.md 保持不变；仍未完成完整语音认知—行动—反馈 MVP。

## 用户行为与范围

控制中心“连接提醒事项…”先取得当前应用的系统权限，选择可写清单后点击“保存授权并自动回读”。取消选择不改变当前连接。持续连接在本机资料库保存；重启后不用再次选清单。后台仅核对这个清单中已有 VoiceOS 关联的任务，不自动发送未关联任务、不新建、不改名、不改期、不删除。停止按钮保留外部任务和历史；再次连接使用新的授权版本。

应用启动、激活、EventKit 变化通知、系统唤醒及五分钟兜底计时触发核对。通知只表示可能变化，不能作为完成证据；每次重新取得原清单中的关联项。清单失效或系统权限不可用时保留历史并暂停，不换默认清单、不自动弹权限请求。默认静默，不启用系统通知。应用真正退出后停止后台工作；目前不是独立常驻服务，不阻止 Mac 睡眠。

外部改名自动显示在本地标题旁；外部重开与已有本地完成不一致时显示冲突，保留双方。外部重新完成只更新观察，不重复推进本地版本或认可观点。“最近核对”与观察历史分开：成功读取相同内容只更新时间；内容改变或产生新反馈才追加观察，避免每五分钟复制相同历史。

## 工程决策与实现边界

采用现有宿主内的 ReminderRefreshCoordinator：500 毫秒合并通知，单个工作任务串行运行，忙时保留一次尾部请求；停止后取消调度，重新连接也等待旧处理退出，避免原生读取重入。前台发送与后台读取共享忙状态；前台结束补一次核对。备选逐通知直接并发查询容易重入，独立守护进程则增加生命周期、权限身份和通信边界；当前选择复用宿主，五分钟为可调整的工程默认，尚未提供频率设置或证明该值最优。

Core 持久授权包含清单 ID/名称、启用状态和递增版本。变更使用版本 CAS；后台带捕获的授权版本进入、每条关联前、异步返回后与整轮结束再次核对。撤销后旧结果不得生成观察/完成历史；旧请求异常可保留 unknown，不能冒充最新外部事实。系统读取已发出时无法保证取消底层 EventKit 查询，但可以阻止其结果应用。已经发出的外部保存也不能撤回；不承诺分布式事务或跨设备 exactly-once。

EventKit 的变化监听与原生权限检查在 VoiceOSPlatform，调度在应用，Core 依赖 RemindersPort；没有把业务规则塞入 AGENTS.md。Apple 的[变化通知说明](https://developer.apple.com/documentation/eventkit/updating-with-notifications)要求重新取得对象；实现不把旧 EKReminder 缓存或通知负载当真值。

schema 9 在 reminder_links 增加 last_checked_at，并新增本机 reminder_access 授权历史。逻辑包格式 8/schema 9 仍导出十六类实体，保留关联及外部观察，但不导出持续连接授权；恢复到空库必须重新连接，不能因迁移而获得自动读取权限。来源文本权限及其历史仍随包保留。旧格式 1–7 可恢复，旧 schema 8 原有数据无损升级。这是 [ADR-004](../adr/004-reminders-adapter.md) 的部分采用与 [ADR-006](../adr/006-portability.md) 的连接暂停约束实现，不改变用户已确认的产品方向。

## 实际验证

- 64 项自动化测试通过：新增授权 CAS/迁移不携带授权、撤销期间旧回读阻断、只核对已关联范围且相同内容不增历史、事件合并/工作串行及停止后重启等待旧任务。
- 13 项认知/行动与 4 项提醒事项真实 SIGKILL 检查通过，共 17 项。提醒事项崩溃测试仍用落盘服务替身，没有杀真实 EventKit 保存进程。一次认知检查误用了三份逐字稿输入，校验脚本的单源假设不成立；改用既有单源包后全部通过，并增加单逐字稿前置检查，防止以后将夹具不匹配误判为业务故障。
- 真实 VoiceOS 应用仅使用既有“VoiceOS 验证 2026-10-10”及原有合成任务：后台自动读到外部改名；外部重开自动显示冲突；再完成恢复 linked。本地仍 completed/版本 2，只有一条 external 完成历史，认知仍 unverified。没有按手动回读按钮，没有新建任务。
- 真正结束进程、重启原隔离资料库，持续授权版本 1 保留，原清单自动核对；停止后持久授权版本 2/disabled。再次外部改名和激活应用后核对时间、观察数量不变，手动回读按钮禁用。合成项保留完成，外部最新标题为“开发验证任务 — 暂停回读测试”；本地保留停止前的外部标题，不伪装已经读到新标题。
- 格式 8 导出/恢复，十一个历史/上下文/行动/关联表逐字段一致，持续授权为空。真实旧包格式 1–7 分别恢复到 schema 9、无持续授权，完整性与外键检查通过；实际 schema 8 的十六个原有表全部原字段保留。
- 构建、开发签名和 23 个愿景文件基线检查通过。隔离测试资料库没有移入默认个人库；本轮无新模型调用、原始媒体云端上传或删除。原生提醒事项可能由 Apple 自身同步，不以此宣称零网络。

脱敏汇总见[验证证据](../research/evidence/continuous-reminders-2026-10-10.json)。真实睡眠唤醒、连续五分钟兜底计时的单独触发、OS 权限撤销、离线/iCloud 延迟和 ID 变化尚未实测；当前接好了相应唤醒/计时入口，不能把代码存在当验证通过。底层 fetch 若一直没有返回，调度不会并发绕过旧请求；有界超时/取消和恢复策略仍需后续验证。生产签名、沙盒和完整三方字段修改未完成。
