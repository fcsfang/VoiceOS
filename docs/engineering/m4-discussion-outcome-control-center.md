# M4 讨论成果控制中心

2026-10-11。结束后的讨论现可明确点击“整理整段讨论成果”，使用现有文本模型生成持久成果，沿用已整理个人候选及AI段落身份。当前 Core 全套测试已扩展至 266 项；本切片原始合成验证、原生界面/重启/迁移检查与含语义资源的签名构建通过。完整自然案例B与MVP仍未通过。

## 行为与实现

仅结束、当前、无既有成果尝试的讨论显示提取入口。模型配置、本段全部个人原文与历史授权、保存版本、在途回复及录制状态决定按钮可用性；Core在预留前、模型返回后再次核对完整快照、权限和复用目录。打开历史、结束讨论与打开迁移库都不自动提取。普通明确个人任务沿用已有行动策略与清单授权；条件/指代保持机会，AI建议保持待核对，完成任务不验证观点。

应用先同步锁住提取状态，再启动应用拥有的工作任务；关闭讨论窗口不取消已发出的请求，重新打开不会重复发送。提取期间暂停切换会话及互相冲突的整理/回复操作，结果持久后刷新成果和已有提醒连接。UI只作提前提示，不能取代Store授权及版本校验。配置一次读取、四个模型端口全部校验后同时发布，避免分别读取文件造成配置不一致。

采用应用拥有任务而非窗口生命周期任务：后者关闭窗口会取消等待，可能留下未知结果；备选后台独立服务增加当前不必要的权限与通信边界。真正退出/崩溃仍依靠持久预留恢复为unknown，不宣称后台跨退出继续执行。现有完成、未知或拒绝结果不提供重发按钮；迁移成果保留身份/出处但冻结为历史。

新增三条候选：明确整理开发验证素材、条件不满足不调整/不阅读的表达、AI建议记录反例。仅第一条创建普通本地任务；原有AI拒绝与个人候选ID不变。界面核对角色、个人引文、AI引文与用量，点击个人任务完成至版本2，并保存仅本地的合成行动反馈。反馈关联到实际成果模型/原候选/行动版本，所有观点仍unverified。

退出并重启同库，无新请求；带原件包恢复保持成果、模型顺序/用量、候选审阅、完成任务、反馈与原件摘要。实际打开恢复库显示只读历史与冻结提示，无整段提取按钮，原AI拒绝仍在。另打开实际强退后恢复的unknown夹具，提示“成果提取结果未知 · 不自动重发”，既有成果保留，无重发入口。
