# 长逐字稿的本地无损分段

日期：2026-10-12。状态：本地计划、来源校验、控制中心预览已实现；分段模型执行未实现。schema26及迁移包选择规则不变。

## 需求与范围

原始媒体和完整逐字稿必须保留；长录音不能靠静默截断进入4000 Unicode scalar的单次认知预算。用户确认音轨1为混合、音轨2为本人、音轨3为电脑声音。本轮仅提取第二次录制的本人音轨，来源仍为个人导入音频，不伪装为麦克风采集。

分段是本地可重建计划，不是云端授权、持久队列或新的产品处理模式。普通保存、查看分段都不调用模型；超预算的原单次理解按钮禁用，界面明确说明分段模型执行尚未接入。

## 已实现契约

`prepareTranscriptSegmentation(sourceID:scalarBudget:)`只接受当前有效逐字稿和1…4000的分段预算。先复用来源、逐字稿片段及原件完整性校验；为完整本地校验临时增加上下文预算，不改变模型入口预算。

计划保存完整ContextTranscript（来源版本、逐字稿版本、归属、权限及原片段）和policyVersion、算法版本、预算、摘要。每段包含确定性ID、顺序、全局半开scalar范围、原样文字及原片段引用。相同快照与预算得到相同计划。规范校验重新生成整个计划并比较，不能仅靠摘要接受篡改。

切点落在Swift Character边界，优先预算后半段的句末/空白，再选原片段末尾，否则使用预算内完整字符边界。空白、换行、尾段都保留，逐段拼接严格等于原文。单个完整字形超过预算时拒绝，不拆坏emoji或组合字符。这里的“字符”计数具体为Unicode scalar，并非模型token预算或显示字形数量。

引用保留原spanID及全局重叠范围。时间仅表示包含该引用的原识别片段，不按字符比例推算分段精确时间；文字更正后未确认的时间保持空值。播放前再次校验计划和原件；仅saved且原件可用的来源允许播放。界面在逐字稿/权限版本或来源有效状态变化后废弃当前预览。

计划不新增数据库表，不迁移执行状态；从迁移后的当前来源重新构建。迁移冻结规则仍由现有队列/录音处理请求负责。

## 可复现验证

```sh
swift test
python3 scripts/app/build.py --semantic-model runtime/bge-coreml-2026-10-11
codesign --verify --deep --strict --verbose=2 dist/VoiceOS.app
.build/debug/voiceos-check transcript-segmentation-read runtime/queue-fixes-20261012/podcast-personal-40min-library 4000
```

383项测试通过，新增7项覆盖无损分段、复杂Unicode、跨span引用、时间未知、非法预算、政策/文字变化、伪造计划和原件损坏。签名构建通过。

同一期第二段录制，从120秒开始提取本人轨20分钟和40分钟，Apple本地中文转写分别得到3091和5280 scalars。前者以1500测试预算分为3段；后者按默认4000分为2段。两者无损拼接、来源完整性通过，模型及队列记录均为0。40分钟预览的超预算提示、第二段及原引用范围经原生CUA核对。时间定位及自然转写准确率未独立标注验收；最后识别时间接近片段末尾不证明语音无遗漏。

脱敏证据见[执行证据](../research/evidence/transcript-segmentation-2026-10-12.json)。私人原话与媒体仅留在忽略的runtime，未提交。

## 后续模型执行约束

现有认知回执按整份来源/逐字稿绑定和复用，不能把小段冒充完整ContextTranscript或放宽旧校验。下一切片须定义父批次及片段身份、原全局范围映射、冻结传播和聚合门槛。后段可能否定前段的任务承诺，因此各段理解后不能立即外写任务；先完成整个批次语义合并与去重，再释放行动。任一段unknown不能自动重发，也不能把不完整批次当完整结论执行。

本轮未改变产品愿景、未授予新增云端权限、未执行自然行动反馈验收。技术选择见[ADR025](../adr/025-transcript-segmentation.md)。
