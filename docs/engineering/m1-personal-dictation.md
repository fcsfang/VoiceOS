# M1 个人口述捕获增量

日期：2026-10-11。开发实现；AC-01/真实录音、权限与睡眠验收尚未通过。

原生工具栏提供“开始我的口述”和“停止并保存口述”。开始才请求麦克风，声明本人表达；外部节目使用导入。录制期间可关闭阅读窗口，应用宿主继续；导出暂停。停止后核对并封存原件，随后本地中文转写。默认仅本地，不发模型、不上传原始音频或自动写任务。

录制前保存来源身份，暂存CAF，正常结束回调后才完整解码/核对摘要并进入已有保存状态机。未正常结束、强退、编码失败或无法解码时保留片段，显示未封存。启动不自动把可解码片段当完整录制；“核对并保存录制片段”明确保存中断片段。已知sealed窗口可按原身份恢复，不重复生成队列。设备结束回调及错误回调去重；五秒无结束回调则报未正常结束。

## 待验证与下一步

真实设备权限、拒绝授权、录制/停止回调、退出/睡眠和自然口述质量尚无证据；不把合成CAF封存当真实录音成功。建议先10秒本机麦克风采集测试，无需讲话，独立测试资料库、不上传；它只验证设备及封存，不替代语义质量或三条完整闭环。该步骤会采集周围声音，须用户明确允许。W17对话、W18自动关联、W19英语、删除和完整验收继续开放。
