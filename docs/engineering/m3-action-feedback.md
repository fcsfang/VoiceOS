# M3 增量：行动结果与反思

2026-10-10。已实现的开发切片，完整 MVP 尚未验收。产品方向不变：先建立可追溯的认知—行动—反馈闭环。

## 当前行为

行动列表提供“记录结果或反思”，可选实际结果或我的反思，保存不超过 4000 个 Unicode 标量的文字。任务、探索意图和历史行动均可记录；记录是可选的，不阻挡完成。

反馈原文以独立 user_text 来源保存，默认仅本地，保留记录时的行动版本。详情“查看关联行动”能看到任务状态历史与结果；“查看反馈原文”返回原始来源。文字可沿用已有更正与版本历史机制。记录本身不改变任务状态、观点认可、证据状态，也不触发理解或外部写入。

## 工程契约

- `recordActionFeedback` 以父行动 ID、预期版本、类型、原文共同定义命令身份。版本不匹配拒绝，且不创建新来源；同一成功命令在行动后来变化后仍可返回原回执。
- 来源保存意图携带关联配方；原文资产、文字版本和反馈关联同事务完成。恢复复用用户文字保存流程，避免原文成功却丢失父行动关联。
- 行动内递增 sequence 记录历史顺序。反馈关联版本不因任务重新跟进或其他变更而漂移。保存到冻结行动不重新激活行动。
- 结构化或原件迁移均保留父行动、版本、类型、原文与修改历史。当前包 v10/schema 11，有十七类可迁移记录；本机连接授权仍排除。

## 实际验证

80 项自动化测试通过，新增六项覆盖状态/证据分离、成功命令重放与历史版本、陈旧版本拒绝、多条反馈顺序迁移、更正后关联保留、重算 manifest 后缺失关联仍被拒绝。

新增六次实际 SIGKILL：intent、copyComplete、sealed、renamed、savedUncommitted、savedCommitted。每次重开两次确认恢复稳定：intent 中断且无反馈关联；其余原文和关联一并恢复；父任务保持 completed 第 2 版。此前其他切片的 25 次文字/认知/行动/提醒事项故障验证保留，共 31 次。此前检查不是全部在本切片重跑。

真实控制中心使用独立 `feedback-ui-v1` 测试库，记录合成结果后从详情进入任务历史，并返回反馈原文。新来源 local_only=1，原任务 completed/version=2，探索意图 open/version=1；三条候选仍 unverified。模型调用记录保持 1 条历史记录，没有新增请求，提醒事项授权为空，无外部创建。

v10 原件包恢复后十七张可迁移表逐值一致。实际 schema 10 数据库升级后十七张旧表的原字段逐值一致；真实历史 v1–v9 包均恢复至 schema 11，完整性与外键检查通过，连接授权为空。摘要证据见 [action-feedback-2026-10-10.json](../research/evidence/action-feedback-2026-10-10.json)。
