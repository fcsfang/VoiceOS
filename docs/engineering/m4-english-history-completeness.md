# 英文历史界面与模型边界补齐

2026-10-11。承接近期质量复查，优先补已有能力的可核对性和失败语义，不扩展产品范围。

## 本轮交付

英文入口的当前练习选项显示原文摘要，避免同一秒保存的多份“我的表达”难以辨别。准备操作只读取选定文字，打开完整本次/旧练习预览；返回不调用模型。更改选择清除准备快照，准备或发送时锁住选择。反馈历史独立滚动，保留原句、建议和比较双方原句；显示冻结、失败原因、已知 tokens 与未知费用。旧练习列表在有历史时缩短，给反馈更多阅读空间。

新增 `english-ui-seed <新的隔离目录>`，拒绝已存在的目录。只用内存端口创建 24 份合成文字、12 条独立反馈；11 条完成、1 条未知，其中1条完成反馈在撤权后冻结。模拟文字云端授权只验证相同 Store 边界，没有网络实现、凭据读取、录音或提醒事项写入。夹具不是自然英语质量证据。

英文执行在预留前检查取消，已返回结果在提交前再次检查取消和来源授权；不能接纳的晚到结果不保存反馈，但保留已知用量。普通认知请求也补齐取消检查，已返回的用量保留，取消后不提交候选、不自动重发。原有讨论回复、讨论成果、相关性入口已经持久预留后再 await，且具有发送/接纳屏障；此轮检查不等于这些模块全部变体经过重新验收。

英文调用虽暂复用 `discussion_derivation` 存储类别，但其费用状态必须为 unknown，不能误显示本地派生的 not_applicable。后续真实英文 CLI 探针也走持久驱动，不再直接调用裸端口；本轮未发起新的云端试验。
