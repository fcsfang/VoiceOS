# M4：独立样本、长文本与相关性快照

日期：2026-10-11。开发切片；语义界面、云端生产调用和自动关系均未开启。

## 质量进展

[v2 样本](../testing/fixtures/retrieval-quality-v2.json)在测量前固定：24 条原文、24 个问题，包含 4 条 685–767 标量的长原文，核心意思位于末尾；另含同词异义、相反观点、条件和引用中的恶意指令。标注不随输出改动。向量模型按 256 标量、96 标量重叠切成 38 个片段；保留原文位置，单来源取最高片段分数。没有静默截掉末尾。

上一轮固定提示 v1 的召回完整，但在校准组把复习策略争论当成练习时间安排、把会议记录归属当成播客观点归属：精确率 9/11（82%），保留组 10/10；两组相关记录召回率均 100%，6 个无相关问题均为空。该结果没有达到预定 90% 精确率门槛。

提示 v2 只补充一般规则：查询限定对象/载体/情境时，不能仅以可类比的共同原则判直接相关；一般方法问题可以选直接讨论方法的具体例子。没有硬编码样本 ID 或改标注。另固定 [v3 样本](../testing/fixtures/retrieval-quality-v3.json)：16 条原文、16 个新问题，在 v2 提示测量前冻结。v3 的 12 个相关问题全部找回，返回精确率/相关记录召回率均 100%，4 个无相关问题均为空。再对长文本 v2 做回归，两组返回精确率/相关记录召回率均 100%；这个回归不称为独立盲测。

本轮 3 次合成模型调用共 13,394 tokens，模型仍为 gpt-6.1-sol，无重试、私人原文上传或外部笔记/提醒事项写入。实际费用以服务方账单为准。共享批量研究输入与逐次生产发送不同；结果只支持继续工程验证，不代表全部验收或长期使用质量已通过。

## 规模与分段

生成 1,000 条合成来源，以 32 个生活主题模板加不同编号形成干扰，正例分别放第 250、500、999 个位置（从 0 起计）。共扫描 1,011 片段；遗忘练习、条件、迁移查询的 5 个正例排名为 1/3/1/1/1，均在 top8 内。当前 CPU float32/4 线程模型加载和计算约 1.90 秒，不含 Python/模块启动与下载，可能有文件缓存。

这只是位置与容量验证，不是 1,000 个独立语义主题或自然长期历史。未将该大库上传给模型。连续文字检索仍为应用的可靠入口。

新增分段时发现探针的计时变量被片段起点覆盖；首次 v2 计时无效，修正后离线重跑得到相同排名，证据只使用修正后的 0.35 秒。此前短文本实验的原有计时不受该新增分段代码影响。

## 已实现的边界

`RelevanceSelection.swift` 提供只读快照与结果接纳：

- 查询 ≤512 标量，输入最多 8 个不重复片段，查询与候选原文合计 ≤4,000 标量；超限报错，不悄悄截断或过滤。
- 来源、文字、权限版本、片段范围及原文固定于摘要；候选身份、来源归属与显示元数据也核对实际记录。
- 云端预览要求主动查询允许上云、每条来源非仅本地；混合授权不自动丢掉私有内容。预览不保留调用、更不发送请求。
- 接纳时核对当前查询身份、快照身份和完整输入；未选中的原文变化也使整次结果失效，空结果同样重验。
- 只可选择最多 3 个已知、不重复候选。结果不创建原文、观点、证据状态、关系或行动。
- 本地判定端口与云端发送分离；本地异步结果取消后丢弃。恢复未完成的资料库不能接纳候选。

快照不是持久发送许可；本轮没有云端调度或可恢复的相关性调用记录。UI 没有新增语义开关。存储仍为 schema 11、包 v10，无新增迁移字段。模型资源仍是研究资产，不增加应用依赖。

107 项自动化测试通过，新增 14 项涵盖私有原文不升级、空结果、混合云端权限、撤销与重新授权、非选中输入更正、错误身份/重复/未知/超量候选、Unicode 预算、取消晚到、更正晚到、损坏、摘要篡改、伪造身份/归属/元数据和非法分数。应用构建与签名核验通过；本轮未改变界面，没有新增界面实测或强退场景。
