# 项目记录

`work/` 保存项目状态和任务记录。完整规则见 [Agent 工作流](../docs/agents/WORKFLOW.md)。

- `TODO.md` 尚未开始的工作。
- `STATUS.md` 当前状态。
- `PROGRESS.md` 已合并改动。
- `tasks/<date>-<slug>/` 单个任务的 `TASK.md` 和 `CHECKPOINTS.md`。
- `TASK-TEMPLATE.md` 和 `CHECKPOINTS-TEMPLATE.md` 模板。

完整职责列表见 [文档职责表](../docs/agents/DOCUMENT-MAP.md)。
