# 使用体验批次二

## 目标

延续第一批的使用体验工作，主动挖掘并修复能自主决定的问题，四个互斥工作流并行推进。

## 范围

- 工作区阅读连续性。材料详情按来源 ID 保存滚动位置；顶层列表偏移按材料或行动过滤器分键，切换列表不再沿用无关偏移。
- 错误可见性。正文上方新增可关闭的错误横幅，覆盖本地语音配置、文本模型配置与导出失败，提供对应的安全重试；注意力徽标不再遮蔽新的失败。
- 导出进度。导出期间禁用按钮并显示进度，防重复触发。
- 材料列表性能。每个列表正文只构建一次记录目录，行内不再全量扫描。
- 首页搜索反馈。显示匹配区域数与无匹配提示，区分仅在问题或联系文字中命中的情况，提供“定位”把现有相机适配到匹配卡片；状态按工具条宽度收敛（≥900 全文、≥620 短文案、≥520 图标、更窄隐藏）。
- 跟进目标守卫。“全部录音”下“更新下一步”不再作用于任意第一份录音，改为禁用并提示先选择录音。
- 减法。删除不可达的 DailyWorkbenchView、KnowledgeLibraryView 与 TaskManagerView，仍在使用的 ConfirmTaskView 拆为独立文件，净删约 800 行。

## 非目标

- 工具条整体重构与溢出菜单；首页搜索的屏幕级视觉确认。
- #44 确认入口语义、#51 单轨分段与收件箱同意、#39 原生触摸验收、#66 核对分批与预算。

## 验证

- 四个工作流各自 worktree 内构建与 12 项测试通过；集成树 `swift build` 成功、`swift test -j 4` 12 项 0 失败、44.6 秒。
- `dist/VoiceOS.app` 按合并后的 main 重建并重启；实时资料库未被生成。
- 屏幕级确认留给日常使用；窄宽度阈值按布局下限推算，未做视觉确认。
