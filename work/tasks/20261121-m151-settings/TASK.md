# 151-设置页信息层级重构（设置页 → 卡片分块 + 行原语）

## 背景
用户直接反馈：设置页信息杂乱无章，没有分块概念，间距不讲究。研究与落地规则：
- NN/g 邻近原则：留白是分组信号；标题与其内容距离必须小于上一区块到标题的距离。
- NN/g 表单留白法：相关字段成组、组可用标题；标签靠近所属控件。
- Apple HIG：减少设置项数量、按变更频率与场景分组、稳定结构。
- Microsoft Fluent 间距刻度：控件与标签 12、区块内容 12、表面与边缘文字 16、区块间距显著更大。

## 改动
- WorkspaceDesign 新增四个设置原语：`WorkspaceSettingsCard`（每类信息一张卡：标题+说明+内容，表面+发丝线）、`WorkspaceSettingsRow`（标签列+右对齐控件列、行间发丝线、minHeight 46、水平 padding 20、16pt 间距）、`WorkspaceSettingsNavRow`（整行可点+chevron+hover）、`WorkspaceSettingsValueRow`（标签/细节/右对齐等宽数字值，支持强调）。
- 设置页按 11 张卡重组：模型与服务 / 数据与隐私 / 连接与自动入口 / 系统权限 / 外观 / 导出与备份 / 资料库 / 存储 / 回顾与查找 / 键盘快捷键 / 其他工作与维护。页头加一行副标题；内容列限宽 680；卡间距 sectionGap 28、卡头到首行 12、行内 12/20。
- 每个原本平铺的动作都保留（导出两种、备份/重试/访达、保留份数+清理、检查资料库、备份新建、打开已有、迁移包恢复、存储明细与删除模型、回顾三入口、快捷键说明与冲突提示、引导、维护工具与状态）。
- 控件词表收敛：导航行 chevron、状态行右侧 compact 按钮、危险操作仅保留现有 workspaceDestructive。
