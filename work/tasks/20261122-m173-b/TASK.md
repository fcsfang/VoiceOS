# 173-B 重复短语的引文锚定消歧

## 来源
审计确认：`anchor` 固定取第一个包含引文的时间片，同一短语在全篇重复时总是定位到最早一次，回听从错误位置开始。

## 改动
- `MaterialNoteAnchoring.anchored` 改为逐段落解析锚点：
  - 同一段落内锚点按叙述顺序单调推进，重复短语优先选择上一个锚点之后的时间片；
  - 仍有多个候选时，用段落上下文（去掉引文后的双字组）与各候选时间片的重合度打分，同分取最早；
  - 全部候选都早于上一个锚点时才退回全量候选；跨时间片引文仍保留锚点且 spanID 为空。
- 补两个测试：上下文偏向的后一次出现被选中；同段重复短语不回退到更早时间片。
- 同时修复：`anchored` 重建段落时丢失 `inferred` 标记（173-A 的测试暴露）。

## 验证
- 改动文件 parse 真实退出码 0；构建与测试结果见 STATUS。
