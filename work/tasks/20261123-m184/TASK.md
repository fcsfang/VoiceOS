# 184 首页最近笔记与许可口径校准

来源：阶段 2 审计候选 7（云端文字许可口径与自动授权点不一致）与候选 8（首页没有「最近笔记」——旧录音今天整理的笔记按录音日期排，不会浮现）。

## 184-A 首页「最近笔记」
- Core 新增 recentMaterialNotes(limit:)：每个表达取最新一版、按 created_at/rowid 倒序（相关子查询，每键一行）。
- 首页时间线顶部新增可折叠「最近笔记」组（默认展开）：笔记标题 + 导语/首段预览，点击 revealSource(expressionKey 首成员) 打开同一正文并恢复阅读位置；随 recordsRevision/materialNotesRevision 刷新。
- 测试 +1：最近笔记按整理时间倒序且每表达只一篇。

## 184-B 许可口径
- 收件箱「查看接收与处理规则」明确：连接入口后新录音文字会自动交给已配置文本模型（云端），随时可在材料里改为仅本机。
- 引导第 2 步补「（或开启自动处理）」，与自动收件行为一致；设置页数据与隐私卡本已准确，不改。
