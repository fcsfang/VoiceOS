# 219 入口条目自愈与跨入口可见性

目标：文件被移走/删除后，入口条目不再永远停在「将在…自动重试」；同一内容出现在另一个入口时，失败原因可见。

## 改动

- 扫描时记录每个入口当前实际存在的路径；非处理中条目若其文件已不在入口目录，转入「需要处理」，说明「入口里已找不到这份录音（可能被移走或删除）；把文件放回后点重试」。目录读取失败的入口不参与判断，避免权限抖动误判。
- `failures` 按内容 digest 跨入口共享：当同一内容在另一个入口失败时，状态行写明是哪一份录音，不再静默跳过。
- 失败分支创建的条目补上 `fileStamp`，与扫描的稳定副本匹配一致。
