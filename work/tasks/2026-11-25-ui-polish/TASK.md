## 审查结论（正式实例截图，只读）

全站：
1. 分组头不统一：材料日期、行动「以后或未定日期」、启动「启动记录」用满宽灰色色带；主题页用文字标题+计数。→ 统一为文字标题。
2. secondaryText 0.72 与 tertiaryText 0.70 肉眼无差。→ 拉开到 0.68 / 0.52（增强对比度 0.85 / 0.72）。
3. 列表标题全部粗体，成墙。→ 列表行标题降为 medium，粗体只留页面/分组标题。
4. 主按钮纯黑，与主题强调色脱节。→ 改用 accent。

- 行动每条一张卡；17/18 条「已写入提醒事项」淹没「提醒缺失」→ 发丝线列表，只显示异常。

- 设置「文字大小」行缩进不齐。
- 阅读页标题下装饰线去掉、高亮更淡。
- 侧边栏底部状态折两行；消息监测角标太弱。

## 决策记录

- 基线：正式实例跑的是 Codex 分支 `codex/edit-generated-content`（42c8023，领先 main 18 提交，色带分组头就来自其 ce0e170）。本波基于 42c8023 开工作树 `.worktrees/ui-polish`，避免与其冲突；合并时该分支随本波一起进 main。
- 文字层级：原计划 0.68/0.52 经 WCAG 计算不可行（鼠尾草 0.52 仅 3.0:1，原 0.70 已在 AA 线 4.5 附近）。改为反向拉开：secondary 0.80、tertiary 0.68，三主题所有浅色表面最低 4.69:1。增强对比度 0.90/0.80。
- 分组头：WorkspaceListGroupHeader 与 WorkspaceListSection 去掉 selection 色带，回到画布上的文字+发丝线（与主题页一致）。
- 主按钮：背景由 text（近黑）改 accent，前景仍 canvas。石墨 accent 0x3A4A5C 对白 ≈ 9:1。

- 行动：ActionCardList 由每条一张卡改为每组一张卡、行间发丝线（左缩进 54 = 内边距 10 + 图标 30 + 间距 14，对齐标题）；键盘高亮改行底色。ActionRowLayout 中「已写入提醒事项」是常态，行只显示日期（今天/明天/已逾期 X），提醒待核对/缺失照旧完整显示并保持 warning 色。测试矩阵同步更新并补逾期、缺失两例。
- 笔记：行下加一行 tertiary 预览（lead 首句，与标题相同时不显示），垂直内边距 14→12。
- 材料：「已读」不再显示尾标（静止态），「在读」点与「N 条待办」保留；未读/在读筛选和右键菜单不变。筛选栏本已是系统分段控件，不动。
- 主题卡：「材料已更新，待重新整理」灰底提示块改为标题行右侧 accent 小标签「待重新整理」，完整文案进 tooltip；主题详情页的 banner 保留（那里需要上下文）。「新建主题」加 plus 图标并用 workspaceSecondary（有边框）。
- 启动：「查看归档」改为左标签+右小号开关一行。
- 侧边栏底部：「需要查看」+ 警示色数字胶囊，一行放下；完整分解放 tooltip 与无障碍标签。消息监测角标是系统 List badge，保留原生样式。
- 阅读页：标题下短线是有意的「手账感」设计且挂着滚动探针，保留；高亮 marker 0.20→0.16、muted 0.10→0.07。
- 设置：文字大小行与主题卡片同为 20pt 左内边距，复核后无需改。
