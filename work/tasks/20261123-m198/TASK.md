# 198 材料列表：没有笔记的行不再直接展示原文首句

成品优先的第三处（待实现）：材料列表里没有笔记的行目前直接展示原文首句，等于把原材料摆在一级列表上。

## 计划
- WorkspaceView 材料行：有笔记时保持现有笔记标题/预览（174-A）；没有笔记时，标题用中性可辨的标识（材料名/导入日期），预览位显示状态行：「待整理 · 完成后这里显示笔记」；不再截取原文首句。
- 正在整理/转写等待/仅本机等状态直接复用行内既有状态文案或补充。
- 主题「未归入材料」列表同步检查是否展示原文首句（如有，同样改为状态）。
- 与 171-A 的材料卡结构保持一致，只改预览来源与回退链，不动分组/筛选。

## 验收
有笔记的行视觉不变；无笔记行不再出现原文句子；点击行为不变（打开材料页）。

## 状态
等 192–197 评审工作流结束后实施（避免与评审读取的文件交叉）。
