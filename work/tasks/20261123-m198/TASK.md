# 198 材料列表：有笔记的行改用笔记标题

成品优先的第三处。原计划「无笔记行一律改待整理状态」，实施时修正：材料列表是「去查」的材料视角，没有笔记的行若丢掉原文首句就不可辨识（自动标题本身是 20 字截断的半句），会把可用的辨认能力换成抽象状态，得不偿失。因此：

- 有笔记的行：标题用笔记标题（与首页、笔记页同源，经 fittedDisplayTitle 排版）；没有笔记的行：维持原题/原文首句回退。
- 「待整理 / 转写中 / 仅本机」等状态继续由行尾状态位承载，不加新文案。
- 成员口径与笔记生成一致（expression.sourceIDs + externalVersions 排序去重，materialNoteExpressionKey）。

## 验证
parse_exit=0；集成构建 104；上机看有笔记材料行的标题与笔记页一致。
