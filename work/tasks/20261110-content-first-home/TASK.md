# 内容优先的首页：最近记录与想法

## 目标

用户指出首页已经形式优先：思考全景把跨材料的主题关系画在最前面，最新录入的内容和想法反而找不到。初衷是把想法、思想与成长存档，并用 AI 辅助拓展；首页应先回答「我最近想了什么」，形式放在后面。

## 决定

原型比较了三种布局，用户选择 C：左侧按日期与材料排列，右侧直接阅读所选内容的摘要与想法。全景保留为首页的切换视图。

- A 内容流：单列时间流，每张卡片带摘要与少量想法。
- B 每日回顾：以「昨天」为主角，先读想法，更早内容压缩成列表。
- C 时间线 + 阅读（采用）：左栏负责定位，右栏负责阅读；默认选中最近一条带想法的材料。

## 数据形状

- `RecentContentThought`：一条想法（claim 身份与清洗后的陈述）。
- `RecentContentItem`：时间线上的一条内容，材料或当天的行动反馈组；含来源、时间、标题、摘要、想法与反馈摘录。
- `RecentContentDay`：按本地日期分组。
- `RecentContentIndex.build`：从 sources 与 claims 纯函数生成；过滤非本人材料、去重陈述、去掉「说明：」「【录音中活动】」「【待核对】」等提取簿记，行动反馈按天合并。

## 范围

- 首页默认「最近」；「全景」一键切回星图。
- 全景可见性跟随切换，隐藏时不重建全景。
- 右栏显示材料标题、摘要、想法列表与「打开材料」；反馈组显示当天反馈原文，段间分隔。

## 非目标

- 未做已读标记、想法按主题分组与折叠、跨材料的「最近想法」聚合。
- 未改主题页、材料页与行动页。
