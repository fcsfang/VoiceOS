# 界面说明性文字清理

## 目标

用户反馈：软件里到处是说明性文字，正文被旁注包围，整体显得脏、像打补丁。目标：给「什么文字配出现在正文旁边」定一条硬规则，按规则删掉主要阅读界面上的解释性噪音，让正文重新成为页面主体。

## 规则（本次执行的取舍标准）

1. 每屏每类数字只说一次。同一组「条想法 / 条线索 / 条任务进展」不在列表、导语、目录、标题里复述。
2. 时间只说一次。列表用日期分组；阅读区用日期、时长。不显示 ISO 原始时间戳。
3. 解释只留一层。区块标题与副标题二选一；空态是标题加一句可操作的话；功能边界、AI 归属、免责声明全页最多一次，逐条卡片不再重复。
4. 技术字段不进正文层。ID、digest、responseID、token 用量、英文状态、文件名只进可展开详情或本地化后进小字。
5. 一级页面只有标题，必要时一行短副标题。口号式 slogan 删除。

## 证据（实机 + 源码审计）

- 首页实机：行元「16:00 · 3 条想法 · 1 条线索」；导语「这次录了 19 分钟，留下 10 条想法，可以归成 2 条线索。」；目录「职业与学习 2 · 生活杂记 8」与正文线索标题重复；任务进展行两行计数「2 条任务进展 / 实际进展 2」；左栏标题「我的表达 · 2026-11-12T23:44:29Z」暴露原始时间戳。
- 主题页：「让零散的积累，连成脉络」+「同一个主题跨周、跨月延续；时间用来回顾变化。」两层 slogan/说明。
- 材料页：「按材料查看」+「最近加入的材料在前。连续录音由 AI 自动合为一次表达，原始分段在详情中保留。」说明规则；行元再带原始文件名。
- 行动页：「事情在向前推进」+「你的待办、AI 承担的任务和完成结果，都在这里。」+ 两个区块各一行说明。
- 源码审计（子代理，全 42 个视图文件）：同屏复述同一组数字 4 到 6 次；几乎每个区块标题都带一句解释；原始 ID、token、英文状态、文件路径直接进入主阅读层。完整清单见任务记录讨论，不在仓库重复。

## 决定

- 2026-11-14 追加（用户指定）：首页保留分类标题，但所有想法默认全部展开。删除重点框、支持段与「展开 N 条」的折叠层级，以及背后的 leadScore 打分；目标统一进「想慢慢做到」盒。`RecentContentThread` 收敛为「标题 + 全部想法（原顺序）+ 目标子集」。
- 2026-11-14 阅读区定稿：序号给想法（1 到 N，左侧悬挂、小号淡色），分类标题不再编号；删除观点/想法标签。AI 概览摘要从页尾折叠移到标题下方并标注「AI 概览」。加载完成前显示加载态而不是空态。
- 2026-11-14 行动口径统一（用户报告材料与待办不一致）：行动页「全部」增加问题与目标概览节；材料详情的相关行动拆为「待办」与「问题与目标」两节；问题与目标分类排除冻结条目。判定：不是数据缺失，是「全部」实际为最窄待办与材料口径不一致的展示缺陷。
- 2026-11-14 去防御性 AI 标签（用户指定）：整体由 AI 生成的阅读面不再逐块标注 AI。删除首页「AI 概览」、主题阅读「AI 综合整理」、全景「探索区域 · AI 归纳」与逐面板「AI 归纳 · 未表示本人认可」、知识核查逐卡「AI 核查建议」、交付页「仍保留 AI 产出归属」。混合来源处的归属标注保留（我的表达 / 外部资料 / AI 建议、AI 弹性安排等），那是信息不是防守。概览改为主色衬线导语，靠排版区分声音。
- 分四个可独立验证的单元：
  1. 首页：删导语、目录、计数复述、「来自这次录音」逐条标签；左栏行动反馈计数合并；阅读区元信息收敛。
  2. 一级页面：主题 / 材料 / 行动 / 启动 / 设置 / 搜索的 slogan 与规则说明删除，只留标题与必要计数。
  3. 详情页：区块副标题与标题重复的删除；AI 归属与免责声明每页一次；空态压成一句。
  4. 技术泄漏：展示标题与内部 name 分离（首行文本或「未命名表达」）；原始 ISO、ID、token、英文状态本地化或移入详情。
- 每单元先改、再构建测试、再看截图；首页必须有前后对比截图。
- 深度面板（全景、讨论、回顾）作为第二遍，待前四个单元落地后评估是否需要同一分支追加。
