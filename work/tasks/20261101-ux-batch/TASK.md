# 日常使用体验批次

## 目标

按用户要求把关注点从全景管线转到日常使用体验与遗留 bug。能自主决定的直接修，需要产品语义的只记录不发明。

## 范围

三个并行工作流，文件互斥，各自独立 worktree 与分支，合并前在集成树跑全量测试。

- 记录与导入。录制主按钮的前置条件直接显示并给配置入口；首次启动显示打开进度而不是空库；完整录音缺前置条件有说明，媒体检查失败弹出警告；收件箱可以先连接文件夹再配模型；三轨固定布局拒绝把混音或系统轨标为本人声音，单轨未勾选时提供“作为外部资料导入”出口，音轨角色收敛为纯函数 `RecordingTrackDecision`；主题重复保存有在途守卫。
- 首页与英文练习。全景读取失败保留上一份可用状态与选择，显示可关闭的横幅与只读重试；英文练习首次打开不再误报“选择已变化”，空库显示可理解的无内容视图。
- 冻结任务。外部完成说明要求链接有效、标记有效且已完成，并统一到来源页、处理页与主题页的行动行；冻结原因先报真实原因，许可变更带旧新版号与时间，任务页显示原因；“纠错影响”新增许可变更的只读分区。
