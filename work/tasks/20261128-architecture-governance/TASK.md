# VoiceOS 架构治理

把现有产品行为收敛到明确的模块职责、单一事实来源和可验证的依赖方向。逐批迁移真实调用方，保留已有资料和对外契约。

## 范围

覆盖生产 Swift targets、Python 与 shell 工具链、持久化和备份、UI 状态、外部系统适配以及验证入口。按 [架构现状与任务池](ARCHITECTURE.md) 推进。

在架构治理独立分支继续推进。前序 A01 至 A15 的产物已复核，真实资料副本的 41 组 CLI 输出与行动投影改造前一致。A16 修复打包产物发布边界，签名失败时保留旧包。A17 将资料授权的两处写入和五处历史版本核对收敛到一处。A18 统一连续表达的版本与许可校验，工作区从一次判断取得分组或失效原因。A19 在同次快照、批量跟进和分组准备与写回中复用完整目录。A20 让普通资料读取和知识核查轻量投影共用双轨、连续表达和全文校正规则。A21 删除侧栏的未使用行变体，并复用工作区的悬停状态实现。A22 共用材料的列表投影，并按快照复用全部材料标签。A23 统一材料筛选及排序，并验证保存格式兼容。A24 统一行动筛选、回顾跳转和保存表示。
