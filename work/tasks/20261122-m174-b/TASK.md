## 修复
1. 生成态闪烁：`.generating` 移到「已有最新笔记即空闲」判定之后；单飞由 run 注册表保证，不再需要提前占位。
2. 失效横幅冲突：`.unavailable` 说明仅在无已显示笔记时出现，避免与正文和「AI 根据…整理」自相矛盾。
3. 页头首帧塌缩：新增会话内同步缓存 `materialNotePresence`（加载/生成成功回填），页头让位在首帧即按正确版式排版。
4. 键盘顺序：行动页「全部」的方向键顺序改为 今天 → 专注 → 其余，与可见顺序一致。
5. 材料行题长：原文首句作为行题最多 48 字，避免单行被撑成多屏。
6. 锚定消歧跨成员：段落内单调次序改为按 (sourceID, spanIndex) 记录，切换成员时复位。
7. 视图成员集合：阅读视图的 memberIDs 并入 externalVersions（与生成/展示同口径），外部成员变化会触发重读与重请求。
8. 单飞键控：run 注册表按表达式成员集合（排序 sourceID 连接）键控，同一表达从不同分段进入共享一次运行，加入者同步最终状态。
