# 外部提醒完成的显式确认与结果回流

## 目标

冻结任务的外部提醒已在 Apple 提醒事项中完成，但本地仍显示「尚未登记完成」。用户需要一个明确的确认入口，确认后把这件行动登记为已完成并进入结果队列，同时保持观点与理解冻结，不恢复旧输出。

## 范围

- Store：新增 `confirmExternalCompletion`，只接受 冻结任务 + 已关联 + 标记有效 + 最新回读已完成 的组合；写入一条 actor 为 user 的 action revision，备注包含观测 ID；版本递增；不改 validity。
- 结果队列：`pendingOutcomeFollowups` 与 `recentActionOutcomes` 纳入「冻结但已被用户确认外部完成」的行动，保存的结果能被识别并移出队列。
- UI：任务页与暂停任务行在外部完成说明旁提供确认入口，确认弹窗写明「登记完成并进入结果队列；观点与理解仍冻结」；已完成或已确认时不再显示。
- 测试：冻结行动 + 已完成外部观测的夹具；确认后状态、revision、结果队列、幂等、validity 不变；再次调用不重复。

## 非目标

- 不自动完成、不自动恢复冻结输出、不改观点有效性。
- 不新增模型调用或提取管线。

## 决策

- 采用用户显式确认，而不是自动登记；这是 #44 评论里留给产品决定的那一项。默认选择确认后登记完成并进入结果队列，可逆：用户可以不点。
- 复用 `action_revisions` 的 command_id 与 input_fingerprint 做幂等，不新增表。
- 结果队列必须同时识别已保存结果，避免确认后反复出现。
