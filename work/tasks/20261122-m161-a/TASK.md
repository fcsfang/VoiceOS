# 161 卡片家族审计修复（发现波）

## 背景

## 修复清单
一致性：
1. 消息监测设置页三张卡改用 `WorkspaceSettingsCard`（检查计划 / 微信推送 / QQ 群读取），卡头统一 rowTitle 与 20/18/12 内边距。
2. 处理情况页两处裸 `WorkspaceRow` 补 `.processingRowInset()`（当前处理材料行、最近完成行），与同卡其它行对齐。
3. 行动详情「记录与依据」卡三处 DisclosureGroup 行垂直内边距 14→12。
4. 自动入口「工作方式」折叠行标签 meta→body，内边距改 20/12。
5. 静默回顾与查找历史文字两页容器间距 14→sectionGap。
6. 监测历史报告副标题由裸计数改为「共 N 次，最新在上」。
7. 来源状态卡副标题去掉句末「。」。
8. 英文反馈页卡内子分组标题改用 `WorkspaceSectionHeading`。

可达性：

10. 设置页两个「导出」按钮补区分性 accessibilityLabel（导出结构化资料 / 导出资料与原件）。
11. 「更改」「清除」三个按钮补上下文 label（更改语音转文字 / 更改文本模型配置 / 清除文本模型配置）。
12. 两个「在访达中显示」补上下文 label（显示资料库 / 显示备份）。
