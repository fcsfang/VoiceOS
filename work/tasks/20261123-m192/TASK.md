# 192 笔记即首页

用户想法：笔记能否替代首页成为新首页——现在的首页点进材料是【想法】【原文】的结构化信息，实际不太想看。

判断：方向对。文章是更好的阅读单位；但旧首页还承担「待处理」提醒（新录音、转写疑点、行动反馈），暂时保留为一键可达的收件箱，观察几天再决定是否完全替换。

## 实现
- WorkspaceView 默认页从 .home 改为 .notes；旧「首页」侧栏项保留。
- NotesLibraryView 顶部：还有未读材料时显示「收件箱 · N 条材料待处理 / 去处理」安静入口（按 homeSnapshot 的材料项与阅读态计算，读完即消失）；点击进入旧首页。
- 阅读态随 recordsRevision 刷新。

## 验证
parse_exit=0；集成构建 97；上机确认启动落在笔记页、收件箱入口可见可控。
