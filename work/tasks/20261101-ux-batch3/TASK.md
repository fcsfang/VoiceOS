# 使用体验批次三：键盘、焦点、材料行与英文入口

## 目标

减少日常录入与浏览里最常见的摩擦：打开录入页要先点正文，材料行被两个按钮撑高，英文练习空状态没有去处。

## 交付

- 录入页与讨论编辑框打开即聚焦正文；其他输入框已聚焦、正在录制或保存时让开，不抢焦点。
- ⌘⇧R 开始或停止口述，录入页显示提示。SwiftUI 命令注册在这台环境不生效，改用本地事件监听。
- 材料行恢复单行高度，归档与移入回收站收进行内更多菜单；已归档保留取消归档，回收站保留恢复材料。
- 英文练习空状态新增“去记录英文表达”，直达记录页。

## 验证

- `swift build` 通过；`swift test -j 4` 12 项 0 失败（43.7 秒）。
- `dist/VoiceOS.app` 按本分支重建并启动，实时资料库仍为 54 个来源，无写入。
