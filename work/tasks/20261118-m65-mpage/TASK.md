# 波 65 任务书（2026-11-18）：消息监测页拆分报告与设置

## 背景（实机反馈 2026-11-18）

消息监测页把今日报告（35 项事项的长列表）、历史、来源状态与设置（每日时间、云端授权、推送、QQ 绑定）放在同一个滚动页。今日报告一长，QQ 绑定与推送设置就被压到页面最底部；实机绑定 QQ 时需要滚动数千点才能到达，用户与助手都被卡住。设置是配置项，不应随报告长度漂移。

## 完成判据

1. 消息监测页顶部加二级切换（沿用首页「最近/全景」式分段控件或等效既有样式）：「报告」与「设置」两页。
2. 「报告」页放今日报告、历史报告、来源状态与「立即检查」；「设置」页放每日自动检查时间、云端分析授权、微信推送、QQ 群读取（含列群、起始时间、添加）。
3. 两页状态与既有逻辑不变：切换不丢表单输入、不重复触发检查；进入页面默认「报告」。
4. 设置页内 QQ 群读取区独占篇幅，添加按钮在常规滚屏内可达（无长报告垫底）。
5. 既有行为不回归：立即检查、报告状态、来源启停、推送测试、诊断与权限指引全部保留。
6. `swift build -j 2` 真实退出码 0；若加测试只测纯逻辑（≤1 个用例）。当前 main 597 项测试。
