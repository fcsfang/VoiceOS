# 215 测试连接失败排查与保存顺序修正

现象：用户在设置页点「测试连接」失败。排查结果：
- 内部配置已存：baseURL=https://api.chiyi.cc/v1，model=gpt-6.2-sol，note/topic effort=high。
- 系统钥匙串存在 local.voiceos.textmodel / apiKey 条目，但读不出值（key_len=0）→ 探针拿到空密钥。
- 服务端拉取未完成（请求 120s 未返回），无法排除上游可达性问题。

根因判断：applyTextModelConfiguration 先构建全部端口、再写钥匙串。构建期间系统会弹钥匙串授权框；若被拒绝/忽略，整次保存抛错，密钥未写入，出现「配置已存、密钥为空」的半保存状态。

## 改动
- 先写钥匙串与配置，再构建端口：保存失败不再丢输入；失败文案区分「钥匙串被拒」与「端口初始化失败（服务不可达）」。
- 探针：空密钥给出可操作提示；失败结果附带规范化请求地址与响应体前 200 字（不含密钥），便于诊断 /v1 重复拼接与鉴权错误。

## 验证
parse_exit=0；构建 133；重启后请用户点「保存并启用」并在钥匙串弹窗点允许，再点测试连接。
