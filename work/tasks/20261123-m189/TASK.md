# 189 笔记的纯阅读入口

用户反馈：笔记页点进某一篇后和材料页没有区别，仍是要点、原文等材料工具；笔记应当是文章。

## 实现
- WorkspacePage 增加 note(String)：纯笔记阅读页，仅「所有笔记」返回、MaterialNoteReadingView（标题/导语/段落/看原话/相关）与安静的「查看材料与原文」入口；材料工具（摘要/要点/待办/原文与回听/处理记录）不出现在这里。
- 笔记页与首页「继续读」「最近笔记」行都改走 note(id)；无笔记的条目仍打开材料页。
- 阅读位置恢复复用 175-A 的段落锚点机制，滚动绑定按 note-reading:<id> 区分。
- 内容抽成 noteReadingPage(id) 独立属性，避免 pageContent 类型检查超时。

## 验证
parse_exit=0；集成构建 93。
