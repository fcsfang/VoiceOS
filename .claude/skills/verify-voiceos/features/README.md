# VoiceOS feature map

The map is the maintained verification source. A proof that drives one convenient entry point is incomplete when the map lists another. Each file uses the same four headings so a cold agent can find the drive recipe fast.

| Feature | Primary surface | Proof status in this checkout |
|---|---|---|
| [Import a recording](import-recording.md) | `voiceos-check import`, SwiftUI 导入文件 | CLI path proven (import, duplicate, export, restore) |
| [Record and seal dictation](record-dictation.md) | SwiftUI 开始我的口述 | Recipe present; GUI drive blocked without Accessibility, microphone permission still required |
| [Save an expression](save-expression.md) | SwiftUI 记录我的表达 | Recipe present; GUI drive blocked without Accessibility |
| [Export and restore a library](export-restore.md) | `voiceos-check export/restore`, SwiftUI 导出资料 | CLI path proven |

Launch and cleanup live in the parent [SKILL.md](../SKILL.md). Run the doctor before any drive. Use a separate data dir for CLI proofs; the store lock is exclusive.
